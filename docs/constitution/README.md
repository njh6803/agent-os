# Agent OS 헌법

세 파일로 나뉜다. 로드 시점이 다르기 때문이다.

- [principles.md](principles.md): 원칙 다섯과 거버넌스. `CLAUDE.md`가 임포트해 항상 실린다.
- [tech.md](tech.md): 언어, 도구, 의존성. 의존성을 더하거나 스택을 바꿀 때 읽는다.
- [operations.md](operations.md): 검증, LLM 테스트, 가드레일, 브랜치, 리뷰 파이프라인, 이슈, 환경 규약. 커밋·병합·리뷰·트래커를 만질 때 읽는다.

디렉터리별 규칙은 헌법이 아니라 `.claude/rules/*.md`에 있고 해당 파일을 열 때만 실린다. 현재 트리는 루트 `README.md`, 미래 배치와 첫 슬라이스의 범위는 `.scratch/plan.md`에 있다.

**Version**: 2.5.2 | **Ratified**: 2026-09-19 | **Last Amended**: 2026-09-28 (ADR 0001~0016, 0018). 2.5.2는 원칙 IV의 판정자 문장을 사실에 맞춘 것 — 플러그인 경계는 `tests/test_plugins_boundary.py`가, 나머지는 import-linter가 판정한다(ADR 0018. 판정자만 바뀌어 patch). 2.5.1은 patch 여럿을 묶은 것. 스택 표의 테스트 행에 둘째 구동자 문장(#75)과 HTTP 행의 fastapi 하한 0.140.8(#76)은 버전을 올리지 않은 채 들어와 여기서 소급한다. `principles.md`의 형제 상대 경로 셋(`tech.md`·`operations.md`·`adapters.md`)을 전체 경로로 고쳤다 — 임포트된 파일은 루트에서 읽히고(대기열 32), 이제 `tools/check_instructions.py`가 판정한다. 운영에는 LLM 테스트를 돌리는 계기(대기열 1), `fix/` 접두사(대기열 23), 일지 이름 규약, 리뷰 축 이름의 원천, Claude Code Review 건너뛰기 조건의 정정(#43은 반례가 아니었다), skip 판정자와 권한 거부 문장을 더했다. 원칙의 내용은 바뀌지 않았다. 2.5.0은 원칙 IV의 의존 방향에 공용 HTTP 층 `http`를 더하고, core의 금지 열거에 그것을 넣고, 어댑터가 그것을 import하지 않는다고 적은 것(ADR 0016, 열거가 는 것이라 minor). 같은 올림에서 스택 표의 HTTP 행이 fastapi의 하한을 적었다(ADR 0014). 2.4.0은 2.3.3 뒤에 버전을 올리지 않은 채 헌법 파일을 바꾼 PR 열하나(#19·#24·#27·#28·#30·#38·#39·#43·#45·#46·#50)를 한 번에 묶은 것. 가장 큰 것이 운영의 새 규칙 문장과 스택 표의 HTTP 행이라 minor이고, 원칙의 내용은 바뀌지 않았다(원칙 III는 판정자만, ADR 0013). 같은 올림에서 `principles.md`가 이 파일을 전체 경로로 가리키게 했다. 루트 README로 읽혀 PR #43이 버전을 찾지 못했다(ADR 없음, 문구 수정, 경위는 일지 2026-09-25-01). 2.3.3은 CodeRabbit 상한을 공식 문서 기준으로 바로잡은 것. CLI는 청구 주기당 3회가 아니라 개발자당 시간당 3회이고, OSS PR 리뷰는 별 수에 따라 시간당 1~10회다(ADR 없음, 사실 정정). 2.1.0은 원격·CI·PR을 첫날부터로 바꾼 것, 2.2.0은 리뷰 파이프라인 절 추가, 2.2.1은 CodeRabbit PR 리뷰를 빼고 CLI만 남긴 것, 2.3.0은 거버넌스에 "ADR은 결정 단위" 문장을 더하고(절 추가라 minor) 2.1.0~2.2.1을 ADR 0005·0006으로 소급한 것, 2.3.1은 공개 전환 뒤 CodeRabbit PR 리뷰를 다시 켠 것, 2.3.2는 스택 표의 테스트 행에 pytest-asyncio를 더한 것(ADR 0007)

2.0.0은 파일 분할이다. 원칙 I~V의 문구는 1.6.0과 같다. 1.x 이력은 git과 `docs/journal/`에 있다.
