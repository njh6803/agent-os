# 2026-10-12 (28) design-refresh: 재탐색을 패키지에 옮기는 명세를 쓴다

## 계기

일지 2026-10-12-22의 "다음"이 design-refresh의 명세였다. 결정은 승인된 ADR 0026의 2026-10-12 이력 "테마는 넷이고 색만 바꾸며,
글꼴은 모든 테마가 Noto Sans KR과 Noto Sans Mono를 쓴다"가 다 정했으므로 설계 인터뷰 없이 `/to-spec`으로 시작했다. 지시문의
"어디서"대로 새 세션이 주 체크아웃에서 `tidy-checkouts`를 돈 뒤 워크트리 `design-refresh-spec`에 들어가 브랜치
`docs/design-refresh-spec`을 땄다.

`tidy-checkouts`는 루트를 `030c976`에서 `79a0c19`로 당겼다. 판정에서 지울 후보는 `chore/spec-pipeline-and-pytest-ids` 하나였고,
`remove`가 종료 3으로 멈췄다. 폴더가 옆 이름 `.tidy-probe`로 옮겨진 채 되돌리지 못했다(`WinError 5` 액세스 거부). 규약대로
남은 후보를 치지 않고 사람에게 넘겼다. 분리 HEAD 넷, prunable 하나, 머리가 다른 것 하나, 등록 없는 폴더 여섯도 넘겼다.

## 측정

- **값을 뽑는 프로브.** `design.mjs`는 v3의 `tokJson`만 읽었다. 함수를 나눠 `readRefresh()`(`--refresh`)가 새 파일의 `tokensJson`과
  테마 표, 컴포넌트 표, props 표, 패턴, 아이콘 이름을 내게 했다. v3를 읽는 `setup.mjs`·`measure.mjs`는 그대로 돈다.
- **명암비(`contrast.mjs`).** 디자인 파일 표의 판정 행 값과 프로브의 셈이 모두 같았다. 디자인 파일의 짝 35개는 여덟 벌 모두
  넘었다. 상태 표를 읽고 옮긴 컴포넌트의 짝 가운데 위험 버튼의 누름(`danger`를 `bg-active`에 겹친 바탕 위에)이 다크에서 테마 넷
  모두 미달했다(3.67~4.09). 누름 바탕을 `bg-selected`로 바꾸면 모두 넘었다(가장 낮은 값 4.51).
- **글꼴(`font.mjs`).** `@fontsource/noto-sans-mono` 5.3.0은 OFL-1.1, 예약 글꼴 이름 없음, 설치 스크립트 없음이고, 굵기 CSS가
  Noto Sans KR과 같은 모양(`./files/`, `local()` 없음)이다. google/fonts 사본의 머리는 처음 WebFetch의 요약으로 봤고, PR 직전
  리뷰가 #192의 새 규칙(웹 요약은 근거가 아니다)을 짚어 원문을 `curl`로 받아 손으로 다시 봤다.
- **같은 값(`same-values.mjs`).** 셀프 리뷰가 짚어 더했다. 한 벌이라도 같은 원색을 가리키는 쓰임새 토큰의 짝은 12개이고, 여덟
  벌 모두 같은 것은 `accent`와 `focus-ring` 하나다.
- **읽은 것.** lucide-react 1.51.0 설치본의 `nonScalingStroke`(선을 화면 px로), 변환기(2.1.286 판의 무시된 사본)의 `overrides.<Name>.skip`과
  "폴더마다 첫 `@dsCard` HTML 하나", `DesignSync` 도구 설명의 `@dsCard` 카드.

## 결정

명세를 쓰기 전에 넷을 물었다. 질문에 처음 나오는 개념(props, 명암비, 밀도, 이음매)을 먼저 풀었다.

> 사용자(질문에 답): "모양만 새 디자인 (Recommended)", "누름에 고른 바탕 (Recommended)", "없으면 화면 폭 (Recommended)", "밀도 둘 다 (Recommended)"

컴포넌트 아홉은 모양만 새 디자인을 따르고 props는 지금 계약을 지킨다. 위험 버튼의 누름은 `bg-selected`다. 밀도는
`data-density`가 고르고 속성이 없으면 화면 폭 768px 이상에서 촘촘이다. 이음매는 지금 둘이고 사진은 밀도 둘을 찍는다.

셀프 리뷰의 표준 축이 명세 초안의 `.design-sync/previews/`가 ADR 0026 본문의 "스토리 한 벌이 갤러리, 실제 브라우저 테스트,
Claude Design의 원천을 함께 맡는다"를 바꾼다고 짚었다. 같은 ADR이 갤러리를 따로 만드는 안을 "두 벌"로 거부했다. 그래서 다섯째를
물었다.

> 사용자(질문에 답): "패키지 스토리로 (Recommended)"

보여 주기용 미리보기를 패키지의 스토리로 두고 `/design-sync`의 카드에서 판정용 스토리를 뺀다. ADR의 그 문장이 참으로 남아
ADR 이력은 없다. 기초 카드는 스토리가 될 수 없어 HTML로 두되 값은 CSS 변수로만 읽는다.

명세가 스스로 정한 것은 열여덟이다. 쓰임새 토큰은 디자인 파일의 이름을 그대로(`bg-raised`, `text-muted` 등) 쓰고, 크기의
디자인 토큰은 Tailwind의 숫자 뜻을 지키는 지금 이름 체계를 둔다. 아이콘은 Lucide 그대로 선만 1.5px이다.

## 셀프 리뷰

`/code-review`(기준 `79a0c19`, 표준 축 sonnet). 표준 축은 Major 하나(위의 미리보기)와 Minor 여덟, Nit 다섯이었고, 명세 축은
Major 하나와 Minor 일곱, Nit 하나였다.

- 고친 것: 컴포넌트의 쓰는 법 `<Name>.md` 아홉을 고칠 목록에 넣었다(`/design-sync`가 설명으로 올린다). 짝의 수를 43으로 고쳤다.
  `danger`/`bg`에 겹친 `bg-selected`가 디자인 파일의 짝과 겹쳤다. 프로브도 명세의 43개를 한 번에 내게 묶음을 바꿨다. 기초 카드를
  폴더마다 하나씩 두게 했다. 계산값으로 가를 수 없는 짝을 둘에서 프로브의 12개로 넓혔다(스위치 손잡이는 라이트에서 꺼짐과 켜짐이
  같다). 밀도의 별칭이 `@theme inline`이라 CSS 변수로 나오지 않는다는 것과 사용 규약이 원천 변수를 안내할 것을 적었다. 잔존
  grep의 말을 넓혔다. 서두의 수(다섯, 열여덟), 일지 번호(23~25는 형제 브랜치가 써서 26으로 옮겼고, 커밋 직전에 26도 형제가 가져가 28로 옮겼다), 누름 목표 24px의 출처(ADR 이력), 글꼴의
  손으로 본 근거와 디자인 파일 스택의 반만 맞던 문장, 인용 셋, 패턴·화면의 근거가 v3에서 재탐색 파일로 바뀐다는 것(admin-style과
  web-widget 행), 빠지는 단언 둘(스위치 줄 48px, 여러 줄 입력 88px), `.design-sync`의 구현 파일 경로, 아이콘 굵기의 셈 표시.
  글꼴 프로브가 설치 스크립트도 보게 했다.
- 남긴 것: Noto Sans Mono를 Vite·Next가 실제 파일로 내는지는 재지 않았다. 같은 Fontsource 모양의 Noto Sans KR을 둘 다 냈으므로
  새 결정을 낳지 않는다고 보고 어림으로 적었다. 프로브의 짝이 위치 튜플이라 읽기 어렵다는 지적은 프로브라 두었다.

## PR 직전 리뷰

CodeRabbit CLI는 좌석이 없어(`Seat: not assigned`) 대체 둘을 돌렸다. `/security-review`는 발견이 없었다. `bug-perf-review`는
유효 여덟(Major 하나, Minor 다섯, Nit 둘)을 냈고 모두 고쳤다.

- Major: 위험 버튼 누름의 4.507은 반투명을 겹친 색을 채널마다 정수로 반올림해야 지난다. 반올림 없이는 4.494다. 명세가 반올림을
  말하지 않아, 티켓이 부동소수로 셈하면 판정이 빨개진다. 명세에 반올림을 판정의 일부로 적고, 여유가 0.01도 안 된다는 것을 남긴
  위험으로 적었다. 프로브가 반올림 없이 뒤집히는 자리를 내게 했다(43개 × 여덟 벌 가운데 그 하나).
- Minor: shadow 호스트는 바깥 밀도를 물려받지 않는다(선택자 `:host`가 다시 선언한다). 반투명이 두 겹 겹치는 행 올림 안의 위험
  버튼은 다크에서 미달한다. 판정 범위를 한 겹으로 적고 admin-style 행에 넘겼다. 같은 값의 짝에서 `on-primary` 계열을 빠뜨린 것을
  더했다. 대기열 행 201(main)과 같은 자리에 202를 더해 rebase에서 충돌했고, 201 아래에 두었다. 201은 같은 워크트리의 `.pyd`가
  지워지지 않는 일이라 202와 같은 뿌리일 수 있다고 적었다.
- Nit: 프로브가 대조한 행 수(44)를 내고, 글꼴 프로브가 npm의 오류를 흘리고 `--version` 값이 없으면 멈춘다.
