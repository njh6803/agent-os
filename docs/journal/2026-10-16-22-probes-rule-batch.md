## 어떻게 했나

1. **248은 규칙 문장을 골랐다.** 행의 "어디로"는 `probes.md`의 문장과 `tools/canary.py`의 실행·읽기를 함수로 빼는 것 가운데
   하나를 고르게 한다. 사건의 탐침 `enter_worktree_loading.py`는 턴마다 stdin으로 입력을 보내며 출력을 이어 읽고(`drive`),
   `canary.py`는 `subprocess.run(timeout=…)`이 끝난 뒤 한꺼번에 푼다(그 파일의 `subprocess.run`을 grep으로 봤다). `canary.py`에는
   뺄 이어 읽기 코드가 없어 함수 빼기는 새 설계가 된다. 같은 이어 읽기를 따로 가진 프로브는 더 있다(아래 셀프 리뷰). 그래서 문장을 골랐고, 지시문이 짚은 대로 같은 파일을 든 287(카나리아 명세
   모양 검사)과는 묶지 않았다.
2. **항목의 자리.** `.scratch/token-usage/spec.md`가 `probes.md`의 "둘째 항목"을 번호로 가리킨다. 새 항목을 중간에 끼우면 그
   인용이 다른 항목을 가리키게 되어, 248과 269는 끝에 두 항목으로 더했다. 290은 행이 첫 항목을 짚어 그 안에 넣었다.
3. **290(첫 항목).** "결론은 측정인 회차만으로 낸다" 뒤에 표지를 재려는 상황에서만 나오는 문구로 고르라는 문장을, 197 사례
   뒤에 290 사례를 더했다. `tools/mutate.py` 독스트링의 표지 문단은 이미 `probes.md`의 표지 항목을 가리켜 고치지 않았다.
4. **248(다섯째 항목).** 이어 읽는 탐침의 읽기(줄을 풀어 `type`으로, 읽는 스레드와 큐, EOF 표시 되돌리기, 끝의 배출에도
   제한 시간)와 그 선례(`drive`), 새 `claude -p` 탐침의 첫 갈래를 줄마다 시각을 찍어 먼저 띄우는 것과 사례를 적었다. PR 직전
   리뷰 뒤에 끝없이 기다리지 않고 원본을 잃지 않는다는 일반 조항을 머리에 두고, 풀지 못한 줄, daemon 스레드, stderr를 더했다. 같은 규칙 파일이 "표지"를 출력의
   문구로 쓰므로 큐의 끝 값은 "EOF 표시"라 불렀다.
5. **269(여섯째 항목).** 절대 경로 검사(드라이브 문자는 `uname -s`가 MINGW·MSYS·CYGWIN으로 시작하는 셸에서만), 표지 파일이 있거나 빈 폴더만 지우기, 지우기나
   다시 만들기의 실패에서 멈추기를 적고 선례(`worktree_duplicate_checkout.sh`)를 달았다. PR 직전 리뷰 뒤에 점 파일까지 세는
   빈 폴더 판정, 표지를 심는 순서, `cd` 실패를 더했다. 인자 아래의 고정된 이름만 지우는
   프로브(`import_comments/run.sh`, `pr_head_sync/time_hook.sh`)는 이 항목의 대상이 아니다.
6. **지도.** `docs/agents/issue-tracker.md` 프로브와 근거 절이 규칙 내용을 괄호로 나열해 새 두 항목을 더했다.

   `expect`와 대 보면 커밋 전에 안다. 일지 2026-10-16-19가 기각한 "카나리아 조각(테스트 파일 경로)이 세션에 실리는 git
   상태로 샌다"는 커밋 전 사전 확인이 잡은 바뀐 경로였고, 이번은 그 확인이 볼 수 없는 커밋 뒤의 제목이라 다르다. 되돌림:
   PR 하나. 이 PR의 범위(규칙 문장)를 넘는 도구 변경이라 대기열에 둔다.
2. **기각 — 선례를 가리킨 규칙 문장이 선례 코드의 장치를 빠뜨렸다.** 배출의 제한 시간, MINGW, daemon 스레드, stderr, 풀지
   못한 줄이다. 셀프 리뷰 두 축과 PR 직전 `bug-perf-review`가 차례로 잡았고, 반례를 일반 조항으로 올리는 것은 `code-review`
   6단계 1이 이미 시킨다. 이미 있는 리뷰가 의도대로 잡았다.
3. **기각 — 번호 인용을 피하려고 새 항목을 끝에 두고서, 새 문장에 다른 항목을 번호로 가리켰다.** 셀프 리뷰 표준 축이 잡았다.
4. **기각 — main을 합칠 때 대기열 표 끝에서 충돌이 났다.** `tools/sibling_overlap.py`가 함께 고친 파일로 미리 알렸고, 푸는
   데 행 하나를 대 보는 것으로 끝났다.
5. **기각 — 훅과 검사가 막거나 알린 것.** MSYS의 경로 변환(`origin/main:.scratch/…`), `.env`에 닿는 Grep glob, 일지의 옛 문구
   인용이다. 훅과 검사가 의도대로 잡았다.
