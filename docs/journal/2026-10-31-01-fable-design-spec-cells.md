# 2026-10-31 (01) 설계 인터뷰와 명세 칸을 Fable 5.1 / xhigh로 바꾼다 (harness 030)

다시 풀기 본 측정을 돌리던 세션(제목 `feature/12-main-run`, 워크트리 `12-main-run`, 브랜치 `feature/13-main-run-judge`)이 곁 세션으로 연 세션이다. 주 체크아웃에서 시작해 `EnterWorktree`(이름 `fable-design-spec`)로 들어가 티켓 030을 쓰고 브랜치를 `chore/030-fable-design-spec-cells`로 바꿨다. 기준은 `origin/main` `c18619bb`(PR #437 병합)이다.

> 사용자(그 세션에서): "설계 인터뷰와, 명세 작성에 사용할 모델을 Fable5.1 xhigh으로 바꿔죠."

그 세션이 사용자에게 짚은 것(그 세션의 과제 배경 요지): 공식 문서는 Fable 5.1을 아키텍처 결정처럼 모호한 문제에서 더 조사하고 검증하는 모델로 적는다. 명세와 설계의 실수는 뒤 티켓 전체로 퍼지지만 세션 수가 적어 비싼 모델의 몫이 작다는 판단(측정 아님). 단점은 단가 2.5배, 느림, 크레딧 동의가 첫 턴을 멈출 수 있음(ADR 0029).

## 사용자 결정: 이어받는 세션도 Fable

셀프 리뷰가 낸 갈래(끊기거나 인계된 설계·명세 세션이 Opus로 열린다)를 초안과 함께 곁 세션을 연 세션에 보냈고, 그 세션이 사용자에게 물어 답을 전했다. 초안을 그대로 승인한 것이 아니라 고친 초안을 다시 승인받는다.

> 질문: "설계 인터뷰나 명세 세션이 도중에 끊기거나(컨텍스트가 차서 새 세션으로 넘길 때 포함) 다시 열릴 때, 이어받는 세션은 어떤 모델로 열까요? 지금 초안은 사용자가 말한 두 칸만 바꿔서, 이어받는 세션은 예전처럼 Opus 5.5 / xhigh 로 열립니다."
>
> 사용자: "이어받아도 Fable 로" — "설계·명세 세션을 이어받는 세션도 Fable 5.1 / xhigh 로 엽니다. 처음 세션과 이어받은 세션의 모델이 같아집니다. 결정표의 '끊는 줄', '같은 주제가 남았다' 줄, 인계 파일(handoff.md)에 '설계·명세면 Fable' 조건을 더해야 해서 고칠 곳이 늘어납니다. 열린 PR 의 반영·병합만 남은 경우는 지금처럼 Sonnet 5.5 / high 로 둡니다."

고르지 않은 선택지는 "초안대로 승인"이었다.

고친 것: 결정표의 끊는 줄("끊는 세션의 다음 단계가 설계 인터뷰나 명세면 `Fable 5.1 / xhigh`. 어느 쪽이든 남은 것이 PR 반영·병합뿐이면 `Sonnet 5.5 / high`"), "같은 주제가 남았다" 줄("그 PR이 설계 인터뷰나 명세였으면 `Fable 5.1 / xhigh`"), `handoff.md` 인계 줄의 모델 항목, ADR 이력의 결정문·범위 문장·결과 항목, 티켓의 What to build와 수용 기준. 잔존: `.scratch/token-usage/spec.md`는 티켓 아홉이 모두 done이라 기록이고, ADR 0029 이력 2026-10-20의 인계 줄 인용은 지난 이력이라 두었다.

## 추가분 셀프 리뷰

세 자리를 고친 뒤 서브에이전트 하나(sonnet·high)로 추가분만 다시 봤다.

- 고친 것: 끊는 줄의 "끊는 세션의 다음 단계"가 그 줄의 "다음 단계" 열 값(`이어서`)으로 읽힐 수 있다(Major). 세 자리의 조건을 모두 지시문의 "다음 단계" 칸(`directive.md`의 다섯 값)으로 고쳤다. 끊는 줄의 Fable 절이 스윕에 덮일 수 있다(Major). 설계·명세 브랜치 `docs/<slug>`는 스윕 밖이라(`uv run python tools/model_sweep.py docs/foo-spec`이 `스윕 밖`, 서브에이전트가 돌렸다) 덮이지 않지만, 끊는 줄에 그 괄호를 적었다. ADR 결과의 "세 자리 모두 다음 단계를 지시문에서 읽으므로"의 반례(같은 주제 줄이 PR 종류를 읽는다, Minor)는 위 고침으로 없어졌다.
- 남긴 것: 열린 PR이 있는 설계·명세 세션의 인계가 Sonnet으로 열리는 것(사용자 선택의 "반영·병합만 남은 경우"대로). "같은 주제가 남았다" 줄이 설계·명세에 거의 닿지 않는 것(사용자가 고치라고 한 자리라 조건만 맞췄다). ADR 0029 이력 2026-10-20의 인계 줄 서술(지난 이력이라 기록).
- 다시 돌린 것: `tests/tools/test_open_session.py`·`test_hook_handoff.py`·`test_canary.py` 440 통과, `tools/check_adr_pointers.py` 종료 0, 카나리아 `next_session_fable_cut_row.toml` 통과 4(claude 2.1.312).
