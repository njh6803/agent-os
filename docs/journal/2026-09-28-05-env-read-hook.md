## 반영

- **43 `tools/hook_env_read.py`**(PreToolUse `Bash|Grep`). 막는 모양 셋 — 읽는 명령의 인자에 `.env` 파일(cat·grep·sed·head·
  tail·less·rg에 tac·awk·cut·diff·paste·source 등을 더했고, `bash -c`·`eval`·`$(…)`·백틱·`<(…)`·`find -exec`·`git diff` 안도
  한 겹씩 본다), 입력 리다이렉션 `< .env`, `.env`를 빼지 않은 저장소 전체 grep(`grep -r`이 경로 없이·`.`·`..`·절대 경로·`$PWD`,

`.env*`는 읽는다. 가짜 파일은 지웠다. Bash 도구에서 `echo $CLAUDE_CODE_NEW_INIT`이 사용자 설정 `env`의 값을 보였다.

## 적대 검증 워크플로

렌즈 넷(훅이 놓치는 읽기, 훅의 오탐, 독스트링 주장, 인용 대조 논리)에 지적마다 반박자 하나 — 에이전트 49, 확정 45, 기각 0.
기각 0은 반박자가 너그러웠다는 뜻도 된다(겹치는 지적 열 쌍이 따로 확정됐다). 그래도 알맹이는 실제였다.

- **훅 파서의 구멍 열둘.** 리다이렉션 토큰(`2>/dev/null`, `> hits`)이 경로로 세어져 경로 없는 grep이 통과, 저장소 루트를 절대
  경로·`$PWD`·`../..`로 주면 하위 디렉터리 취급, `if …; then cat .env` 같은 예약어 뒤, 백슬래시 줄 이음, `bash -c`·`eval`,
  `find -exec`, `diff`·`paste`, `rg -u` 하나, `-rC3` 같은 숫자 붙은 옵션 묶음, `\grep`·`/usr/bin/cat`·`timeout`, `$PWD/.env`
  리다이렉션. 정규식 파서를 버리고 shlex(`punctuation_chars`)로 토큰을 나눠 다시 썼다.
- **오탐 아홉.** 패턴 인자 `.env`를 파일로 봄(`grep .env .gitignore`), 인용 안의 `|`가 분리자(`grep -rE 'a|b' src/`가 전체
  훑기), `--include=*.py`·`-t py` 좁힘, 출력 리다이렉션 `cat x > .env`, 메시지 문자열 안의 `< .env`, `--exclude .env` 공백형,
  `--no-ignore-messages`. 패턴 위치 인자 제외, fnmatch 좁힘 판정, 리다이렉션 대상 분리로 풀었다.
- **주장 셋.** `grep -r KEY *`는 셸이 점파일을 빼서 훑기가 아니다(테스트와 독스트링을 고쳤다), 절대 경로 루트가 "못 보는 것"에
  없었다, 테스트가 "못 보는 것" 주장을 재지 않았다(묶음을 더했다).
- **인용 대조 열.** 생략 인용의 조각을 인용 파일 자신에서 찾아 영영 경고하지 않던 것, ADR 60자 창이 무관한 인용을 끌어가던 것,
  한 줄에 ADR 둘, 코드 스팬의 홑따옴표 하나가 줄의 인용을 지우던 것, 네 백틱 펜스와 닫히지 않은 펜스, 목록 안의 `- > `,
  추적되지 않은 새 파일의 자기 자리, 줄바꿈을 넘는 인용(못 보는 것에 적음).

## 갈린 곳

- **Grep 매처.** 행은 Bash만 말했다. Grep 도구가 경로·glob으로 `.env`를 읽는 것을 재고 넣었다. 매 Grep 호출에 훅 하나(약 0.2초).
- **`.`은 언제나 루트.** `cd src && grep -r x .`는 오탐이다. cwd를 조각마다 알 수 없어 보수 쪽을 택했다. 독스트링과 PR에 적었다.
- **스테이지 줄만.** 행은 "바뀐 문서에서"다. 파일 전체의 옛 인용이 경고를 무시하게 만들 것이 뻔해(hook_journal_retro의 교훈)
  좁혔다.
- **40의 훅 쪽.** 재지 못했고 재지 못했다고 적었다. 다음 세션이 주 체크아웃에서 훅 하나에 계측을 넣어 재면 tools.md 문장이 준다.
- **사용자 설정의 토큰.** 설정 `env`를 확인하느라 `~/.claude/settings.json`을 읽었고 그 `env`에 든 GitHub 토큰이 도구 출력에
  실렸다. 값은 어디에도 옮기지 않았고 회전은 사용자 판단으로 남겼다. 이 훅의 "못 보는 것"(`.env` 밖의 비밀 파일)이 같은 세션에서
  실제가 됐다 — 회고 후보다.

## 번복하거나 고친 것

- 첫 훅은 정규식 조각 파서였다. 워크플로가 구멍 열둘을 내 shlex로 다시 썼다. `_ROOTISH`에 `*`를 넣었다가 뺐다.
- 인용 대조를 라이브러리로 부르면 경고 셋이 나오는데 CLI로 부르면 0건이었다 — 상대 경로로 넘어온 파일이 절대 경로 키와 다른
  키로 corpus에 한 번 더 들어가 모든 인용이 두 번 세어졌다. 검사가 조용히 비는 모양이라 키를 resolve하고 회귀 테스트를 두었다.
- 스테이지 diff가 비면 빈 집합으로 했다가 None(전체)으로 되돌렸다. 손으로 넘긴 파일이 조용히 안 보이는 쪽이 더 나쁘다.
- Grep 도구가 훑을 때 숨김 파일을 건너뛴다는 첫 독스트링의 주장은 glob이 없을 때만 참이었다. 명세 축이 짚어 다시 재고 fnmatch로
  막았다.
- 가짜 `.env`를 만들어 재고 지운 것이 두 번이다.
