## 어떻게 했나

1. **이 티켓이 정할 것 1: 헤드리스 세션을 가르는 길.** 프로브(`.scratch/token-usage/probes/session_start_payload/`)로 두
   갈래의 SessionStart 페이로드와 환경을 저장했다. 데스크톱 세션의 Bash에서 띄운 `claude -p`와, 터미널 패널에서 워크트리
   폴더로 띄운 대화형 `claude`(시작 화면이 뜨자 프롬프트 없이 껐다)다. 페이로드에는 가를 칸이 없었다(`model`이 헤드리스에만
   없었지만 데스크톱 세션의 페이로드는 재지 못했다). 대신 `CLAUDE_CODE_SESSION_ATTENDED`가 헤드리스 `0`, 대화형 `1`로
   갈렸고, 헤드리스는 부모 세션의 `1`을 물려받지 않았다. 실행 파일(2.1.295·2.1.300)에서 그 값을 정하는 코드를 찾아
   (`cli_attended.py`) 셸 도구와 훅이 같은 함수로 환경을 짓고 그 값이 "대화형이거나, 자식 세션이 아니면서 진입점이
   데스크톱·VS Code 같은 목록에 있다"라는 것을 확인했다. 그래서 명세의 두 갈래(페이로드의 칸, 카나리아의 표지 변수) 대신
   이 변수로 갈랐다. 카나리아뿐 아니라 세션 안에서 띄운 모든 `claude -p`가 헤드리스로 갈리고 `tools/canary.py`를 고치지
   않았다. 셀프 리뷰의 명세 축이 이것을 명세의 결정을 승인 없이 바꾼 것으로 짚어, 사용자의 선택으로 카나리아의 표지 변수도
   더했다(아래 "사용자의 선택"과 "명세 축의 반영"). 데스크톱 세션의 훅이 받는 값은 훅으로 재지 않고 코드와 그 세션의 셸 값으로 셈했다. 실제로 요약이 보이는지는
   09가 본다.
2. **이 티켓이 정할 것 2: 표지.** 출력 폴더 아래 `shown/summary-<보고서 날짜>`, 낡은 요약은 `-stale-<지역 날짜>`를 더한다.
3. **계정.** 계정 ID가 없으면 이메일도 버린다. 읽는 쪽(02)이 `account_uuid`가 null인 줄을 "읽지 못한 줄"로 보기 때문이다.
   장부는 쓰기 한 번으로 덧붙이고, 윈도에서는 `O_BINARY`로 열어 줄 끝을 LF로 둔다(첫 판은 바이트로 쓰면 LF라고 보고
   `O_BINARY`를 빠뜨렸다. 셀프 리뷰가 잡았다, 아래).
4. **러너.** 자리표시자 둘(`${USAGE_REPO}`, `${USAGE_HOME}`)을 더하고, 자식 환경에서 `CLAUDE_CODE_SESSION_ATTENDED`를
   벗긴다. 벗기지 않으면 `claude -p` 세션의 커밋에서 발동 사례가 침묵으로 어긋난다. 표에는 헤드리스 시작(침묵), 대화형 시작
   (알림), 이어 하기(침묵) 셋을 그 차례로 둔다. 헤드리스가 표지를 가져가면 뒤의 알림 사례가 빨개진다.
5. **변이.** `.scratch/token-usage/probes/session_usage_hook_mutations.toml`의 열아홉. 첫 실행에서 열셋 모두 빨갰지만
   여섯이 "어긋남"이었다. 변이 도구가 pytest를 첫 실패에서 멈추는데 표지에 시험 이름 둘을 적어서다. 표지를 첫 실패 시험으로
   고치고, CLI 시험 하나로 좁혀 그 시험도 잡는지 보는 변이 여섯을 더해 열둘을 다시 돌렸다. 모두 기대대로였다. 셀프 리뷰를
   반영하며 셋(텍스트 모드, 장부 쓰기의 예외, `cwd`를 먼저 보기)을 더해 스물둘이고, 더한 셋도 기대대로였다.
6. **시간.** 래퍼를 거쳐 0.5~1.3초였다. 같은 때 대조로 돌린 `guard_hooks_time.py`도 기록의 두 배쯤이라 이 PC가 바빴다.
   git 한 번이 63~85ms, 18만 바이트 JSON 풀기가 1ms 미만이었다. `.claude/rules/tools.md`의 시간 목록에 더하고, 그 문단을
   원천으로 든 카나리아 `tools_rule_session_hooks.toml`에 새 조각을 더해 통과 4를 봤다.
7. **런북.** `KICKOFF.md` 7단계의 `.claude/settings.json` 항목에 이 등록은 복사하지 않는다는 것과 SessionStart 매처의
   주인을 적었다.
