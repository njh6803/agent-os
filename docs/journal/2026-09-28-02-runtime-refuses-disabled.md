## 이 티켓이 정한 것

일지 01의 "다음"이 넘긴 둘(메시지 모양, `ports.py`의 미래형 문장)을 포함한다. 전부 티켓 파일 끝에도 적었다.

1. **메시지 모양.** `꺼진 플러그인이다: {종류} {이름}`. mcp 때문이면 `(에이전트 {이름} 이 쓴다)`가 붙는다. 종류를 붙인 것은
   에이전트와 mcp가 같은 이름일 수 있어서이고, 괄호는 운영자가 어느 에이전트 때문에 그 mcp를 켜야 하는지 알게 하려는 것이다.
   재개의 409는 실행 식별자를 싣지 않는다.
2. **판정은 `_prepare` 안의 한 줄이다.** mcp 해석과 마스킹·승인 충돌 뒤, 진입점 로드 앞에서 꺼진 집합을 한 번 읽는다.
   `run()`과 `resume()`이 같은 준비를 거치므로 두 진입점에 따로 넣지 않았다.
3. **PUT → 409 흐름은 채널 테스트에 둔다.** 채널의 가짜 플러그인 포트가 켜짐 쓰기를 얻었다. 관리 테스트의 가짜는
   `load_agent`가 없어 실행을 일으키지 못한다.
4. **CLI `resume` 테스트는 다시 켜서 이어 가는 것까지 재지 않는다.** core와 HTTP 주 이음매가 잰다.

## 번복하거나 고친 것

- CRLF가 된 두 파일을 바이트로 되돌렸다. 이어서 `grep -c $'\r'`이 이 셸에서 모든 줄을 세어 CR이 남은 것처럼 보였고,
  파이썬으로 바이트를 세어서야 0임을 확인했다. 환경 함정 "검사 도구가 내가 생각하는 것을 실제로 봤는지"의 가족이고 1회차라
  여기에만 둔다.
- PR 본문을 76줄 heredoc으로 넘기다 훅(상한 40줄)에 막혀 Write로 파일을 쓰고 경로를 넘겼다. 훅이 제 일을 했다.
- `cd`를 붙인 명령 하나가 세션의 작업 디렉터리를 주 체크아웃으로 옮겼다. 다음 명령에서 워크트리로 돌아왔다.
