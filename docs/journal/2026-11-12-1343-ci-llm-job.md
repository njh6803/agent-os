## 고치지 않은 것, 새 세션에 넘기는 의심

- 티켓 수용 기준 7번 "검증 명령이 모두 초록이다"에 체크를 넣었으나 위대로 `run_checks`를 보지 못한 채다. 새 세션이 돌려 초록이 아니면 체크를 되돌린다.
- 셀프 리뷰(`/code-review`)는 하지 않았다. 새 세션이 한다. PR 직전 리뷰에 밀 주장으로 넘길 후보는 아래다. `ci.yml`의 `llm` 잡 위 주석은 "needs 에 이으면 dev 로 가는 PR 에서 건너뛴 이 잡을 verify 가 빨강으로 본다"고 적었다. 이 문장의 근거는 `verify` 위의 기존 주석(건너뛴 잡은 빨강, 332~333행의 옛 번호)이고 이 세션이 건너뛴 잡을 실제로 돌려 본 것이 아니다(코드를 읽은 것).
- 건너뛴 잡이 `verify`의 `filter=all` 잡 목록 조회에 나오는지는 본 적이 없다(어림). 나오지 않으면 `llm`을 예외에 둔 것은 아무 일도 하지 않고, 나오면 예외가 필요하다. 어느 쪽이든 동작은 같다.
- 위 "돌려 본 것"의 근거 종류: zizmor와 pytest와 ruff는 이 세션이 Bash로 돌려 출력을 본 것이다(손으로 본 것). YAML 구조는 `uv run python`으로 읽어 찍은 것이다. 시크릿이 저장소에 있다는 것은 사용자의 답이고 이 세션이 GitHub에서 확인한 것이 아니다.

## 셀프 리뷰 (이어받은 세션, base 4b02bbe29, 수정 3 + 미추적 1, 커밋 0)

표준 축은 `sonnet`·`high`, 명세 축은 세션 모델로 돌렸다.

고친 것.
- 헌법 판을 3.0.87에서 3.0.88로 올렸다(`docs/constitution/README.md`). `operations.md`의 규칙 문장을 바꾼 문구 수정이라 patch다. 앞의 PR #541이 같은 종류에 3.0.87을 매겼다(표준 축의 하드 위반).
- 티켓 "결과"의 "질문 페이지 빌드가 더 들어서 뺐다"를 지웠다. 근거를 찾지 못한 어림이었다. 뺀 까닭은 ADR 0043이 꼽지 않았다는 것 하나다.
- `ci.yml` 머리 주석의 "잡을 더하면 verify 의 needs 에 넣는다"에 참고 모드 `llm`만 예외라는 말을 달았다. `verify` 위 주석의 어색한 줄바꿈도 고쳤다.

남긴 것.
- ADR 0058 8행의 "실제 모델 시험은 지금 셋이고 모두 손으로 돌리며 CI는 돌리지 않는다"는 고치지 않았다. 그 ADR을 쓴 때(2026-11-11)의 서술이고 ADR 0043 Consequences가 이미 CI 분담을 예고했다. ADR 본문과 이력은 사용자 승인 몫이라 이 PR에서 건드리지 않는다.
- `llm` 잡의 설치 스텝이 `e2e-widget`의 복사본이다(Duplicated Code 판단 항목). 재사용하려면 composite action이 필요한데 이 티켓의 범위가 아니다.
- 같은 저장소 PR이 main으로 갈 때 PR 코드가 키를 받는 위험은 협업자만 PR을 열 수 있는 범위로 받아들였다(키는 스텝 env에만 있고 `persist-credentials: false`).
- 건너뛴 `llm` 잡이 `verify`의 잡 목록 조회에 어떻게 보이는지는 jq 입력 경계(목록에 있을 때·없을 때·needs에 있을 때·엉뚱한 잡)로만 봤다. 네 경우 모두 기대대로 나왔다(두 축이 각자 jq 1.8.1로 돌렸다). 실제 API 응답은 첫 dev→main PR에서야 본다.
- 수용 기준 2·6번의 체크는 코드를 읽어서 한 것이다(실행으로 본 것이 아니다). 티켓 "결과"가 이미 그렇게 밝혔다.

다시 돌린 것. `uv run ruff check .`와 `uv run ruff format --check .`는 통과했다(손으로 본 출력). `uv run python tools/run_checks.py`는 종료 코드 0이고 pyright·pyright-linux·lint-imports·pytest·web-verify·zizmor 등이 모두 Passed였다(출력 끝 줄을 손으로 봤다). 이 실행은 리뷰 반영(주석 두 곳, 티켓 한 문장, 헌법 판 숫자) 앞에 시작했으므로 반영 뒤의 판정은 커밋의 pre-commit 결과로 갈음한다. 티켓 수용 기준 7번의 체크는 이 결과로 유지한다. `uv run python tools/sibling_overlap.py`는 번호 겹침 없음을 냈다(헌법 3.0.88). 함께 고친 파일 후보는 워크트리 `dev-release-pr-step`의 `docs/constitution/operations.md`다.
