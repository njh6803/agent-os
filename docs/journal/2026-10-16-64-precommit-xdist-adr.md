# 2026-10-16 (64) pre-commit의 pytest를 xdist로 나눠 돌리는 결정

주 체크아웃의 세션에서 시작했고, 사용자의 질문 하나가 설계 인터뷰(`grill-with-docs`)로 이어졌다. 산출물은 ADR 0035 초안(상태

## 시작: 작업하는 세션이 있는가

없었다(손으로 봤다). `git worktree list`의 마흔 곳 남짓에 xdist나 pytest 속도를 가리키는 이름이 없었고, 열린 PR은 #272(ruff FBT 규칙)
하나였다. 실행 중이던 세션 다섯(`feature/04-session-start-hook`, `feature/07-review-axis-and-plugins`,
`feature/03-remaining-metrics-and-weekly-reports`, `docs/mcp-shutdown-spec`, `chore/hooks-push-help-and-commit-lock`)은 제목과
브랜치로 다른 일이었다. 트랜스크립트 검색에서 `xdist`와 "11.5분"이 여러 세션에 걸렸지만 대기열 행을 읽어 찍은 흔적이었다.
열린 행은 대기열 309(사용자 승인 2026-10-16, 일지 2026-10-16-36)였다.

> 사용자: "관련해서 인터뷰 하자." (다른 저장소의 대화를 붙여 넣었다. 그 부분은 옮기지 않고, 그 저장소를 열지도 않았다.)

붙여 넣은 글이 다른 저장소의 지시문이고 pre-commit 속도 이야기가 없어, 주제부터 물었다.

## 셀프 리뷰

`/code-review`의 두 축(base `c689c9ce`, 커밋 0, 바뀐 파일 22개, 미추적 0). 표준 축은 sonnet·high로 돌렸다.

**표준 축.** Critical·Major 없음, Minor 넷, 판단 항목 일곱. ADR의 수치(688.33초, 192.32초 등 서른 남짓)는 모두 원본과 맞았다.

- [Minor] `probes.md` 첫 항목: 한 바퀴 프로브가 xdist가 떴다는 표지를 단언하지 않았고, "자동(16개)"의 16개는 어느 원본에도 없었다. 고쳤다.
  `pytest_run.py`를 새로 지어 통과 집계 줄과 xdist가 뜬 줄, 프로세스 수(`created: N/N workers`)를 단언하게 하고, `rounds.py`와
  `pair.py`가 그것을 거친다. 이 PC에서 자동은 16개였다(`skip_under_xdist.py`와 `round_xdistauto`의 `workers`).
- [Minor] ADR 0035가 ADR 0005의 이력이 "검사 여덟"을 적었다고 했는데 0005는 "일곱"이다. 고쳤다.
- [Minor] `issue-tracker.md` 19: "측정은 프로브가 다시 낸다"가 손으로 돌린 수까지 덮었다. 종류를 갈라 고쳤다. 손으로 돌린 것은 명령과
  함께 적었고, 세 수(688.33초, 192.32초, 3254개)를 빼고는 프로브가 다시 낸다.
- [Nit] "FAQ 원문을 브라우저에서 읽었다"는 "손으로 읽었다"가 맞다. 고쳤다. ESLint 문장은 web verify 쪼개기 항목에 섞였던 것을 따로
  뺐다.
- [판단·고침] 과잉 해석("가장 빠른 8", "자동이 가장 느렸다"): 6~12개의 한 바퀴가 구별되지 않아 8을 가장 빠르다고 고른 것이
  아니라고 고쳤다. Duplicated Code(한 바퀴 프로브 둘, 여섯 단계 목록 셋)는 `rounds.py` 하나와 `STEPS` 하나로 합쳤다. Mysterious
  Name(`COMMON`, `TEXT`, `_round`, `swapped`)은 이름을 바꾸거나 없앴다. 스타일 불균일은 모두 `main()`으로 맞췄다. 굵은 결정문 하나에
  결정 여섯이 든 것은 목록으로 나누고 xdist와 논리 CPU를 풀어 썼다.
- [판단·고침] 취약한 식별: `check_ci`가 pytest 단계를 `ulimit -c unlimited` 줄로 찾는다. 이유를 주석으로 적었고, 원본 JSON을 저장해
  시각에서 직접 계산하게 했다.

**명세 축.** Critical·Major 없음, 빠진 것 셋, 범위 넘침 하나, 틀려 보이는 것 열둘.

- [빠짐·고침] 대기열 309가 먼저 재라던 "같은 파일·포트·`pwsh`"를 ADR이 말하지 않았다. 「부딪힘」 절을 더했다(파일, 포트, `pwsh`, 시간,
  회차). ADR 0021과 0005가 xdist를 "다시 본다"며 미룬 약속을 잇는다는 말도 더했다.
- [빠짐·고침] 합의("걸리면 그 테스트만 고친다")를 ADR이 `test_filesystem`에서만 물렸다. "사례만 고쳐서 되는지 구현에서 보고 운영 코드를
  고쳐야 하면 그때 사용자에게 묻는다"로 고쳤다.
- [범위 넘침·고침] ESLint `--cache`는 합의에 없던 안이 web verify 항목에 섞였다. 사용자 물음(캐시)에 답한 근거라 별도 항목으로 뺐다.
- [틀림·고침] "시간이 늘어나는 기울기를 바꾸지 않는다"는 자체 측정과 어긋난다. 기울기는 줄고 늘어남은 남는다고 고쳤다. "전체가 고르게"는
