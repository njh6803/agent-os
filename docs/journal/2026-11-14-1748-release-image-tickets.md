## PR 직전 리뷰(coderabbit-review)

CodeRabbit CLI 0.7.5가 `coderabbit review --agent --committed --base dev`로 문서 14개를 끝까지 봤다(`review_completed`, `Seat: not assigned`, `Plan: Free`). 지적 4건을 서브에이전트가 유효 1, 보류 1, 오탐 2로 나눴다.

- 유효 Minor. 명세 "실패한 판을 다시 돌리는 길"에서 번호 태그 뒤에 실패한 판을 사람이 남긴 초안으로 공개하는 절차에, 초안의 자산이 다 있는지 보는 단계가 없다. 사전 확인이 앞 초안을 지우고 새로 만들었거나 자산 올리기 도중에 끊겼으면 일부만 있을 수 있다. **고친다.**
- 보류 Minor. 반영 단계에서 새로 쓴 문장(둘째 잡이 받은 아티팩트의 대조에서 실패했으면 초안도 번호 태그도 없다)은 첫 시도에서만 참이다. 둘째 잡만 다시 돌린 회차가 이 대조에서 실패하면 앞 회차가 남긴 초안과 번호 태그 일부가 있을 수 있다. 서브에이전트는 드문 길이라 보류했지만 이 세션이 새로 쓴 사실 문장이 틀린 것이라 **고친다.** 셀프 리뷰 반영으로 새로 쓴 문장을 PR 직전 리뷰가 잡은 사례다(대기열 260과 같은 꼴, 회고 후보).
- 오탐. 04가 `pyproject.toml`을 제품 경로에 넣지 않은 것(명세 "제품 변경의 경로 목록"이 거부한 안으로 적었다), 07의 판 번호가 PEP 440 정규화로 어긋난다는 것(명세 "이미지의 구성"이 세 값이 글자까지 같았다고 쟀고, 07이 다시 돈다).
