# 지침은 로드 시점 기준으로 배치한다

로드 시점은 셋이다. 항상(`CLAUDE.md`, `@` 임포트, `paths` 없는 `.claude/rules/*.md`), 해당 파일을 열 때(`paths` 있는 rules), 필요하다고 판단할 때(skill). 마크다운 링크는 로드되지 않는다. 파일을 쪼개거나 하위 폴더로 나눠도 임포트하면 분량은 같다. 첫날 헌법을 한 파일 161줄로 키워 통째로 임포트했고, 2026-09-20에 원칙과 거버넌스만 임포트(28줄)하고 스택·운영은 경로와 "언제 읽나"로, 디렉터리 규칙은 `.claude/rules/`로 옮겼다. 항상 실리는 줄이 190에서 112로 줄었다. 줄 수는 토큰의 대리 지표일 뿐이라 `/context` 실측은 아래에 적는다.

분류 기준. 지침을 더할 때 같은 기준을 쓴다.

| 성격 | 어디에 |
|---|---|
| 린터·타입체커·훅이 판정할 수 있는 것 | 도구 설정. 문서에는 실행 명령만 |
| 특정 디렉터리·파일 패턴에만 해당 | `.claude/rules/*.md` + `paths` |
| 순서 있는 다단계 절차 | `.claude/skills/` |
| 가끔 참조하는 자료 | `docs/` + 마크다운 링크 + "언제 읽나" |
| 매 세션 필요 | `CLAUDE.md`. 넣기 전에 "이 줄을 지우면 실수하게 되나". 코드에서 유추 가능한 것은 넣지 않는다 |
| 반드시 실행되어야 하는 것 | 문서가 아니라 훅. 문서는 강제력이 없다 |

이 기준은 선행 저장소에서 2026-09-01 AAPP-15로 한 번 겪은 것이다(`ai-agent-platform/docs/setup-prompts/06-context-load-timing.md`). 런북이 이것을 처음부터 담지 않아 같은 일을 두 번 했다. 런북 3단계에 넣었다.

## Consequences

- `/context` 실측(사용자가 직접 실행해 붙여 넣은 값만 적는다. 추측하지 않는다): 재배치 전 미기록. 재배치 후 (대기).
- 옮긴 것과 근거는 `docs/journal/2026-09-19-kickoff.md`의 "헌법 분할과 CLAUDE.md 재편" 절.
- 삭제한 것: 헌법의 디렉터리 트리(현재 구조는 코드가 진실, README에만), 검증 명령 중복(CLAUDE.md에만).
- 훅으로 옮긴 것: 없음. 이미 pre-commit이 검사 넷을 돈다.

## 이력

### 2026-09-29 로드의 계기는 Read이고, 항상 실리는 것에 빠진 것이 있었다

공식 memory·large-codebases 문서와 `claude -p` 2.1.281 실측(`InstructionsLoaded` 훅 로그)으로 쟀다. 일지
2026-09-29-03·04.

- **"해당 파일을 열 때"는 Read 도구로 읽을 때다.** Bash(`cat`·`sed`), Grep, Glob, Write(새 파일)로는 `paths` 규칙도
  하위 디렉터리의 CLAUDE.md도 실리지 않는다. 이 저장소의 세션도 `tools/*.py`를 `cat`으로 읽는 동안 `tools.md`가
  빠져 있었다. `CLAUDE.md` 지도와 런북에 Read 도구로 열 때 실린다고 적었다.
- **항상 실리는 것에 빠진 것이 셋이다.** 모델이 부를 수 있는 스킬의 description(한 항목 1,536자), 자동 메모리
  `MEMORY.md`의 앞부분(200줄 또는 25KB), 켜 둔 MCP 서버의 도구 이름과 서버 지침이다. 위 첫 문단의 "셋"은 런북의
  "넷"(훅의 계기)과도 어긋나 있었다.
- **중첩 CLAUDE.md를 쓰지 않는다는 배치는 그대로다.** 공식 문서는 중첩 CLAUDE.md와 `paths` 규칙을 나란히 두고
  기준을 소유권으로 든다. 디렉터리마다 소유자가 제 규약을 유지하면 중첩 파일, 규약을 한곳에 모으면 `paths`
  규칙이다. 한 사람이 규약을 모으는 이 저장소는 후자다. 로드 시점은 둘이 비슷하고, 다른 점은 중첩 파일 안의 `@`
  임포트가 루트 지침에 거는 검사(줄 수, 임포트 허용 목록) 밖에 놓인다는 것이다. 디렉터리마다 소유자가 갈리면
  다시 본다.
- **`/context` 실측.** 사용자가 2026-09-29에 붙여 넣은 값이다. Memory files 6.5k, Skills 9.4k, MCP tools 12.6k(지연
  로딩분 125.3k는 맥락 밖), System tools 20.2k, Messages 658.3k(맥락의 66%). Memory files는 그 세션에 실린 rules를
  포함한다. 위 Consequences 첫 줄의 "재배치 후 (대기)"가 이 값이다.
