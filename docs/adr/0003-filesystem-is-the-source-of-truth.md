# 플러그인의 진실의 원천은 파일시스템이다

관리 화면이 생기면 "등록"이 어디에 기록되느냐가 문제가 된다. `plugins/` 디렉터리와 매니페스트를 유일한 원천으로 두고, 관리 API와 화면은 그 파일을 읽고 쓰는 클라이언트로 만든다. DB는 색인과 권한에만 쓴다. 선행 저장소 둘은 DB 레지스트리부터 시작해 화면과 마이그레이션이 실행 루프보다 먼저 자랐다. 파일이 원천이면 화면이 없어도 시스템이 돌고 git이 이력을 가진다. 멀티테넌시는 테넌트별 `plugins/` 루트로 시작한다.
