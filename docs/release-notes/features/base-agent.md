기본 플러그인 루트에 문서에 관한 질문에 출처를 달아 답하는 기본 에이전트 `assistant`가 더해졌다. 문서 검색 서버를 가리키는 연결 `doc-search`의 주소는 매니페스트의 `url`에, 인증 값은 환경 변수 `DOC_SEARCH_AUTHORIZATION`(`Bearer <토큰>` 꼴)에 둔다. `assistant`는 먼저 검색해 찾은 내용으로만 답하고, 근거가 없으면 정해진 한 문장으로 답한다. 답에는 문장 끝 번호와 출처 목록이 붙는다. 문서 전문을 읽는 호출은 규칙 파일의 `assistant` 표에 따라 승인을 묻는다. 에이전트 매니페스트에는 선택 칸 `max_turns`와 `max_tool_calls`가 더해졌고 `assistant`는 6과 4로 적었다.
