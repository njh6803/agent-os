# adapters 규칙

- 어댑터는 core가 선언한 포트 Protocol을 상속하지 않는다. 시그니처로 만족한다. 드리프트는 테스트 픽스처의 포트 타입 annotate가 잡는다(`.claude/rules/tests.md`).
- 파일, DB, 외부 서비스, 시계에 닿는 코드는 여기에만 산다. core로 새면 원칙 IV 위반이다.
- 어댑터의 import 경계는 `pyproject.toml`의 `[tool.importlinter]` 계약이 원천이다(어댑터는 HTTP 표면이 아니다, ADR 0016). 조립은 `main.py`와 `server.py`가 한다.
- 첫 슬라이스의 어댑터: JSONL TraceStore(`traces/<run_id>.jsonl`, 첫 줄 헤더에 `schema_version`. 새 파일은 형식 3으로 쓰고 형식 1·2·3 파일을 읽으며 한 실행을 쓴 순서대로 돌려준다(ADR 0022). 재개는 헤더를 다시 쓰지 않아 형식 2 파일에 이어 쓴 뒤에도 헤더는 2다. 형식 목록에 없는 버전은 헤더에서 파일째 거부된다. 목록은 디렉터리를 훑어 실행 요약을 만든다), 파일시스템 PluginSource(종류 디렉터리를 훑어 매니페스트 목록을 만든다), MCP ToolSource(langchain-mcp-adapters), 시스템 Clock(UTC, uuid4). ChatAnthropic 인스턴스는 `adapters/anthropic.py`의 factory로 `main.py`가 만든다. 어댑터는 자기를 스스로 조립하지 않는다.
- **파일시스템 PluginSource는 플러그인 루트의 운영자 파일 `disabled.toml`을 읽고 쓴다(ADR 0017).** 형식은 이 어댑터가 소유하고 sdk가 아니다. 읽기: 파일이 없으면 빈 집합, 문법·형식 버전·모르는 키·이름 패턴·값의 타입·UTF-8·열기 실패는 전부 `PluginError`이고 메시지가 경로와 이유를 든다. 디렉터리가 없는 이름(고아 항목)은 손상이 아니라 집합에 들고 쓸 때도 지우지 않는다. 쓰기: 부재 판정(매니페스트 파일이 있느냐, 읽히느냐가 아니다)이 먼저이고 값으로 돌려준다, 손상 판정이 그다음이라 깨진 파일은 덮어쓰지 않는다(쓰기도 먼저 읽는다), 바뀌는 것이 없으면 파일을 건드리지 않는다, 바뀌면 정규형(종류 넷 전부, 이름순, 중복 없음)을 같은 디렉터리의 임시 파일에 쓴 뒤 이름을 바꿔 통째로 교체하고 임시 파일을 남기지 않는다. 마지막 꺼진 것을 켜도 파일은 남는다. 파일을 열거나 교체하다 받는 `PermissionError`만 수십 밀리초 안에서 **동기로** 다시 시도한다(간격과 실측은 ADR 0017의 2026-09-27 첫 이력, 값은 `filesystem.py`의 `_RETRY_DELAYS`) — 윈도우에서 다른 핸들이 연 파일의 교체와 교체되는 순간의 읽기가 그 오류다. 동기인 이유는 재개의 첫 걸음에 `await`가 없다는 불변식과 쓰기 둘을 루프가 줄세운다는 전제가 그것에 기대서다(ADR 0017의 2026-09-27 첫 이력). 쓰기 의존성을 들이지 않고 맞게 쓰는지는 `tomllib` 왕복 테스트가 판정한다.
- 반환은 항상 새 객체다. 인자로 받은 객체를 제자리에서 바꿔 결과를 돌려주지 않는다.
- JSONL 목록은 단건 읽기를 재사용하지 않고 파일마다 헤더와 첫 줄과 마지막 줄만 파싱한다. 전부 파싱하면 목록 하나가 모든 실행의 모든 이벤트를 메모리에 올리고 `limit`은 그 뒤에 자르므로 도움이 되지 않는다. 그래서 가운데 줄이 깨진 파일은 목록에서 요약으로 나오고 단건에서 `PluginError`다. 표지의 이유와 단건의 `PluginError` 문구는 경로와 오류 종류만 싣고 트레이스 내용을 되울리지 않는다 — pydantic 검증 문구의 `input_value`가 깨진 줄의 내용(도구 결과)을 싣기 때문이다(`jsonl.py`의 `_describe`). 매니페스트 목록은 반대로 단건 읽기를 그대로 부른다 — 파일 하나가 작고, 디렉터리와 `kind`·`name`이 맞는지 보는 검사가 거기 있다.
- JSONL의 줄 경계 규칙(무엇이 커밋된 줄이고 미완 줄 뒤에 어떻게 하는가)은 `jsonl.py` 모듈 주석이 원천이다(ADR 0012의 2026-09-23 이력 둘째). 줄을 텍스트나 `str.splitlines`로 가르지 않는다.
- 첫 어댑터는 디렉터리를 훑어 전부 만든 뒤 자른다. 필터와 커서를 포트가 이미 받으므로 색인을 붙일 때 어댑터만 바뀐다(ADR 0012).
