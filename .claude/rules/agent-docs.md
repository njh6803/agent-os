# 에이전트 문서 규칙

스킬, 서브에이전트 정의, 규칙, `CLAUDE.md`는 에이전트가 읽는 문서다. 이 가운데 하나를 쓰거나 고치기 전에 Skill 도구로 `writing-for-agents`를 부르고 그 기준으로 쓴다. 한 세션에서 한 번 부르면 된다.

스킬 목록 예산이 줄면 그 스킬의 설명이 목록에서 빠질 수 있어, 이 규칙이 부르는 자리를 맡는다(ADR 0033 이력 2026-10-20 "하네스가 스킬을 부르는 자리를 감사하고, 설명에만 기대던 계기를 하네스로 옮긴다").
