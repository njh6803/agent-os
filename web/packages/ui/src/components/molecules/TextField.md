# 글 입력(`TextField`)

사람이 글을 넣을 때 씁니다. 짧은 이름과 찾기는 한 줄, 요청과 사유처럼 길어질 글은 여러 줄입니다.

| 해도 되는 것                                        | 하지 않는 것                                                 |
| --------------------------------------------------- | ------------------------------------------------------------ |
| 라벨은 칸 위에 늘 보입니다.                         | 자리 글자를 라벨 대신 쓰지 않습니다. 글을 넣으면 사라집니다. |
| 오류는 칸 아래 글과 아이콘, 테두리로 함께 알립니다. | 테두리 색만으로 오류를 알리지 않습니다.                      |

- 도움말과 오류는 칸 아래 한 줄에 놓이고 `aria-describedby`로 칸에 이어집니다. 오류가 있으면 그 글이 도움말의 자리를 차지하고, 앞에 `circle-x` 아이콘이 붙으며, 칸은 `aria-invalid`입니다.
- 꼭 넣지 않아도 되는 칸은 `optional`로 라벨 옆에 "선택"을 붙입니다. 이름에도 듭니다.
- 쓸 수 없는 칸의 도움말은 흐린 글자 그대로 둡니다. 쓸 수 없음의 색으로 칠하면 명암비가 모자라 읽기 어렵습니다.
- 여러 줄은 세로로만 늘어나고 처음 줄 수는 `rows`(기본 3)입니다.
- 누름과 불러오는 중의 상태는 없습니다.

출처: 디자인 파일 v3의 02.3 글 입력(`.scratch/design-system/design/`).
