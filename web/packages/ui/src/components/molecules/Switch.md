# 스위치(`Switch`)

누르는 즉시 적용되는 설정을 켜고 끕니다. 플러그인 켜기와 끄기가 대표입니다.

| 해도 되는 것                                      | 하지 않는 것                                                         |
| ------------------------------------------------- | -------------------------------------------------------------------- |
| 바뀌는 즉시 적용되는 설정에 씁니다.               | 저장 버튼을 눌러야 적용되는 항목에 쓰지 않습니다. 체크박스를 씁니다. |
| 라벨 아래에 지금 상태(켜짐·꺼짐)를 글로 적습니다. | 트랙 색만으로 켜짐을 알리지 않습니다.                                |

- 라벨 전체가 누르는 곳이고 높이가 48px 이상입니다.
- 상태 글은 스위치가 이미 알리는 켜짐·꺼짐과 같은 뜻이라 화면 읽기 프로그램에서 숨습니다. 이름은 라벨 하나입니다.
- 오류와 불러오는 중은 없습니다. 바꾸지 못하면 쓰는 쪽이 되돌리고 알림으로 알립니다.
- `checked`를 넘기지 않으면 꺼짐에서 시작해 누를 때마다 스스로 바뀝니다.

출처: 디자인 파일 v3의 02.4 스위치(`.scratch/design-system/design/`).
