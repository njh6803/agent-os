# 알림(`Alert`)

실행의 실패, 꺼진 플러그인처럼 영역 전체에 걸린 일을 알릴 때 씁니다. 칸 하나의 오류는 글 입력의 도움말로 알립니다.

| 해도 되는 것                                          | 하지 않는 것                                                |
| ----------------------------------------------------- | ----------------------------------------------------------- |
| 제목에 일어난 일을, 본문에 까닭이나 할 일을 적습니다. | "오류가 발생했습니다"처럼 알맹이 없는 제목을 쓰지 않습니다. |
| 실패만 `role="alert"`로 곧바로 읽힙니다.              | 정보 알림까지 alert로 두어 읽던 글을 끊지 않습니다.         |

- 톤마다 아이콘 모양이 다릅니다. 실패는 `circle-x`, 경고는 `triangle-alert`, 정보는 `info`입니다.
- `actions`에는 다음에 할 일(다시 실행 같은 작은 보조 버튼, 실행 보기 같은 링크)을 둡니다. 본문 아래에 놓입니다.
- `onClose`를 넘기면 오른쪽 끝에 이름이 "닫기"인 투명·작은 아이콘 버튼이 생깁니다. 알림을 거두는 것은 쓰는 쪽입니다.
- 알림 자체는 포커스를 받지 않습니다.

출처: 디자인 파일 v3의 02.6 알림과 03.2 실행 실패 알림(`.scratch/design-system/design/`).
