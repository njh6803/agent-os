# 진행 표시(`Progress`)

1초를 넘기는 실행에서 단계를 보일 때 씁니다. 값을 알면 막대, 모르면 도는 표시입니다.

| 해도 되는 것                         | 하지 않는 것                               |
| ------------------------------------ | ------------------------------------------ |
| 몇 단계 중 몇째인지 글로도 적습니다. | 막대만 두고 무엇을 하는지 숨기지 않습니다. |
| 1초를 넘길 때만 보입니다.            | 곧 끝나는 일에 깜빡이게 두지 않습니다.     |
| 끝을 모르면 도는 표시를 씁니다.      | 끝을 모르는데 막대를 채우지 않습니다.      |

- `label`이 보이는 이름이자 화면 읽기 프로그램이 읽는 이름입니다.
- 막대의 채움은 한 색입니다. 실패는 진행 표시로 알리지 않고 알림으로 바꿉니다.
- 값을 모르면 `value={null}`입니다. 막대 대신 16px의 도는 표시와 이름을 한 줄에 보이고, 움직임 줄이기 설정이면 도는 표시가 멈춥니다. 그 줄은 막대가 있는 모양보다 낮아, 값을 알게 되면 이름 아래 사이와 트랙만큼(14px) 자랍니다.
- 0보다 작거나 `max`를 넘는 값은 그 끝에서 멈춥니다. 화면 읽기 프로그램이 읽는 값도 같은 값입니다.
- `max`는 0보다 큰 값을 넘깁니다. 0 이하이면 막대가 비고, 화면 읽기 프로그램이 읽는 범위는 0부터 0까지입니다.
