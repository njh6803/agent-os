# 진행 표시(`Progress`)

1초를 넘기는 실행에서 단계를 보일 때 씁니다. 값을 알면 막대, 모르면 옮겨 다니는 막대입니다.

| 해도 되는 것                         | 하지 않는 것                               |
| ------------------------------------ | ------------------------------------------ |
| 몇 단계 중 몇째인지 글로도 적습니다. | 막대만 두고 무엇을 하는지 숨기지 않습니다. |
| 1초를 넘길 때만 보입니다.            | 곧 끝나는 일에 깜빡이게 두지 않습니다.     |

- `label`이 보이는 이름이자 화면 읽기 프로그램이 읽는 이름입니다. 실패한 단계에서 멈추면 `tone="danger"`로 둡니다.
- 값을 모르면 `value={null}`입니다. 움직임 줄이기 설정이면 막대가 트랙 가운데에 멈춥니다.
- 0보다 작거나 `max`를 넘는 값은 그 끝에서 멈춥니다. 화면 읽기 프로그램이 읽는 값도 같은 값입니다.
- `max`는 0보다 큰 값을 넘깁니다. 0 이하이면 막대가 비고, 화면 읽기 프로그램이 읽는 범위는 0부터 0까지입니다.

출처: 디자인 파일 v3의 02.7 진행 표시(`.scratch/design-system/design/`).
