# 버튼(`Button`)

화면에서 일을 일으킬 때 씁니다. 주는 그 영역에서 가장 앞선 일 하나, 보조는 나머지, 위험은 되돌릴 수 없는 일입니다.

| 해도 되는 것                                                    | 하지 않는 것                                     |
| --------------------------------------------------------------- | ------------------------------------------------ |
| 한 영역에 주 버튼은 하나만 둡니다. 승인 옆의 거부는 보조입니다. | 승인과 거부를 둘 다 주 버튼으로 칠하지 않습니다. |
| 되돌릴 수 없는 일(실행 지우기)에만 위험을 씁니다.               | 눈에 띄게 하려고 위험을 쓰지 않습니다.           |

- 글자는 동사로 짧게 씁니다. 아이콘은 글자 앞에 두고 화면 읽기 프로그램에서 숨습니다.
- 오류 상태는 없습니다. 실패는 알림으로 알립니다.
- 불러오는 중에는 글자 자리를 그대로 두고 그 가운데에 도는 표시를 그립니다. 너비가 바뀌지 않고 이름도 그대로입니다.

출처: 디자인 파일 v3의 02.1 버튼(`.scratch/design-system/design/`).
