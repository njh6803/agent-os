# 아이콘 버튼(`IconButton`)

글자 없이 아이콘 하나로 일을 일으킵니다. 자리가 좁고 뜻이 널리 알려진 일에 씁니다: 보내기, 닫기, 더 보기.

| 해도 되는 것                                                                       | 하지 않는 것                                 |
| ---------------------------------------------------------------------------------- | -------------------------------------------- |
| `aria-label`과 `title`에 같은 이름을 붙입니다(보내기). `label` 하나가 둘이 됩니다. | 이름 없이 아이콘만 두지 않습니다.            |
| 뜻이 모호한 일(다시 실행)은 글자 버튼으로 둡니다.                                  | 아이콘만으로 처음 보는 일을 시키지 않습니다. |

- 기본은 투명입니다. 올리면 옅은 면이 깔립니다.
- 불러오는 중에는 아이콘 자리에 도는 표시를 두고 이름은 그대로입니다.

출처: 디자인 파일 v3의 02.2 아이콘 버튼(`.scratch/design-system/design/`).
