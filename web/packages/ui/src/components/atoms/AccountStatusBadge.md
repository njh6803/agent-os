# 계정 상태 배지(`AccountStatusBadge`)

운영자 계정 목록에서 계정의 상태를 보일 때만 씁니다. 실행의 상태는 `StatusBadge`가 맡습니다.

| 해도 되는 것                                                       | 하지 않는 것                                                      |
| ------------------------------------------------------------------ | ----------------------------------------------------------------- |
| 글자와 아이콘을 함께 씁니다.                                       | 점 하나나 색만으로 상태를 보이지 않습니다.                        |
| 상태 넷(활성, 비활성, 비밀번호 미설정, 잠김)만 둡니다.             | 실행의 상태나 플러그인의 켜짐·꺼짐에 쓰지 않습니다.               |
| 잠김은 몇 시까지인지 같은 덧붙임을 배지 옆의 글자로 따로 적습니다. | 배지의 글자를 바꾸거나 덧붙이지 않습니다. 글자는 정해져 있습니다. |

- 앞의 셋(활성, 비활성, 비밀번호 미설정)은 상태 점이 앞에 붙고, 잠김은 자물쇠가 붙습니다. 비활성과 비밀번호 미설정은 같은 흐린 색이라 문구로만 갈립니다.
- 바탕을 칠하지 않습니다. 옅은 테두리 안에 글자와 아이콘을 둡니다. 모양과 치수는 `StatusBadge`와 같습니다.
- 글자는 배지가 스스로 씁니다. admin-login 명세의 "배지의 이름"(활성, 비활성, 비밀번호 미설정, 잠김) 그대로이고, 아이콘은 그 옆의 꾸밈이라 화면 읽기 프로그램에서 숨습니다.
- 계정의 "비활성"은 쓰지 못하게 막은 계정을 말합니다. 꺼진 플러그인을 가리키지 않습니다.
- 누르는 곳이 아닙니다. 폭은 늘 내용의 폭이라 세로로 쌓인 자리에서도 늘어나지 않습니다.

출처: admin-login 명세(`.scratch/admin-login/spec.md`)의 "디자인 시스템에 더하는 것"과 "계정 화면과 내 비밀번호"의 "배지의 이름", 그린 화면 `.scratch/admin-login/design/mk-accounts.dc.html`.
