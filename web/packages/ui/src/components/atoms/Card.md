# 카드(`Card`)

플러그인 하나, 실행 하나처럼 한 대상을 묶을 때 씁니다. 그림자 없이 바탕과 테두리로 섭니다.

| 해도 되는 것                               | 하지 않는 것                               |
| ------------------------------------------ | ------------------------------------------ |
| 카드 안의 버튼이나 링크가 누르는 곳입니다. | 카드 전체를 누르는 곳으로 만들지 않습니다. |
| 안을 나눌 때 구분선을 씁니다.              | 카드 안에 카드를 겹치지 않습니다.          |
| 테두리로 경계를 짓습니다.                  | 그림자로 띄우지 않습니다.                  |

- 안의 줄 사이는 8px이고, 폭을 정하지 않은 줄은 카드의 폭으로 늘어납니다. 상태 배지는 내용의 폭을 지킵니다.
- 감싸는 요소는 `as`(`div`, `section`, `article`)로 고릅니다. 모양은 셋이 같습니다.

출처: 재탐색 디자인 파일의 2.8 카드(`.scratch/design-system/design/Agent OS Design System.dc.html`).
