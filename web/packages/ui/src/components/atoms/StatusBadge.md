# 상태 배지(`StatusBadge`)

실행 목록과 승인 묻기에서 실행의 상태를 보일 때만 씁니다.

| 해도 되는 것                                       | 하지 않는 것                                                |
| -------------------------------------------------- | ----------------------------------------------------------- |
| 아이콘 모양과 글자를 함께 씁니다.                  | 점 하나나 색만으로 상태를 보이지 않습니다.                  |
| 상태 넷(일시정지, 끝남, 실패, 결말 없음)만 둡니다. | 개수나 꼬리표를 배지로 만들지 않습니다. 흐린 글자를 씁니다. |

- 글자는 배지가 스스로 씁니다. 용어집의 말 그대로이고, 아이콘은 그 옆의 꾸밈이라 화면 읽기 프로그램에서 숨습니다.
- 누르는 곳이 아닙니다. 폭은 늘 내용의 폭이라 세로로 쌓인 자리에서도 늘어나지 않습니다.

출처: 디자인 파일 v3의 02.5 상태 배지(`.scratch/design-system/design/`).
