# 비용 보고 (매일 09:30)

먼저 `common.md`를 따른다. 이 보고는 "어제 돈이 어디로 갔고 어디서 새나"에 답한다. 비용 칸 옆의 `주간 한도(%p)` 칸은 그 비용을
주간 한도의 몫으로 어림한 것이고, 한도 기록이 없으면 그려지지 않는다.

## 메모

`<보고 폴더>/<어제>.cost.notes.json`.

```json
{
 "heads": {"cost": {"conclusion": "어제 비용의 70%가 Opus xhigh 세션이었다. 시작 때 싣는 것은 평소와 같았다.", "decide": []}},
 "blocks": {
  "cost.models": {"conclusion": "Opus xhigh 세션이 어제 비용의 70%를 썼다", "so_what": "xhigh를 쓸 작업을 고르면 비용이 가장 크게 준다", "todo": "없음"}
 },
 "prs": {}, "branches": {}
}
```

- **블록.** 이 보고로 가는 표는 넷이다. 표마다 무엇을 볼지는 이렇다.
  - `cost.models` 누가 썼나·모델·노력별 비용: 몫이 큰 조합, 서브에이전트의 몫.
  - `cost.sessions` 비용이 큰 세션: 한 작업에 비용이 몰렸는지, 토큰에 비해 호출이 많은지.
  - `cost.branches` 브랜치별 비용: PR을 열기 전에 쓴 몫(리뷰 왕복이 길면 낮다), 인계로 열린 세션 수.
  - `cost.waste` 낭비 후보: 여러 세션이 거듭 읽은 파일, 큰 도구 결과.
  표 아래의 요약 줄(호출 수, 캐시 효율, 압축, 계정별 비용)은 "그 밖의 수"로 그려진다. 따로 쓸 것이 있으면 머리나 블록의 그래서에
  넣는다.
- **이름.** 작업 칸의 브랜치는 PR이 있으면 PR 이름이 붙는다. 시트의 이름을 지을 PR과 PR 없는 브랜치 가운데 이 보고의 표에 나온
  것에 이름을 쓴다.

그리기는 `common.md`의 "그리기와 보고"를 `--report cost`로 따른다.
