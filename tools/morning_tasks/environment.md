# 작업 환경 보고 (매주 월요일 10:00)

먼저 `common.md`를 따른다. 이 보고는 "동시에 몇 개가 알맞았나, 손볼 훅은, 고칠 때가 된 회고 항목은"에 답한다. 하루치로는 평소의
흔들림과 구별되지 않거나 창이 14일 이상인 표라 매주 본다. 경보가 나면 종합 보고의 "평소와 다른 것"에 먼저 오른다.

## 메모

`<보고 폴더>/<어제>.environment.notes.json`.

```json
{
 "heads": {"environment": {"conclusion": "동시 세션 셋일 때 PR당 비용이 가장 낮았다. 손볼 훅은 둘이다.", "decide": []}},
 "blocks": {
  "environment.hooks": {"conclusion": "조용한 훅 둘이 검토 판정이다", "so_what": "28일 동안 한 번도 발동하지 않아 뺄 후보다", "todo": "retro에서 두 훅을 뺄지 판정한다"}
 },
 "queue": {"238": {"name": "남은 워크트리 여섯 판정", "content": "정리 도구가 판정하지 못한 워크트리 여섯을 사람에게 넘긴다"}}
}
```

- **블록.** 이 보고로 가는 표와 볼 것은 이렇다.
  - `environment.concurrency` 동시 세션 구간별 비용: 효율이 좋았던 동시 세션 수(구간의 비용 몫·PR당 비용).
  - `environment.hooks` 손볼 훅: 판정이 `검토`(28일 동안 조용했던 훅), `아직 이르다`(들인 지 얼마 안 돼 판정하지 못한 훅),
    `등록 안 됨`인 훅만 든다. 발동하고 등록된 훅은 많이 늘었거나 많이 막았어도 판정이 `유지`라 표에 없고 수만 줄로
    적힌다. 모든 훅이 `유지`면 이 표는 만들어지지 않아 시트의 열쇠 목록에도 없고, 다른 빈 표처럼 `해당 없음` 줄도 없다.
    그때는 블록을 쓰지 않는다. "앞 14일 대비" 칸은 참고이고 판정이 아니다.
  - `environment.start` 세션을 열 때마다 실리는 것: 큰 항목과 그 흐름.
  - `environment.queue` 고칠 때가 된 회고 항목(3회차 이상): chore 브랜치를 딸 계기.
  - `environment.queue_files` 같은 파일을 가리키는 항목: 한 브랜치에서 함께 고칠 묶음.
- **이름.** 이 보고의 표에 나온 대기열 행마다 이름과 내용을 쓴다.
- 훅을 뺄지, 지침을 바꿀지는 제안만 한다. 판정은 retro 스킬이 한다.

그리기는 `common.md`의 "그리기와 보고"를 `--report environment`로 따른다.
