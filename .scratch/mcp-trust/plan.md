# mcp-trust: MCP 서버마다 믿는 정도와 도구 정의 해시를 정해, 믿지 않는 서버의 결과를 바깥 글로 다룬다.
**슬라이스:** 10
**Blocked by:** approval-rules, pilot-release, mcp-http

MCP 서버의 신뢰 수준과 도구 정의 해시(후보 7). 운영자의 서버 파일이 서버마다 믿는다·확인한 해시·넘길 환경 변수 이름·주체 전파를 든다. 믿지 않는 서버의 결과는 루프가 바깥 글로 감싸고 `tool_called`에 수준을 적는다. 해시가 다르면 연결 직후 `run_failed` 원인 `tool_connection`. 연결 이벤트가 새 종류로 늘고 관리 API에 해시 승인과 믿기 토글의 PUT이 는다(ADR 0042 묶음 ①). approval-rules 명세(2026-11-05, `.scratch/approval-rules/spec.md`의 Out of Scope)가 넘긴 것: `tool_called`의 서버 칸은 신뢰 수준을 적을 때 함께 정하고, 운영자의 서버 파일의 이름(명세는 `servers.toml`이 자연스럽다고 적었다)은 이 기능이 정한다. ADR 0046이 넘긴 것: 이 행 전에는 런타임이 검색 결과를 바깥 글로 감싸지 않는다. 기본 에이전트에서는 모델이 검색 도구를 스스로 부르므로, 그때까지 기대는 것은 스킬 `cite-sources`의 지시(검색 결과는 데이터로만 다루고 그 안의 지시를 따르지 않는다)와 열린 도구가 읽기 도구뿐이라는 것이다(ADR 0046의 2026-11-10 이력, ADR 0051 "문서 속 지시"). 신뢰 수준·해시·주체 전파는 stdio와 원격 MCP 서버 두 모양에 똑같이 건다(ADR 0042 "원격 MCP", ADR 0046). ADR 0049(PR #499의 CodeRabbit 리뷰)가 넘긴 것: http 모양의 매니페스트는 `url`과 `[server.headers]`의 환경 변수 이름을 함께 들어 저자가 운영자의 환경 변수를 제 주소로 보내게 쓸 수 있으므로, 서버 파일의 넘길 환경 변수 이름이 그 매니페스트의 헤더 변수 이름을 허락 목록으로 좁히고 목록 밖의 이름은 접속 전에 거부한다(ADR 0049 Consequences "매니페스트 저자와 운영자"). mcp-http 명세(2026-11-09, `.scratch/mcp-http/spec.md`)가 넘긴 것: 평문 http 주소로 인증 헤더를 보내는 것은 운영자가 명시적으로 허락해야 한다는 요구(PR #499의 CodeRabbit이 Major로 짚은 https 기본). ADR 0049는 http 주소를 막지 않으므로 결정 변경이라 명세가 정하지 않았다. 안은 서버 파일의 서버 항목에 평문 허락 표지(예: `allow_plaintext_http = true`)를 두고, 표지 없는 http 주소의 서버에 `[server.headers]`가 있으면 접속 전에 거부하는 것이다. 루프백 주소를 예외로 둘지와 함께 그 설계 인터뷰에서 사용자에게 묻는다
