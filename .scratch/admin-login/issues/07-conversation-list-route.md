# 07: 대화 목록 경로

**What to build:** 프로그램이 `GET /conversations`를 부르면, 이어 가기로 이어진 실행들이 대화(용어집: 이어 가기로 차례로 이어진 실행들) 한 줄씩으로 묶여 돌아온다. 끝 실행은 그 대화에서 아직 아무도 이어 가지 않은 마지막 실행이고, 첫 실행은 거기서 앞 실행을 거슬러 올라 닿은 가장 오래된 실행이다. 줄마다 끝 실행의 식별자와 상태와 에이전트, 첫 실행의 요청 앞 120자와 요청한 계정(그 실행을 시작한 운영자 계정)과 주체(실행을 요청한 신원), 실행 수, 끝 실행의 시작 시각과 마지막 이벤트 시각, 대화의 처음까지 읽었는지가 실린다. 같은 실행을 둘이 이어 가 갈라진 대화는 끝마다 한 줄이다. 줄은 끝 실행의 시작 시각이 늦은 차례이고, `status`로 거르고 `limit`와 `after`(앞 쪽이 준 커서. 다음 쪽을 이어 읽는 표지 글)로 쪽을 나눈다. 읽히지 않는 트레이스는 `{run_id, reason}` 표지 줄(읽히지 않는 트레이스를 대화 줄과 따로 알리는 줄)로 맨 뒤에 선다. 관리 화면의 대화 목록 화면(10)이 이 경로를 읽는다.

이 티켓은 경로 `list_conversations`를 계약에 더하므로 10을 막는다. 05와 나란히 돌 수 있다.

근거는 명세 `.scratch/admin-login/spec.md`의 "대화 목록", "경로"(표의 `list_conversations`), "이벤트의 두 칸"의 "실행 요약에는 싣지 않는다", "권한 표", Testing Decisions의 "sdk와 core"다. 결정은 ADR 0063 결정 "대화 화면"과 그 이력 2026-11-24, ADR 0012(목록의 정렬과 커서)다. 이 티켓의 "명세 검토"는 일지 `docs/journal/2026-11-25-1007-admin-login-tickets.md`의 "명세 검토(spec-reviewer)" 절을 가리킨다.

**Blocked by:** 01

**Status:** ready-for-agent

### 계약

- [ ] `GET /conversations`(`list_conversations`)를 명세 "대화 목록"대로 계약에 더한다. 질의는 트레이스 목록과 같은 셋(`status`, `limit` 1~200 기본 50, `after`), 답은 `{conversations, next_cursor}`, 오류 문서는 401·403·422다
- [ ] 줄의 칸 열(`last_run`, `status`, `agent`, `first_request`, `requesting_account`, `principal`, `run_count`, `last_started_at`, `last_at`, `complete`)과 표지 줄의 모양을 계약에 적는다
- [ ] 생성 클라이언트의 경로 목록을 고정한 타입 시험(`web/packages/api-client`의 `clients.test-d.ts`)에 새 경로를 더한다
- [ ] `openapi.json`과 생성 TS 타입이 같은 커밋에 실린다
- [ ] 권한은 `view`다. 05가 먼저 병합됐으면 이 티켓이 권한 표에 `list_conversations` 줄을 더하고, 아니면 05가 더한다. 늦게 병합하는 쪽이 기준 브랜치를 합친 뒤 전수 검사가 초록인지 본다

### 짓는 자리

- [ ] 묶는 규칙(끝 고르기, 거슬러 오르기, 멈추기, 칸 채우기, 정렬과 커서)은 core의 순수 함수 하나가 갖는다. 끊긴 고리(앞 실행이 없다, 읽히지 않는다, 이미 지난 실행으로 돌아온다)에서 멈추고 `complete`를 거짓으로 둔다. 이어 가기의 판정을 다시 하지 않는다
- [ ] 트레이스 저장 포트에 동기 메서드 하나(대화 목록)를 더한다. 포트를 새로 두지 않는다. `.claude/rules/core.md`의 포트 표에서 트레이스 저장 포트의 줄에 이 메서드를 더한다
- [ ] JSONL 어댑터는 지금 목록처럼 파일마다 헤더와 첫 줄과 마지막 줄만 읽어, 실행마다 요약과 시작 이벤트의 앞 실행·요청·요청한 계정을 그 함수에 넘긴다
- [ ] 시험의 가짜 트레이스 저장소도 같은 메서드를 갖는다
- [ ] 첫 요청은 파이썬의 글자 수로 앞 120자만 싣는다. 트레이스 목록(`GET /traces`)은 계약과 모양 그대로 둔다
- [ ] 규칙 파일을 고치기 전에 Skill 도구로 `writing-for-agents`를 부른다

### 시험

- [ ] 순수 함수의 사례: 이어 가지 않은 실행 하나, 갈라진 끝 둘, 앞 실행이 없는 고리, 읽히지 않는 앞 실행, 손상된 기록의 순환, 같은 시작 시각의 차례와 커서
- [ ] JSONL 어댑터가 진짜 트레이스 디렉터리에서 줄을 짓고 읽히지 않는 파일을 표지 줄로 낸다
- [ ] HTTP 시험은 가짜 트레이스 저장소로 경로의 질의와 쪽과 422를 본다

### 검증

- [ ] `CLAUDE.md`의 검증 명령이 모두 초록이다
- [ ] 서버 라우트와 api-client를 고치므로 관리 화면 e2e(`pnpm -C web/apps/admin exec playwright test`)를 로컬에서 친다
- [ ] `adapters/`를 고치므로 LLM 시험의 병합 조건 범위에 든다. `-m llm`을 치고, 로컬 모델 시험은 `--yes` 없이 쳐 예상 비용을 사용자에게 보이고 확인받은 뒤 돌린다
