# admin-login 프로브

admin-login의 설계 인터뷰(일지 `docs/journal/2026-11-14-2152-admin-login-design.md`)가 근거로 든 측정 스크립트의 색인이다. 규약은 `docs/agents/issue-tracker.md`의 "프로브와 근거", 짓는 규칙은 `.claude/rules/probes.md`다. 이 폴더의 코드는 프로브의 것이고 제품 코드가 아니다. 프로브마다 그 폴더의 `README.md`가 돌리는 법, 판, 결과, 재지 못한 것의 원천이고, 아래 표는 한 줄씩의 길잡이다.

| 파일 | 재는 것 | 근거로 드는 자리 | 다시 돌 때 | 잰 판 |
|---|---|---|---|---|
| `cookie_relay/` | 관리 화면의 중계(Next `rewrites`)와, 호스트가 같고 포트가 다른 서버 사이에서 쿠키와 요청 머리(`Sec-Fetch-Site`, `Origin`, `Host`, `x-forwarded-host`)가 움직이는 모양. 실제 관리 화면과 Chromium으로 본다. `Secure`와 `__Host-` 쿠키가 `localhost`와 평문 `http`의 다른 이름에서 저장되는지도 본다 | ADR 0062 결정 "로그인 상태"와 "요청 출처 검사", Consequences "한계"와 "재지 못한 것" | `web/`의 의존성, Playwright의 Chromium, `openssl`. 네트워크를 타지 않는다. 약 3분이고 `web/apps/admin/.next/`를 다시 쓴다. 명령은 `cookie_relay/README.md` "다시 돌리기" | Next 16.3.6, Playwright 1.63.0, Chromium 153.0.8010.12, Node v24.19.0, Windows 10 |
| `password_hash/` | 비밀번호 해시 후보 둘(표준 라이브러리 `hashlib.scrypt`, `argon2-cffi`의 Argon2id)의 판·라이선스·휠, 후보 모듈이 pyright strict와 타입 우회 검사를 지나는지, OWASP 권고 매개변수에서 해시 한 번의 시간과 메모리, 해시하는 동안 이벤트 루프가 막히는지 | ADR 0062 결정 "비밀번호 저장", Considered Options의 scrypt 항목, Consequences "의존성"과 "재지 못한 것" | 도는 Docker 데몬, 네트워크(PyPI, Docker Hub, `ghcr.io/astral-sh/uv`), `uv`, 임시 트리. 항목 전부가 16~18분이었다. 측정이 아닌 회차가 하나라도 있으면 종료 코드가 1이고, 결과를 낸 실행 `ca9b00`은 이벤트 루프의 parallel 갈래 30 회차가 측정 아님이라 1로 끝났다(그 README의 머리). 명령은 `password_hash/README.md` | argon2-cffi 25.1.0, argon2-cffi-bindings 26.2.0, cffi 2.1.1, 파이썬 3.12.10(호스트)과 3.12.16(`python:3.12-slim-trixie`), uv 0.10.8 |
| `port_shape/` | 포트를 선언한 모듈을 가져오지 않는 어댑터가 pyright strict에서 그 포트를 만족하는지, 포트에서 어긋난 어댑터를 조립하는 자리의 타입 검사가 잡는지. 작은 모듈 둘로 흉내 낸 모양 하나만 본다 | ADR 0062 결정 "경로와 층", Considered Options의 포트 자리 항목 | `uv`와 저장소의 의존성. 네트워크와 Docker를 쓰지 않고 수 초다. 명령은 `port_shape/README.md` "다시 돌리기" | pyright 1.1.414, 파이썬 3.12.10, Windows 10 |
| `pg_stack/` | PostgreSQL을 쓰는 도구 조합(psycopg 동기·비동기, asyncpg, SQLAlchemy Core)이 pyright strict와 타입 우회 검사를 지나는지와 윈도 호스트·리눅스 컨테이너·서버의 이벤트 루프·pytest 설정에서 도는지, 표를 만드는 도구 셋(alembic, yoyo-migrations, SQL 파일), 테스트가 PostgreSQL을 스스로 띄우는 길(testcontainers), 공식 이미지의 판과 크기 | ADR 0066 결정 "도구 묶음", "이미지와 지원 범위", "테스트 데이터베이스", "표를 올리는 때"와 Considered Options의 도구·testcontainers·Alpine 항목(postgres-foundation의 설계, 일지 2026-11-17-1747). ADR 0062는 이 프로브의 결과로 고른 것이 없다 | 도는 Docker 데몬, 네트워크, `uv`, 임시 트리. 명령은 `pg_stack/README.md` | psycopg 3.3.9, psycopg-pool 3.3.3, asyncpg 0.32.0, asyncpg-stubs 0.32.0, SQLAlchemy 2.1.8, alembic 1.20.1, yoyo-migrations 9.0.0, testcontainers 4.15.0, PostgreSQL 18.7(`postgres:18-alpine`), 파이썬 3.12.10(호스트)과 3.12.16(리눅스 이미지), uv 0.10.8 |

`pg_stack/`은 postgres-foundation의 폴더로 옮기지 않았다. 프로브의 Dockerfile과 실행 스크립트와 기록에 이 폴더의 경로가 박혀 있어, 옮기면 다시 돌려 확인해야 하기 때문이다. 그 행의 설계가 옮기지 않고 이 경로로 인용하기로 했다(ADR 0066 결정 "프로브 폴더").

두 프로브가 지은 Docker 이미지(`admin-login-pwhash-probe-linux`, `admin-login-pg-probe-linux`)를 지우는 명령은 각 README의 끝에 있다.
