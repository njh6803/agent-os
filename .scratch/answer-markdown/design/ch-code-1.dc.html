갈래 3 · 안 1 (추천) · 긴 줄은 가로 스크롤

코드 블록은 승인 묻기의 인자 칸과 같은 칸이다. 줄을 꺾지 않고 칸 안에서 가로로 스크롤하며, 처음에는 왼쪽 끝이 보이고 줄이 오른쪽 끝에서 잘린다. 언어 이름과 복사 단추는 없다.

사내 규정 도우미 새 대화

  1. 신청서 번호는 LV-2026-000184 꼴로 옵니다. 시작일은 11월 30일 12월 1일로 바뀌었습니다. 자세한 안내는 인사 시스템 도움말에 있습니다.

    인사 시스템 API로 낼 때는 아래처럼 보냅니다.

    curl -X POST https://hr.example.com/api/v1/leave-requests -H "Content-Type: application/json" -d '{"type":"parental","start":"2026-12-01","end":"2027-11-30"}'

출력의 끝부분을 스크롤해 본 모습이다. 위젯 틀의 높이는 보이는 부분에 맞췄다.
