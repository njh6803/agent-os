# 04: 회차의 자리 — 회차마다 B까지의 이력만 든 새 클론과 막는 규칙, 허용 목록 환경을 짓고, 표지를 본 폴더만 지운다

**What to build:** 회차 도구가 회차 하나를 열기 전의 자리를 짓는다. 사람이 준 뿌리 아래 회차마다 다른 폴더를 만들고 표지를 심는다. 그 안에 B를 `main`으로만 받은 로컬 bare 원격과 그 클론을 짓고, 클론에 B 뒤 커밋과 다른 ref가 없는지 대 본다(스토리 12·13·14). 클론에서 준비 명령을 돌리고 그 시간과 비용을 회차에 넣지 않는다(스토리 15). 클론의 `.claude/settings.local.json`에 막는 규칙을 쓴다(스토리 19·20). 세션에 넘길 환경을 허용 목록으로 짓고 gh 설정 폴더를 빈 폴더로 준다(스토리 18). 회차 폴더를 지우는 명령은 표지가 있는 폴더만 지운다(스토리 46). 세션을 띄우는 것은 06이다.

근거는 `.scratch/model-rerun/spec.md`의 "클론과 설정 폴더"의 회차 폴더·bare와 클론·준비·환경 변수와 그 2026-10-22 주석 셋(뿌리와 설정 폴더의 머리, 상위의 `.claude/`, 게이트 작업 트리와 회차 폴더를 지우는 때. 준비의 실패. 캐시 변수의 이름), "명령과 막는 규칙"의 막는 규칙 목록, "자리와 모듈"의 지우는 길과 `REPO_LOCATION_VARS` 항목, Testing Decisions "회차 하나"의 클론·지우기·환경 항목이다. 설계 5절이 원천이고 명세가 고친 자리(쓰기도 막는다, 웹 도구 전부, 바깥 상태를 바꾸는 도구, 윈도 기본값)는 명세가 원천이다. 프로브 `.scratch/model-rerun/probes/headless_flags/headless_flags.py`의 `layout`, `allowed_env`, `ancestors_with_claude_dir`, `remove_tree`가 같은 일을 프로브 크기로 한다.

### 뿌리와 회차 폴더

- [x] **뿌리는 러너를 띄우는 쪽이 명령 줄로 준 절대 경로다.** 상대 경로면 아무것도 하지 않고 멈춘다. 뿌리와 전용 설정 폴더 둘 다 주 체크아웃(`git worktree list`의 첫 줄)과 사용자의 `~/.claude`를 경로 조각 단위로 머리로 가지면 멈춘다. `C:/Users/User/.claude-rerun`은 조각으로는 `~/.claude` 아래가 아니어서 받는다. 견줌은 대소문자와 `/`·`\`를 가리지 않는다
- [x] **회차 폴더는 뿌리 아래 `<과제 id>-<갈래>-<회차 번호>-<짧은 난수>`이고(이름은 01의 함수로 짓는다), 만든 직후 표지 파일을 심는다.** 회차 번호는 부르는 쪽(10)이 01의 함수로 잡아 넘긴다. 그 안에 bare 원격, 클론, 원본 stream-json 자리, 빈 gh 설정 폴더가 든다. 회차마다 경로가 달라 세션 기록 폴더와 자동 메모리 경로가 갈린다
- [x] **회차 폴더와 표지를 만드는 함수는 bare·클론·준비와 따로 부른다.** 폴더가 이미 있으면 덮지 않고 실패한다. 10은 번호를 잡자마자 이 함수만 차례로 부르고, bare·클론·준비는 회차마다 따로 돈다. 한 함수로 묶으면 10이 번호 잡기를 지키려고 그 함수째 차례로 돌려 동시에 둘이 사라지거나, 차례를 풀어 두 회차가 같은 번호를 받는다
- [x] **회차 폴더의 상위(홈은 뺀다)에 `.claude/`가 있으면 멈춘다**(프로브의 `ancestors_with_claude_dir`). 상위의 설정과 `CLAUDE.md`가 세션에 실리는 것을 막는다
- [x] **지우기 명령은 사람이 부르고, 뿌리 아래에서 표지가 있는 회차 폴더만 지운다.** 표지가 없는 폴더는 건드리지 않고 이름을 보고한다. 표지는 있는데 `records/`에 그 회차의 기록이 없는 폴더도 지우지 않고 이름을 보고한다. 그 회차의 비용은 아직 그 폴더의 원본에만 있고, 다시 뜬 러너가 측정 아님(중단)으로 기록한 뒤에야 지울 수 있다(명세 "차례, 동시성, 예산"의 2026-10-23 주석). 링크는 따라가지 않고 링크만 끊는다(선례 `tools/canary.py`의 `_cut_links`, `tools/tidy_checkouts.py`의 `delete_path`). 커밋 전에 임시 저장소에서 판정을 깨려는 입력(폴더 안의 링크와 junction, 커밋하지 않은 파일, 윈도 경로 정규화가 바꾸는 이름, 표지 없는 비지 않은 폴더, 뿌리로 준 홈)으로 반박한다(`.claude/rules/tools.md`의 지우는 도구 항목)

### bare와 클론

- [x] **주 저장소에서 B를 bare 저장소의 `main`으로만 민다.** 태그와 다른 ref는 밀지 않는다. 클론의 `origin`은 그 bare 저장소이고, 푸시가 GitHub에도 주 저장소에도 닿지 않는다
- [x] **세션을 열기 전에 클론의 모든 ref가 B를 가리키고 `git rev-list --all`에 M이 없는지 대 본다.** 하나라도 아니면 그 회차를 열지 않고 멈춘다
- [x] **git을 띄우는 자리와 그 시험은 `tools.run_hooks.REPO_LOCATION_VARS`를 자식 환경에서 벗긴다**(`.claude/rules/tools.md`의 pre-commit 항목)

### 준비

- [x] **`uv sync`, `pnpm -C web install --frozen-lockfile`, `uv run pre-commit install`을 클론에서 차례로 돌린다.** 걸린 시간은 회차의 벽시계에 넣지 않는다. 하나라도 0이 아니게 끝나면 남은 준비를 돌리지 않고, 회차를 "측정 아님(준비)"로 낼 수 있게 어느 명령이 몇으로 끝났는지를 돌려준다. 러너를 멈추는 것은 10이다
- [x] **준비 명령은 함수의 인자로 받는다.** 시험에서는 임시 저장소 안의 작은 명령으로 돌고, 실제 목록은 상수로 따로 단언한다

### 막는 규칙

- [x] **클론의 `.claude/settings.local.json`의 `permissions.deny`에 명세 "명령과 막는 규칙"의 목록이 모두 든다.** `Bash(gh:*)`, `Bash(git push:*)`, 주 체크아웃과 사용자 `~/.claude`의 `Read`·`Edit`·`Write`, `Skill(open-session)`, `Bash(*open_session.ps1*)`, `Bash(*claude://*)`, `WebFetch`·`WebSearch`, 그리고 `SendMessage`, `ListAgents`, `RemoteTrigger`, `PushNotification`, `DesignSync`, `CronCreate`, `ScheduleWakeup`이다. 경로 규칙의 꼴은 프로브가 막는 것을 본 꼴(`Read(//<드라이브>/<경로>/**)`)을 따른다. 쓰기·편집 규칙과 도구 이름만 쓴 규칙은 프로브가 재지 않은 꼴이라 파일럿(11)이 본다
- [x] **클론의 `.claude/settings.json`(B의 것)은 고치지 않는다.** 그 파일이 켠 플러그인은 그대로 실리고, 설정 확인(09)이 허용 모임으로 받는다

### 환경

- [x] **세션에 넘길 환경은 허용 목록으로 짓는다.** 설계 5절의 목록(`PATH`, OS 기본값, `CLAUDE_CONFIG_DIR`, `DISABLE_AUTOUPDATER=1`)과 명세가 더한 윈도 기본값, 캐시 변수(`UV_CACHE_DIR`, `UV_PYTHON_INSTALL_DIR`, `PNPM_HOME`, `XDG_CACHE_HOME`)이고, 부모 환경에 있는 것만 넘긴다. 여기에 회차 폴더의 빈 폴더를 가리키는 `GH_CONFIG_DIR`을 더한다
- [x] **허용 목록은 상수 하나이고, 시험의 기대 집합도 그 상수에서 낸다**
