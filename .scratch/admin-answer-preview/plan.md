# admin-answer-preview: 관리 화면 실행 상세의 최종 출력 칸에서 원문과 마크다운으로 그린 모양을 오가며 보게 해, 운영자가 최종 사용자에게 보인 모양을 바로 확인한다.
**슬라이스:** 10
**Blocked by:** answer-markdown, pilot-release
**설계:** ADR 0053

관리 화면의 실행 상세는 지금 이벤트의 칸마다 값을 글자 그대로 그린다(`web/apps/admin/components/organisms/EventItem.tsx`). 이 기능은 최종 출력 칸 하나에 '원문'과 '그린 모양'을 오가는 전환을 둔다. 사용자가 answer-markdown과 함께 설계 인터뷰에서 골랐다(일지 2026-11-10-1345의 라운드 4와 5). 처음에 보이는 것은 원문이다. 그린 모양은 answer-markdown이 만든 `web/packages/ui`의 부품을 위젯과 같은 제한으로 쓰고, 링크도 위젯과 똑같이 새 탭으로 열린다. 도구 결과, 프롬프트, 도구 인자 같은 다른 바깥 글은 지금처럼 텍스트로만 그린다(ADR 0019). 부품과 제한은 ADR 0053이 정했다. 슬라이스 10은 제품 1.0 묶음이고 0.1 판에는 들지 않는다. 그래서 기준선 뒤의 다른 행처럼 pilot-release를 기다린다(ADR 0046의 2026-11-10 이력. 사용자에게 묻지 않고 정한 기본값이다). 공개 데모는 관리 화면을 밖에 내놓지 않아 이 기능을 기다리지 않는다. 명세 전에 화면을 그린다(ADR 0053 결정의 "목업 먼저"). 그린 화면은 `.scratch/admin-answer-preview/design/`이고 명세가 그 화면을 가리킨다. 전환의 생김새와 자리, 그린 모양임을 알리는 표시는 그 목업에서 사용자가 고른다. 명세가 먼저 볼 것: 관리 화면의 브라우저는 관리 토큰을 들고 있으므로(ADR 0019), 그린 모양의 링크를 운영자가 누를 때의 위험(속임수 링크)과 새 탭이 관리 화면의 창에 접근하지 못한다는 것을 브라우저에서 확인한다(ADR 0053 Consequences "속임수 링크"). 관리 화면의 번들이 느는 크기도 본다. 수락: 관리 화면의 실행 상세에서 최종 출력 칸이 처음에는 원문을 보이고, 전환을 누르면 위젯과 같은 모양으로 그려지며, 원시 HTML이 든 출력은 그린 모양에서도 글자로 보이고 실행되지 않는 테스트가 통과한다
