# replay-evaluation: 지난 실행을 바뀐 에이전트나 모델로 다시 돌려 결과를 견주고 사람이 판정을 적는다.
**슬라이스:** 13
**Blocked by:** delegation

재생 평가(후보 14). 운영자가 고른 지난 실행을 같은 요청·앞 고리로 바뀐 에이전트·모델·스킬에 다시 돌린다. 모델은 실제로 부르고 도구 호출은 원본 기록에서 찾으며 못 찾으면 `run_failed` 원인 `evaluation`이다. 사람의 판정은 평가 표(PostgreSQL)에 적고 LLM 채점은 하지 않는다. 관리 API·화면·CLI(ADR 0042 묶음 ④). answer-eval이 넘긴 것: 고정 질문으로 새 실행을 도는 답변 평가의 표와 합칠지는 이 행의 설계 인터뷰가 본다
