# design-refresh: 디자인 시스템의 색과 글꼴과 밀도를 관리 화면에 어울리도록 다시 탐색해 골라 코드에 옮긴다.
**슬라이스:** 4
**Blocked by:** design-system
**끝:** 2026-10-13

디자인 시스템의 색·글꼴·밀도를 관리 화면 기준으로 다시 고른다. 2026-10-12 사용자가 올린 디자인 시스템을 보고 디자인이 예쁘지 않다며 관리 화면에 맞게 다시 디자인해 달라고 했고, 미리보기 카드 다시 만들기, 색·글꼴·밀도 재탐색, 화면 프롬프트의 시각 방향을 골랐다(일지 2026-10-12-11). 탐색은 Claude Design에서 하고(조작은 세션이 내장 브라우저로, 고르기는 사람이) 시작 프롬프트는 `.scratch/design-system/design/refresh-prompt.md`다. 사용자가 준 참고(Claude Console의 API 키 화면, OpenAI Platform의 홈)와 웹에서 찾은 참고(Linear, Vercel, Stripe)에서 뽑은 규칙과 가져오지 않을 것이 그 안에 있다. 내보낸 디자인 파일은 `.scratch/design-system/design/`에 둔다(`docs/agents/issue-tracker.md`의 화면 디자인 절). 고른 결과는 ADR 0026의 새 이력으로 적고 승인을 받는다. 2026-10-12에 골랐고 결정은 ADR 0026의 2026-10-12 이력 "테마는 넷이고 색만 바꾸며, 글꼴은 모든 테마가 Noto Sans KR과 Noto Sans Mono를 쓴다"다. 디자인 파일은 `Agent OS Design System.dc.html`이다. 반영은 패키지의 디자인 토큰 CSS와 테마 목록, 판정 스토리, 사진 비교 정답이고, Claude Design에 다시 올릴 때 변형 스토리 대신 보여 주기용 스토리(패키지의 Storybook에 두고 `/design-sync`의 카드에서 변형 스토리를 뺀다. 명세에서 사용자가 골랐다)와 기초 카드, 목록 타일(`.design-sync/thumbnail.html`)을 함께 올린다. 테마의 이름·수·기본 테마나 밀도가 바뀌면 함께 고칠 자리(화면 프롬프트, 사용 규약과 검사기, 변환기 포크의 기본 테마, 목록 타일, `web-design.md`, `CONTEXT.md`)는 재탐색 프롬프트의 "고른 뒤" 4다. 명세는 `.scratch/design-refresh/spec.md`다(2026-10-12, 일지 2026-10-12-28). 사용자가 고른 것은 다섯이다. 컴포넌트 아홉은 모양만 새 디자인을 따르고 props는 지금 계약을 지킨다. 위험 버튼의 누름은 `bg-selected`다(디자인 파일의 `bg-active`는 다크에서 4.5:1에 못 미쳤다). 밀도는 `data-density`가 고르고 속성이 없으면 화면 폭을 따른다. 사진은 기본 테마의 라이트·다크 × 밀도 둘이다. 보여 주기용 미리보기는 패키지의 스토리다. 측정은 `.scratch/design-refresh/probes/`다. 명세 검토(2026-10-12)는 blocker 1·should-fix 12·nit 6이었고 명세의 주석과 티켓으로 닫았다. blocker는 명세의 "나눠도 되는 것은 컴포넌트의 새 모양"이 지금 코드에서 서지 않는다는 것이었다. 쓰임새 토큰의 이름을 바꾸면 아홉 컴포넌트가 모두 빨개지고 옛 칠한 모양은 옮길 새 이름이 없어, 색을 바꾸는 티켓이 아홉의 색 모양까지 옮긴다. 티켓은 다섯이다(`.scratch/design-refresh/issues/`, 2026-10-12, 일지 2026-10-12-36). 01 글꼴·02 아이콘의 선과 크기, 디자인이 없앤 prop 넷(나란히) → 03 테마 넷과 색(01·02 뒤) → 04 밀도와 공통 크기(03 뒤) → 05 Claude Design에 올릴 것과 마무리(04 뒤). 05가 병합된 뒤 사람이 `/design-sync`를 시작하는 것으로 닫았다(2026-10-14). to-tickets에서 사용자가 고른 것은 다섯으로 쪼개는 것이다. 05(일지 2026-10-13-62)가 컴포넌트 아홉의 보여 주기용 스토리(태그 `showcase`), 카드에서 변형 스토리를 빼는 목록과 그 검사, 기초 카드 넷(색, 글자, 간격과 모서리, 밀도), 녹청의 목록 타일, 새 사용 규약을 더하고 잔존 grep 을 0으로 맞춰 닫았다. 빼는 목록을 채점이 따르는지와 컴포넌트 폴더 밖의 카드가 모이는지는 사람이 시작한 2026-10-14 `/design-sync`가 봤다. 둘 다 그렇다(일지 2026-10-15-01, `.design-sync/NOTES.md`)
