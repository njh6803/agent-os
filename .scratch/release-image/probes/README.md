# release-image 프로브

설계 인터뷰가 근거로 드는 측정 스크립트다. 규약은 `docs/agents/issue-tracker.md`의 "프로브와 근거", 짓는 규칙은 `.claude/rules/probes.md`다. 근거로 드는 자리는 ADR 0056(`docs/adr/0056-ci-cuts-a-release-whenever-main-moves-and-the-standalone-compose-joins-proxy-and-four-containers-on-a-docker-network.md`)과 설계 인터뷰의 두 일지(`docs/journal/2026-11-11-1110-release-image-design.md`, `docs/journal/2026-11-11-1532-release-image-design-round3.md`)다. 명세는 아직 없다. 결과와 갈래, 재지 못한 것은 폴더마다의 `README.md`에 있다.
