# admin-api 프로브

명세·ADR·코드 주석이 근거로 든 측정 스크립트다. 규약은 `docs/agents/issue-tracker.md`. 2026-09-28에
세션 스크래치패드에서 옮겼다(대기열 29). 바꾼 것은 ruff를 지나게 한 형식과, 원칙 III에 걸리는
`type: ignore` 하나를 실제 반환 타입(`tuple[RunRow, ...]`)의 주석으로 바꾼 것이다. 옮기기 전의 근거는
프로브를 "쟀다" 같은 말로 가리킨다. 이 표가 그 말을 파일로 잇는다.

돌리는 법은 저장소 루트에서 `PYTHONUTF8=1 uv run python .scratch/admin-api/probes/<파일>`이다.

| 파일 | 재는 것 | 근거로 드는 자리 | 다시 돌 때 |
|---|---|---|---|
| `probe_miss.py` | 진짜 JSONL 어댑터에서 커서 순회가 놓치는 두 길. 지나간 키 범위에 늦게 나타난 파일, 그리고 `?status=paused`를 넘기는 동안 재개됐다가 다시 멈춘 옛 실행 | ADR 0012의 2026-09-23 이력 "커서는 순회 도중 들어오거나 키가 바뀐 실행을 놓치거나 두 번 센다"("길은 셋이고 진짜 JSONL 어댑터로 쟀다") | 그대로. 두 길 모두 지금도 재현된다 |
| `probe_torn.py` | 쓰는 중인 마지막 줄(개행 없음)을 목록이 어떻게 보는지. 위 이력의 셋째 길이다 | 같은 이력 | 그대로. 다만 결과가 바뀌었다 — ADR 0012의 다음 이력 "개행으로 끝나지 않은 마지막 줄은 아직 쓰이지 않은 것이다"가 셋째 길을 닫아, 지금은 그 실행이 꼬리에 다시 오지 않는다 |
