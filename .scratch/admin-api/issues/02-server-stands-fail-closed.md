# 02: 서버가 선다 — 토큰 없이는 아무것도 없다

**What to build:** `create_app()`이 만든 앱이 요청에 답하기 시작하고, 그 첫 답이 401이다. 토큰을 가진 요청만 지나가고 `/health`만 예외다. 데이터 라우트는 아직 하나도 없다 — 이 티켓이 만드는 것은 **그 뒤로 붙는 모든 라우트가 기본으로 보호받는 자리**와, 계약 파일이 앱과 어긋나는 순간 빨개지는 게이트다.

인증이 라우트보다 먼저인 것이 이 티켓의 존재 이유다. 라우트가 먼저 병합되면 그 사이의 main이 인증 없는 관리 API이고, 그것이 ADR 0011이 씨앗을 뒤집으며 막은 바로 그 모양이다 — "인증 없이 도는 코드가 먼저 있게 되고, 나중에 그것을 막는 쪽이 예외가 된다". 같은 이유로 `openapi.json`의 최신성 테스트도 첫 라우트와 같은 티켓이다. 늦으면 그 사이에 커밋되는 계약 파일이 앱과 달라도 검사 넷이 전부 초록이다.

근거는 ADR 0010과 그 2026-09-22 이력 둘, ADR 0011.

**Blocked by:** 01

**Status:** done

- [x] `server.py`가 `create_app(*, plugins, trace, token, ...)` 하나만 내보낸다. 모듈 수준 전역 `app`이 없다. 어댑터를 만들어 넘기는 자리는 `main.py`와 `server.py`뿐이고 어댑터는 자기를 스스로 조립하지 않는다
- [x] import-linter의 `(agent_os.server)` 층이 실물이 되어 `main → server → {channel | admin | adapters} → core → sdk`가 실제로 판정된다. 관리와 채널은 서로를 import하지 않는다
- [x] **allowlist 밖의 모든 경로가 토큰 없이 401이다.** `app.openapi()`가 아는 경로를 전수로 돈다. 보호는 미들웨어가 기본으로 걸고 라우트가 opt-in하지 않는다 — 라우트를 더하며 보호를 잊으면 이 테스트가 깨지지만, fail-closed면 그 테스트는 벨트이지 안전장치 전부가 아니다
- [x] 틀린 토큰도 401이고 **빈 문자열은 토큰이 아니다** — 헤더 부재를 빈 문자열로 다루는 구현과 겹치면 그 자체가 fail-open이다. 비교는 값에 따라 시간이 달라지지 않는다. 상수 시간 비교 자체는 바깥 행동이 아니라 테스트로 단언하지 않고 리뷰가 확인한다
- [x] `/health`만 토큰 없이 200이고 allowlist의 원소가 그 하나임을 테스트가 고정한다. **문서 몫은 ADR 0011이 이미 졌다** — 목록이 자라면 그 이력에 쌓는다. 문서 없이 자라는 것이 fail-open으로 돌아가는 길이므로 테스트와 문서 둘 다가 조건이다
- [x] **`/health`의 응답 본문에 무엇이 실리는지를 이 티켓이 정한다.** 인증 없이 경계 밖으로 나가는 유일한 응답이므로 내부 구성을 싣지 않는다. 라우트가 상태를 직접 읽지 않고 `create_app`이 주입받은 것을 돌려준다
- [x] 성공 응답이 봉투 없는 생값이고 에러만 `{code, message, violations, request_id}` 봉투다. 추적 식별자는 성공 응답에서 `X-Request-Id` 헤더로 나간다
- [x] **`code` 어휘와 `violations`의 모양을 이 티켓이 정한다.** 둘 다 `openapi.json`에 박히고, 슬라이스 3이 에러 처리를 한 곳에서 받는 근거가 그것이다
- [x] **에러 하나가 서버 표준 에러에 같은 추적 식별자로 한 줄 남는다.** 명세는 식별자를 헤더와 봉투로 주는 데서 끝나고 그것을 **이을 대상**은 적지 않았다(명세 검토가 잡았다). 누가 무엇을 조회했는지는 남기지 않는다 — 감사 로그는 비목표이고 이것은 실패 하나의 상관 키다
- [x] **토큰이 그 한 줄에도 어디에도 나타나지 않는다**(원칙 V). 토큰은 환경변수로만 들어온다
- [x] 예외를 상태 코드로 옮기는 표가 `admin/http` 한 곳에 있다. 라우트마다 흩어지면 새 라우트가 같은 예외에 다른 답을 한다. `core`의 예외는 상태 코드를 모른다
- [x] `openapi.json`이 저장소 루트에 커밋되고 `tools/export_openapi.py`가 그것을 만든다. **테스트 하나가 `create_app().openapi()`와 파일을 비교해 어긋나면 실패한다.** 검사 명령 넷이 그대로 게이트이므로 새 훅을 만들지 않는다
- [x] 스키마에 이름 있는 타입이 나온다. 생성 클라이언트의 타입 이름이 익명 구조체가 되지 않는다는 것을 테스트가 잰다
- [x] 가짜 포트를 주입한 `create_app`에 httpx `AsyncClient` + `ASGITransport`로 요청을 넣는다. 가짜는 포트 Protocol을 상속하지 않고 시그니처로 만족하며 픽스처에서 포트 타입으로 annotate한다. 네트워크도 디스크도 타지 않는다
- [x] **`create_app`이 도구 포트를 받지 않는다.** 조회가 MCP 서버를 띄우는 것이 구조적으로 불가능하다는 사실을 테스트가 한 줄로 적는다
- [x] 검사 넷이 초록이다
