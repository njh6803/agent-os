첫 실행은 `as-is`의 `node` 표지를 `ERR_MODULE_NOT_FOUND`로 잘못 골라 그 갈래가 측정 아님이었다. 원본 출력을 본 뒤 표지를 실제 오류(`ERR_UNSUPPORTED_DIR_IMPORT`와 `testing` 폴더 경로)로 고쳐 다시 돌린 것이 위 결과다.
