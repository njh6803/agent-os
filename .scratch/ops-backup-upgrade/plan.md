# ops-backup-upgrade: agent-os 데이터를 백업하고 새 서버에 복원하며, 판을 올린 뒤에도 옛 트레이스를 읽게 한다.
**슬라이스:** 9
**Blocked by:** release-image

agent-os 데이터의 백업, 복원, 판 올림. 지킬 것은 플러그인 폴더(운영자 파일 포함)와 트레이스 폴더이고, trace-postgres 뒤에는 agent-os의 데이터베이스다. 명령 하나로 백업하고, 새 VM에 복원해 같은 실행 목록과 트레이스가 보이는지 본다. 판 올림은 이미지 태그를 바꾸는 것이고, 옛 판이 쓴 트레이스를 새 판이 읽는지 시험한다(트레이스 헤더의 형식 버전, ADR 0022). 문서 검색 서버의 색인과 원본 문서는 그 저장소의 backup-upgrade가 맡고, 참조 배포의 관리 명령이 두 백업을 차례로 부른다(ADR 0048). 수락: 백업, 새 VM 복원, 판 올림을 안내 문서대로 사람이 돌려 프로브로 남긴다
