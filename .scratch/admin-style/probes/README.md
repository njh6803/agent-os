# admin-style 프로브

admin-style 화면을 그리기 직전의 디자인 시스템 맞추기와 명세(`.scratch/admin-style/spec.md`)가 근거로 드는 측정이다. 규약은 `docs/agents/issue-tracker.md`의 "프로브와 근거"이고 짓는 규칙은 `.claude/rules/probes.md`다.

`.mjs` 프로브는 저장소 루트에서 `node .scratch/admin-style/probes/<파일>`로 돈다. `web/`에 의존성이 깔려 있고(`pnpm -C web install`) Playwright의 브라우저 캐시에 chromium이 있어야 하며, 네트워크는 쓰지 않는다. 임시 앱을 짓는 프로브는 `web/apps/` 아래에 `package.json` 없는 임시 폴더를 만들고 그 `node_modules`를 `web/apps/widget/node_modules`로 잇는 junction을 둔다. 끝에 junction을 재귀 없이 먼저 떼고 대상이 그대로인지 단언한 뒤 폴더를 지운다.

아티팩트를 읽는 일은 Claude Code의 Artifact 도구로만 되어, 도구가 낸 값(판 id, 바이트 수, sha256)을 기록 파일에 옮겨 적고 대조는 design-artifacts의 스크립트가 한다.

저장소 루트에서 돈다.

```sh
node .scratch/design-artifacts/probes/hash_match.mjs --record .scratch/admin-style/probes/artifact_reads.json [--saved <받은 파일 폴더>]
```

받은 폴더는 그 세션의 스크래치패드에 있어 커밋되지 않는다. `--saved` 없이 돌리면 받은 바이트의 sha256 대조 다섯이 빠져 측정 6(양성 다섯, 음성 하나)이다(2026-10-23 셀프 리뷰가 이 워크트리에서 돌린 탐침의 집계 줄 "측정 6, 측정 아님 0, 기대와 다름 0", 종료 0).

변이 표는 `tools/mutate.py`로 저장소 루트에서 돈다.

```sh
PYTHONUTF8=1 uv run python tools/mutate.py .scratch/admin-style/probes/organisms_props_mutations.toml [번호 ...]
```

카나리아 명세는 `tools/canary.py`로 저장소 루트에서 돈다.

```sh
uv run python tools/canary.py .scratch/admin-style/probes/canary/<명세>.toml <출력 디렉터리>
```
