# 07: 실행 목록과 실행 하나를 본다 — 트레이스는 글자로만

**What to build:** 운영자가 실행을 최근 것부터 본다. 상태(일시정지, 끝남, 실패, 결말 없음)로 거르고, 한 쪽을 넘으면 이어서 더 본다. 멈춘 실행은 목록에서 바로 알아본다. 읽을 수 없는 트레이스도 실행 식별자와 이유로 보인다. 실행 하나를 열면 이벤트를 쓴 순서대로 전부, 들어온 모양 그대로 글자로 본다. 요청과 프롬프트, 도구의 인자와 결과, 출력과 에러가 모두 그렇다. 모르는 종류의 이벤트는 원문으로 보이고, 형식 1 트레이스는 "읽을 수 있지만 재개할 수 없다"를 보인다. 트레이스에 든 HTML이나 스크립트는 화면에서 실행되지 않는다.

트레이스는 바깥에서 온 텍스트를 싣는다. 도구 결과와 프롬프트다. 화면이 그것을 HTML로 그리면 XSS가 곧 토큰 유출이다(ADR 0019). 그래서 이 티켓의 가장 무거운 수용 기준은 "글자로만"이다. 결정 자리는 08이 이 화면 위에 세운다.

근거는 `.scratch/web-admin/spec.md`의 "관리 화면 — 화면들"에서 "실행 목록"과 "실행 하나", "문구와 렌더링", "주 이음매", "e2e"의 읽기 흐름 절이다. ADR 0010·0019·0021도 근거다.

**Blocked by:** 05

**Status:** ready-for-agent

### 실행 목록 (`GET /traces`)

- [ ] **행은 서버가 준 순서 그대로다**(스토리 23). 화면이 다시 정렬하지 않는다
- [ ] **상태 넷과 "전부"로 거른다.** 거르면 질의에 `status`가 실린다(스토리 24). 커서로 더 보면 `after`가 실린다(`next_cursor`, 스토리 25)
- [ ] **상태의 이름은 용어집의 말이다.** 일시정지, 끝남, 실패, 결말 없음이다. "결말 없음"이 보이고 "실행 중"은 어디에도 없다(스토리 26, ADR 0021)
- [ ] 행은 실행 요약이거나 읽을 수 없는 트레이스다. 읽을 수 없는 트레이스 행은 식별자와 이유를 보인다(스토리 27)
- [ ] 멈춘 실행은 목록에서 바로 알아보게 한다
- [ ] 새로 고침과 에러는 05의 규칙 그대로다

### 실행 하나 (`GET /traces/{run_id}`)

- [ ] **상세의 응답에는 요약이 없다.** 필드는 `run_id`, `schema_version`, `events` 셋이다. 목록을 거치지 않고 상세로 곧장 들어온 화면도 선다(ADR 0010의 2026-09-24 이력)
- [ ] **이벤트를 쓴 순서 그대로 전부 보인다**(스토리 28)
  - 종류별 필드를 글자로 보인다
  - 모르는 종류(`unknown`)는 원문 문자열을 그대로 보인다(스토리 29)
  - 인자와 도구 결과 같은 JSON 값은 들여쓴 글자로 보인다
  - 마스킹된 인자는 `***`로 보인다(스토리 31)
- [ ] **형식 1이면 "읽을 수 있지만 재개할 수 없다"를 보인다**(스토리 30)
- [ ] **트레이스 내용은 텍스트로만 그린다**(스토리 32)
  - React의 기본 이스케이프에 기댄다
  - `dangerouslySetInnerHTML`(ESLint가 판정한다)과 마크다운의 HTML 렌더를 쓰지 않는다. 마크다운 렌더러를 들이려면 ADR이 필요하다(`tech.md`)
  - 페이지 테스트: HTML이 든 도구 결과(`<img src=x onerror=…>`)가 글자 그대로 보인다. 문서에 그 요소가 없다
- [ ] 없는 실행과 읽을 수 없는 파일은 봉투의 메시지와 `request_id`로 보인다

### e2e — 읽기 흐름을 잇는다

- [ ] **읽기용 트레이스는 테스트 준비가 쓴다.** 끝남, 실패, 형식 1, 모르는 종류의 줄, 읽을 수 없는 파일이다
- [ ] **05의 흐름(토큰, 플러그인 목록)에 잇는다.** 실행 목록을 보고, 실행 하나를 열어 모르는 종류의 원문과 형식 1의 표시를 본다
- [ ] **트레이스의 HTML이 요소로 그려지지 않는 것을 실제 브라우저에서 한 번 더 본다**

### 확인

- [ ] 화면 문구는 한국어이고 용어집의 말을 쓴다(05의 규칙). 실행, 트레이스, 일시정지, 읽을 수 없는 트레이스 같은 말이다. 각 항목의 _Avoid_(예: 실행 중, 대기)를 쓰지 않는다
- [ ] TS 테스트의 이름은 행동을 말하는 한국어 문장이다
- [ ] `CLAUDE.md`의 검증 명령과 e2e가 모두 초록이다
