# 01: 계약 — HTTP 배관이 공용 층으로 가고 실행 전 실패가 둘로 갈린다

**What to build:** 사람에게 보이는 새 동작은 없다. 관리 API는 어휘 하나가 는 것 말고 그대로 답하고, 기존 서버 테스트가 import 경로만 바뀐 채 초록이다. 달라지는 것은 셋이다. 에러 봉투·상태 코드 표·에러 문서·경로 변환기·요청 식별자·인증 미들웨어가 관리 밖의 새 층 `agent_os.http`로 가서, 채널이 원칙 IV를 어기지 않고 같은 것을 쓸 수 있게 된다. core가 실행 전 실패를 **부재**와 **재개 불가**로 갈라 던지고, 표가 그것을 404와 409로 옮길 줄 안다. 그리고 원칙 IV의 문언과 판정자(import-linter)와 `CLAUDE.md`가 새 층을 안다.

이 기능의 계약 티켓이고 나머지 전부를 막는다. 판정자와 문언과 코드가 한 PR에서 움직여야 어긋난 순간이 없고, 층이 실재하기 전에는 규칙을 바꿔도 판정할 대상이 없다(ADR 0016). 리뷰의 질문은 "동작하나"가 아니라 "이 층 경계와 이름으로 오래 살 수 있나"다. 원칙 IV 개정이 들어 있으므로 PR에서 사용자가 바뀐 문언을 본다 — ADR 0016이 승인한 것은 개정의 내용(열거에 `http`가 는다)이지 문언이 아니다.

근거는 `.scratch/http-channel/spec.md`의 "계약 티켓" 절, ADR 0016, ADR 0014와 그 2026-09-24 이력 "재개에서 트레이스가 가리키는 에이전트가 없으면 부재가 아니라 `PluginError`다", ADR 0010의 2026-09-24 이력 "채널이 붙으며 앱의 인자와 에러 어휘가 는다".

**Blocked by:** 헌법 버전 드리프트 정리(`chore/constitution-version-drift`, 대기열 9와 함께 닫는다)의 병합. 저장소 밖의 선행 조건이다. `docs/constitution/README.md`는 2.3.3에 멈춰 있고 그 뒤로 헌법 파일이 여러 PR에서 바뀌었는데, 기점 번호를 정하는 것은 그 정리의 몫이고 사용자 판단이다(대기열 9). 이 티켓은 그 정리가 정한 번호에서 minor를 올린다. 정리가 병합되기 전에는 시작하지 않는다 — 두 PR이 같은 번호를 서로 모르게 쓰지 않는다(명세 검토).

**Status:** done

- [x] 에러 봉투 셋(`ErrorEnvelope`, `ErrorCode`, `Violation`), `failure_for`와 그 표, `install_error_handlers`, `AssignRequestId`, `error_envelope`·`remember_failure`·`request_id_of`, `_documented_errors`, `_Verbatim`, 인증 미들웨어가 `agent_os.http`에 있다. 관리 라우터와 관리의 응답 모델(`Health`, 목록과 상세의 행, 커서)은 `admin`에 남는다. 사본을 두지 않는다 — 같은 스키마가 둘이면 컴포넌트 이름이 부딪치거나 언젠가 어긋난다
- [x] **옮긴 것이 행동을 바꾸지 않는다.** 기존 서버 테스트 전부가 import 경로만 바뀐 채 초록이다. 새 테스트는 하위 타입과 어휘에만 는다. 인증 미들웨어는 동작 그대로 옮기기만 한다 — 접두사→토큰 표를 받는 일반형은 02가 채널 토큰과 함께 만든다
- [x] 헌법 원칙 IV의 의존 방향이 `main → server → {channel | admin | adapters} → http → core → sdk`가 되고 "어댑터는 `http`를 import하지 않는다"가 적힌다. 첫 문장의 금지 열거("`agent_os.core`는 … import하지 않는다")에 `agent_os.http`를 더할지는 층의 순서가 이미 막는 것이라 이 PR에서 문언과 함께 본다. 버전은 minor를 올린다(Blocked by의 번호에서). `CLAUDE.md`의 레이어 목록에 `src/agent_os/http/` 줄이 늘고 의존 방향 줄이 헌법과 같은 문언이 된다
- [x] import-linter가 층 하나와 금지 하나로 판정한다. `agent_os.http`가 `{channel | admin | adapters}` 아래, core 위에 서고, 어댑터가 `http`를 import하는 것을 따로 막는다. 계약 이름의 방향 문자열도 같이 바뀐다. **판정자가 실제로 보는지 변이로 잰다** — 어댑터 하나에, 그리고 core에 `http` import를 넣으면 각각 빨강이다
- [x] **`src/agent_os/` 안의 파일을 스크립트로 실행하는 길이 표준 라이브러리 `http`를 가리지 않는다.** 명세 검토가 쟀다 — 패키지 안에 `http/`가 생기면 그 디렉터리를 `sys.path` 첫머리에 두는 스크립트 실행에서 `import http.cookies`가 새 층을 찾아 죽는다. 지금 `main.py`에 `__main__` 블록이 있어 그 길이 실재한다. 막는 방법은 이 티켓이 정한다. 콘솔 스크립트(`agent-os`)와 `-m` 실행은 지금처럼 된다. ADR 0016의 "표준 라이브러리 `http`와는 절대 import라 부딪치지 않고"가 모듈 실행에서만 참이라는 것을 그 ADR의 이력 한 줄로 남긴다
- [x] `.claude/rules/admin.md`의 HTTP 표면 공통 규칙(봉투와 어휘, 상태 코드 표, 에러 문서, `verbatim`, `operation_id`, 한 줄 독스트링, 테스트 이음매)이 새 층의 rules 파일로 간다. 목록과 상세의 모양과 커서처럼 관리에만 걸리는 것은 `admin.md`에 남는다. `paths`는 새 층과 관리와 `server.py`와, 지금 `admin.md`가 덮는 계약 파일·생성기·테스트를 덮는다. 지침 검사가 glob마다 무언가를 가리키는지 보므로 **아직 없는 채널 HTTP 모듈을 덮는 glob은 그것을 만드는 03이 더한다**
- [x] 그 rules 파일의 테스트 이음매 줄에 예외 하나를 함께 적는다. 같은 앱을 ASGI로 직접 부르는 구동자는 스트림의 수명(조각별 전달, 끊겨도 끝까지, 느린 수신자, 서버가 멈추면 결말 없음)에만 쓴다. 일반 요청으로 번지면 ADR 0010의 2026-09-22 이력이 클라이언트를 손으로 짜는 안을 거부한 논증이 그대로 걸린다
- [x] core의 `PluginError` 아래에 하위 타입 둘이 선다. **부재**는 `run()`이 받은 에이전트가 없는 것과 `resume()`이 받은 실행이 없는 것이다. **재개 불가**는 일시정지가 아닌 실행(끝남, 실패, 결말 없음)과 형식 1 트레이스다. 클래스 이름은 이 티켓이 짓되 HTTP의 어휘(`NotFound`, `Conflict`)를 쓰지 않는다 — core는 상태 코드를 모른다. 이름이 용어집에 자리를 얻을지는 domain-modeling 스킬이 본다
- [x] **`resume()`에서 트레이스가 가리키는 에이전트가 없으면 부재가 아니라 `PluginError`다**(ADR 0014의 2026-09-24 이력). `run()`과 `resume()`이 매니페스트 부재를 던지는 자리를 함께 쓰므로 이 구분은 저절로 생기지 않는다. 테스트가 두 경우를 나란히 고정한다
- [x] 손상된 트레이스, 깨진 매니페스트, 없는 mcp, 마스킹과 승인의 충돌, 진입점 import 실패, 결정 이벤트를 쓰지 못함은 둘 중 어느 것도 아닌 `PluginError`다. `run()`과 `resume()`의 시그니처와 이벤트는 바뀌지 않는다
- [x] CLI는 기반 타입을 잡으므로 진단도 종료 코드도 그대로다. 기존 CLI 테스트가 그것을 판정한다
- [x] **에러 어휘가 다섯이 된다.** `conflict`가 409다. 표가 MRO로 옮긴다 — 부재 404, 재개 불가 409, 그 밖의 `PluginError` 500. 하위 타입의 갈래가 기반 타입의 갈래보다 먼저 와야 하는 것을 테스트가 잰다(순서가 뒤집히면 둘 다 500이 된다). 상태 코드와 어휘가 1:1이라는 테스트와 표 밖의 상태 코드가 계열로 접히는 테스트는 그대로 판정한다
- [x] 관리 라우트는 409를 내지 않고, 관리 쪽 부재는 그대로 포트의 `None`을 라우트가 404로 말한다. `openapi.json`은 어휘에 `conflict`가 는 것 말고 바뀌지 않는다
- [x] 계약 파일의 제목과 설명은 **이 티켓에서 바꾸지 않는다.** 지금의 "읽기 전용이고 실행을 일으키지 않는다"는 채널 라우트가 붙는 03에서 거짓이 되고, 여기서 바꾸면 채널이 없는 main에서 반대 방향으로 거짓이 된다. 명세의 "계약 티켓" 절이 이 티켓에 둔 것을 명세 검토가 03으로 옮겼다
- [x] fastapi의 하한이 `fastapi.sse`가 들어온 버전으로 오르고 `tech.md`의 HTTP 행이 그것과 맞는다. 몇 버전인지는 이 티켓이 재서 적는다(ADR 0014). 그 모듈을 실제로 import하는 것은 03이라 lowest-direct 해석으로 하한을 재 보는 것은 03의 몫이다
- [x] 바뀐 층을 참조하는 문장을 같이 고친다. `README.md`의 트리, `.claude/rules/core.md`의 import 금지 열거, core 패키지 독스트링의 원칙 IV 요약. 옛 의존 방향 문자열(`{channel | admin | adapters} → core`)의 잔존을 저장소 전체에서 grep해 0인지 본다 — 일지, ADR 본문, `.scratch/`의 명세와 티켓(이 티켓 포함)은 기록이라 제외한다
