## 지금 판(2026-10-19 보고, PR #326 병합 뒤)의 문제

보고 파일 372줄 가운데 231줄이 표이고 표는 24개다(`grep`으로 셌다).

1. **표에 제목이 없다.** 상세 1에만 표가 일곱 개 이어지는데, 표마다 무엇을 답하는지 적은 줄이 없다. 해석은 절 끝에 모여 있어 어느
   표의 이야기인지 읽는 사람이 맞춰야 한다.
2. **칸 이름이 내부 말이다.** "그 분에 난 비용", "PR 앞 · 뒤", "최대 세션 컨텍스트", "쉰 뒤의 캐시 재작성", "판단 이름", "배정대로
   돈 몫", "최대 조합의 몫", "문턱 80%", "실제 최대(본 세션 비용)", "다시 읽기 후보", "7일 기준".
3. **내용 없는 칸과 행이 자리를 차지한다.** "알림 후 실제로 고친 비율"과 "예상 절감액(하루)"은 모든 행이 `(수집 안 됨)`이다. 훅 표
   35행 가운데 30행이 판정 `유지`라 결정할 것이 없다(`grep`으로 셌다).
4. **사람이 알아볼 수 없는 값이 있다.** 세션 번호(`96e0da43`), 기록 폴더(`C--project-agent--claude-worktrees-…`).

   센다)인데, 하루치인 표와 같은 모양으로 섞여 있다.
6. **결정이 표 사이에 묻힌다.** 맨 위의 직접 하실 일과 개선 제안 뒤로 일곱 절이 같은 무게로 이어져, 어느 수치가 어느 결정의 근거인지
   보이지 않는다. 매일 거의 같은 표(시작 때 싣는 것, 훅 표, 모델 실험)가 매일 같은 자리를 차지한다.

### 종합 보고의 뼈대 (한 화면, 25줄 안팎)

1. 결론 한 줄: 오늘 정할 것의 수와 가장 큰 변화.
2. 오늘 정할 것(0~3): 질문 한 줄, 추천 한 줄, 근거 한 줄(숫자와 기간).
3. 평소와 다른 것: 지표 | 어제 | 평소(앞 7일 중앙값) | 차이 | 원인. 원인을 모르면 "원인 모름".
4. 평소대로: 지표 이름만 한 줄.
5. 직접 하실 일: 체크 상자.
6. 오늘 나오는 분야별 보고: 한 줄.

### 분야별 보고의 뼈대

- 머리: 결론 두세 줄과 "이 보고에서 정할 것"(없으면 "없음").
- 표 하나가 질문 하나다. 블록마다 `### <결론 문장>`, 그 아래 `<질문> · <기간> · <단위>`, 표(3~7행), "그래서:" 한 줄, "할 일:" 한 줄.
  결론 문장·그래서·할 일은 예약 작업의 모델이 메모로 쓰고, 질문·기간·단위·칸 이름은 수집 도구가 고정한다.
- 블록 사이에 가로줄을 둔다.
- 메모가 블록의 결론·그래서·할 일을 비우면 그리기 도구가 경고한다. 질문·기간·단위가 없는 표는 수집 도구가 만들 수 없게 타입에 둔다.

- 종합 보고는 분야별 보고를 기다리지 않는다. 수집 JSON만으로 그린다. 분야별 보고가 먼저 돌았는지에 기대면 지연 하나로 종합이 빈다.

## 주간 한도 (2026-10-20 추가 요청)

> 사용자: 주간한도를 얼마나 쓰는지도 알고 싶어, 예를 들어 작업이 주간한도의 몇프로를 썼는지 등, 어떤 모델이 주간한도 몇프로를
> 썼는지? 등 너가 추천해줘봐

### 읽을 수 있는 것과 없는 것

- 읽을 수 있는 것: 앱의 `get_usage` 도구가 계정 전체의 한도 셋을 정수 퍼센트와 초기화 시각으로 준다(5시간, 주간 · 모든 모델,
  주간 · Fable). 2026-10-20 21:52 KST에 5시간 36%, 주간 66%(초기화 10-26 06:00 KST), Fable 0%였다. 파이썬 도구나 훅은 이 도구를
  부르지 못하고, 앱 세션의 모델만 부른다.
- 읽을 수 없는 것: 세션·작업·모델마다 한도를 몇 % 썼는지. 한도는 계정 합계 하나다. 그래서 몫은 어림이다.

### 어림 방법

주간 한도가 API 환산 비용에 비례해 찬다고 놓고, 같은 기간의 비용으로 나눠 "주간 한도 1% = API 환산 $X"를 얻는다. 작업·모델의 몫은
그 비용을 X로 나눈 값(%p)이다.

- 2026-10-20에 손으로 센 값(커밋하지 않은 스크립트): 이번 창(10-19 06:00 KST부터)에 njh4803 계정의 비용이 $1,784(계정 모름 $28 별도)이고 주간 66%였다. 1% ≈
  $27, 한도 전체 ≈ $2,700. 같은 때 5시간 창은 $296에 36%로 1% ≈ $8.2였다(5시간 한도 ≈ 주간의 30%). 장부를 스크래치패드에 복사해
  `ingest`로 그때까지 읽고 커밋하지 않은 스크립트로 셌다.
- 비례 가정은 재지 않았다. 모델(Opus·Sonnet)이나 캐시 읽기를 한도가 API 단가와 다르게 셀 수 있다. 하루 여러 번 찍은 한도와 그
  사이의 비용으로 비율이 모델 구성과 상관없이 고른지 본다. 고르지 않으면 모델별 비율을 따로 맞춘다.
- 장부 밖의 사용(claude.ai 대화, 클라우드 세션, 다른 PC, 같은 계정이면 PR 봇)도 한도를 채운다. 그 몫은 비율에 섞여 작업의 몫을
  조금 크게 보인다.
- 한도는 계정마다다. 계정 기록에 njh6803도 있다(10-16부터). 계정을 바꿔 쓰면 계정마다 따로 센다. 그 전 기록은 계정을 모른다.
