# run-feedback: 최종 사용자가 틀린 답을 신고하고, 운영자가 신고된 실행을 관리 화면에서 볼 수 있게 한다.
**슬라이스:** 10
**Blocked by:** pilot-release

답에 대한 오류 신고. 최종 사용자 경로에 실행 하나에 대한 범용 신고(종류와 짧은 글)를 더하고, 위젯에 신고 단추를 두며, 관리 화면에서 신고된 실행을 그 트레이스(인용된 문서 위치 포함)와 함께 본다. 답이 틀렸을 때 알릴 길이 없으면, 운영자가 고쳐야 할 낡은 문서를 찾기 어렵기 때문이다. 신고는 위젯 전용 경로가 아니라 최종 사용자 경로의 범용 기능이다(ADR 0047). agent-os는 신고를 문서 검색 서버에 넘기지 않고, 운영자가 인용된 문서를 문서 검색 서버의 관리자 페이지에서 고친다(의존은 agent-os에서 문서 검색 서버로만 간다, ADR 0048). 신고를 트레이스의 이벤트로 남길지 따로 저장할지는 설계 인터뷰가 정한다. `openapi.json`의 가산 변경이 첫 티켓이고, 위젯의 단추가 마지막 티켓이다. 수락: 위젯에서 남긴 신고가 관리 화면에 그 실행과 인용 문서와 함께 나오는 e2e가 통과한다
