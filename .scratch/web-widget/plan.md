# web-widget: 다른 사이트에 붙이는 채팅 위젯을 만들어, 질문하고 답과 도구 호출과 승인을 대화 안에서 본다.
**슬라이스:** 4
**Blocked by:** conversation, end-user-channel, end-user-continuation, design-system, design-refresh, design-artifacts
**끝:** 2026-10-26

`apps/widget` 채팅 위젯. 같은 React 19 컴포넌트로 Next 16 iframe 페이지와 Vite 라이브러리 빌드의 Shadow DOM 커스텀 요소 번들을 한 앱 폴더에서 낸다. 스타일은 Tailwind, 아이콘은 lucide-react 서브패스. 토큰은 사이트가 준 손잡이(함수, postMessage)로 요청마다 받고 쿠키는 없다. 화면의 교환과, 이어 갈 마지막으로 끝난 실행과 다시 붙을 실행(돌거나 멈춘 것)의 run_id는 sessionStorage에 두고 토큰의 발급자와 `sub`에 묶는다. iframe 페이지는 사이트 파일의 허용 출처로 `frame-ancestors`와 postMessage를 거르고, 그 값은 위젯 빌드의 입력이다(사이트를 바꾸면 다시 빌드, 파일이 없으면 'none'). 사이트(부모) 쪽 postMessage 규약을 임베드 안내에 적는다. 출력과 인자는 텍스트로 그린다. element 번들은 Next의 `public/`에서 내준다. 위젯의 Next에는 rewrites가 없다. `packages/api-client`에 기준 주소를 받는 위젯 클라이언트. 운영의 배치는 TLS를 끝내는 역방향 프록시(ADR 0024의 nginx 항목) 뒤의 한 출처다. 평문 80은 ACME와 HTTPS로 넘기기만 하고 HSTS를 내며, 최종 사용자 접두사는 파이썬에, 위젯은 Next에 정규화한 URI로 넘기고, `proxy_http_version 1.1`, `X-Forwarded-*` 덮어쓰기, 사이트의 요청 크기보다 큰 본문 상한을 둔다. 그 설정은 운영자가 짓고, 이 기능은 설정의 틀(`deploy/nginx/`)과 실제 nginx로 하는 판정을 두지 않는다(06 구현 중에 사용자가 범위에서 뺐다, ADR 0024 이력 2026-10-24, 일지 2026-10-24-10). 위젯 e2e는 같은 출처를 시험 안의 중계로 만든다. 공급망 유예(`minimumReleaseAge`)를 푸는 예외는 들이지 않는다. 최종 사용자 경로의 이어 가기, 실패 원인, 긴 대화의 비용은 end-user-continuation이 더한다(이 행 끝의 2026-10-15 괄호). end-user-channel 명세(2026-10-05)가 넘긴 것: 위젯은 `EventSource`가 아니라 fetch로 스트림을 읽고(`Authorization` 헤더) `Last-Event-ID` 헤더를 직접 보낸다. 요약 이벤트는 투영이 건너뛴다. 운영자 프록시의 본문 상한은 사이트의 요청 글자 수 × 12(JSON 이스케이프에서 BMP 밖 글자가 서로게이트 쌍이 된다)에 본문의 나머지를 더한 값 이상이다. 임베드 안내에 클레임 다섯·수명 600초·`kid`·`sub`의 의무·허용 출처를 적는다. 요청 글자 수 상한의 값은 사이트 파일이 원천이고 위젯 빌드가 허용 출처처럼 거기서 읽어 입력창에 적용한다. 계약의 422 설명에는 단위(코드 포인트)와 기본값 20,000만 글자로 적힌다(2026-10-05 to-tickets에서 사용자가 골랐다). 타임아웃 뒤의 MCP 서버 프로세스는 mcp-shutdown으로 갔다. 설계는 ADR 0024와 ADR 0011·0021 이력, 일지 2026-10-03-03, 측정은 `.scratch/web-widget/probes/`. 화면(대화, 승인 묻기, 실패, 재접속 중, 상한에 걸림)은 명세 직전에 `/ui-design web-widget`으로 design-system의 디자인 시스템을 붙여 와이어프레임과 목업으로 그리고 `.scratch/web-widget/design/`에 옮긴다. 순서는 그 스킬이, 그 폴더의 표는
