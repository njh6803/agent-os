# web-widget 프로브

명세·ADR·코드 주석이 근거로 드는 측정 스크립트다. 규약은 `docs/agents/issue-tracker.md`의 "프로브와 근거".

`jwt_verify/`는 위젯 토큰(사이트 백엔드가 서명한 JWT)을 검증할 라이브러리와 서명 키 종류를 고르는 측정이다. 후보는 PyJWT, joserfc, jwcrypto이고 알고리즘은 HS256, EdDSA·Ed25519(같은 Ed25519 서명의 두 이름, 뒤의 것이 RFC 9864의 새 이름), RS256이다. 셋 다 저장소 루트에서 돌고, 먼저 `make_envs.py`로 후보마다 빈 가상 환경을 만든다. 저장소 `.venv`와 `uv.lock`은 건드리지 않는다.

```sh
PYTHONUTF8=1 uv run python .scratch/web-widget/probes/jwt_verify/make_envs.py <환경 루트>
PYTHONUTF8=1 uv run python .scratch/web-widget/probes/jwt_verify/check_types.py <환경 루트>
PYTHONUTF8=1 <환경 루트>/<후보>/.venv/Scripts/python .scratch/web-widget/probes/jwt_verify/cases.py <후보>
PYTHONUTF8=1 uv run python .scratch/web-widget/probes/jwt_verify/cases.py pyjwt
PYTHONUTF8=1 uv run python .scratch/web-widget/probes/jwt_verify/deps.py <환경 루트> <작업 디렉터리>
```
