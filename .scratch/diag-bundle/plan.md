# diag-bundle: 문제를 살필 때 판과 구성과 최근 실패 원인을 비밀 값 없이 파일 하나로 묶는 명령을 준다.
**슬라이스:** 9
**Blocked by:** release-image

agent-os의 진단 묶음 명령. 판, 구성(매니페스트와 운영자 파일. 값은 지금의 `_describe` 규칙처럼 되울리지 않는다, `adapters/filesystem.py`), 원격 MCP 서버마다의 접속 확인 결과, 최근 실패 실행의 원인(`cause`)과 이벤트 종류와 시각을 한 파일로 묶는다. 트레이스에는 최종 사용자의 글(PRD의 알아 둘 사실)과 검색된 문서 조각이 그대로 있으므로 기본으로 싣지 않고, 운영자가 실행을 골라 명시할 때만 싣는다. 비밀 값은 싣지 않는다(원칙 V). 문서 검색 서버 쪽 진단(색인 상태, 수집 실패)은 그 저장소의 diag-bundle이 맡고, 참조 배포의 관리 명령이 두 진단을 한 묶음으로 합친다(ADR 0048). 수락: 일부러 깨뜨린 배포(모델 서버 꺼짐, MCP 서버 꺼짐, 토큰 불일치)에서 묶음만 보고 원인을 가를 수 있다
