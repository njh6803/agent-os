admin-style 은 그대로 프론티어이고 그 흐름으로 그린다. end-user-continuation 이 2026-10-20 에 닫혔다(티켓 01~06, PR #274 부터, 마지막 잎 02 가 PR #325, 일지 2026-10-20-27). 그때 web-widget 이 풀렸다. 그것을 막던 여섯이 모두 닫혔다. 프론티어는 web-widget, admin-style, mcp-shutdown 이다. 2026-10-20 skill-call-sites 의 설계 인터뷰가 화면을 Claude Code 가 화면 디자인 스킬로 그리게 바꾸고, 웹에서 고친 디자인 시스템을 코드로 들이는 design-reverse-sync 를 열었다(ADR 0025 의 2026-10-20 이력, 일지 2026-10-20-35). design-reverse-sync 를 막는 design-artifacts 는 이미 닫혀 그것도 프론티어이고, 프론티어는 web-widget, admin-style, mcp-shutdown, design-reverse-sync 넷이다. admin-style 과 web-widget 의 화면은 그 스킬이 선 뒤에 그린다. design-reverse-sync 의 설계 인터뷰가 2026-10-21 에 끝났고(일지 2026-10-21-12, ADR 0025 의 2026-10-21 이력) 명세가 같은 날 섰다(`.scratch/design-reverse-sync/spec.md`, 일지 2026-10-22-04). 2026-10-22 에 명세 검토를 거쳐 티켓 열로 쪼갰고(일지 2026-10-22-13), 나란히 돈 티켓 01·02 가운데 01(명암비 모듈)이 먼저 병합되어 기능이 `in-progress`가 됐다(일지 2026-10-22-24). 02 가 이어 병합됐다(일지 2026-10-22-26). 다음은 막힌 것이 없는 03·04·05 다. 그 인터뷰가 design-card-build 를 열었고, 그것은 design-reverse-sync 를 기다려 프론티어가 아니다. mcp-shutdown 이 2026-10-21 에 닫혔다(티켓 01~03, PR #337 부터, 나란히 돈 02 가 PR #340 으로 먼저 들어가고 마지막 잎 03 이 PR #338, 일지 2026-10-21-14). 그것이 막던 기능은 없어 프론티어는 web-widget, admin-style, design-reverse-sync 셋이다.

## 목표 배치

슬라이스가 끝날 때마다 채워진다. 현재 트리는 `README.md`.

```
src/agent_os/
  main.py                  진입점. run → channel, serve → server. 어댑터를 조립해 넘긴다
  server.py                슬라이스 2. create_app() 하나가 FastAPI 앱을 조립한다. 전역 app은 없다(ADR 0010)
  sdk/  core/  adapters/
  channel/cli/             슬라이스 1
  http/                    슬라이스 2. HTTP 표면의 공용 배관(에러 봉투, 상태 코드 표, 미들웨어, 변환기). 채널과 관리가 쓴다(ADR 0016)
  channel/http/            슬라이스 2. POST /runs, POST /runs/{run_id}/approval. SSE(ADR 0014). 슬라이스 4가 최종 사용자 접두사의 시작, 결정, 구독을 더하고(ADR 0023) end-user-continuation이 이어 가기를 더한다(ADR 0022 이력)
  admin/http/              슬라이스 2. GET 넷과 /health. plugin-toggle 이 첫 쓰기 경로 PUT /plugins/{kind}/{name}/enabled 를 더한다. 승인은 여기가 아니라 채널이다
openapi.json               슬라이스 2. 커밋된 계약. tools/export_openapi.py 가 만들고 테스트가 최신성을 본다
web/                       슬라이스 3부터. pnpm 워크스페이스. 파이썬과 루트 분리
  apps/admin/              Next.js 관리 화면. 브라우저가 토큰을 들고 Next 는 rewrites 중계, 루프백만(ADR 0019)
  apps/widget/             슬라이스 4. 채팅 위젯. React 19 컴포넌트로 Next 16 iframe 페이지와 Vite element 번들을 낸다(ADR 0024)
  packages/api-client/     openapi.json에서 openapi-typescript 로 생성해 커밋한다(ADR 0021). 위젯 클라이언트가 는다
  packages/ui/             슬라이스 4. 디자인 시스템. 디자인 토큰과 atoms·molecules, Storybook. 두 앱이 소스를 import 한다(ADR 0026)
deploy/nginx/              슬라이스 4. TLS를 끝내고 최종 사용자 접두사와 위젯만 넘기는 nginx 설정. CI e2e가 판정한다(ADR 0024)
```

첫 슬라이스: `plugins/agents/`의 파이썬 에이전트 하나를 CLI로 실행하면, Anthropic 모델을 호출하고 MCP stdio 서버 하나의 도구를 써서 답을 내며, 실행 전체가 이벤트 스트림으로 나오고 JSONL 트레이스로 남는다. 첫 슬라이스가 끝나기 전에는 만들지 않는 것: 선언적 그래프 정의, 원격·WASM·FaaS 실행, 메모리·RAG, 멀티테넌시, UI, 스케줄러, HTTP 채널, 스킬 로더와 모델 로더(디렉터리와 `kind`만 예약).
