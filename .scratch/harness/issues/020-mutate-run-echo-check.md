# 020: 변이를 돌리는 실행도 표지의 메아리를 보고 걸리면 기준선 전에 끝낸다

**What to build:** `tools/mutate.py`의 표지 메아리 판정(그 시험 파일 원문에 글자 그대로 있는 표지를 알린다, harness 011)은 이름·번호·`--since`로 고른 `--check`와 `--staged`에만 있다. 그래서 변이를 실제로 돌리는 실행(고르지 않은 전체와 고른 것)은 표지가 메아리인 채로 기준선과 변이를 다 돌고 "기대대로"를 찍었다. 변이를 돌리는 실행이 1단계(원문 확인)에서 같은 메아리 판정을 하고, 걸리면 아무 파일도 쓰지 않고 기준선 전에 끝내게 한다. 전체 실행은 표의 변이 모두를 본다. 다시 돌리는 변이는 지금 재는 것이라 옛 변이를 소급하지 않는 까닭(원문만 보는 확인이 옛 표를 갑자기 빨갛게 하지 않는다)이 실행에는 서지 않는다. 고르지 않은 `--check`는 그대로 메아리를 보지 않는다. 값: 이 브랜치의 작업 트리에 있는 표 142개(커밋된 141개와 이 티켓의 새 표) 가운데 16개가 메아리 161건을 가져 전체 실행이 1단계에서 멈춘다(세션 스크래치 스크립트로 `_echo_problems`를 표마다 불러 손으로 셌다, 일지 2026-10-28-12). 그 표는 다시 돌릴 때 표지를 고르거나, 메아리가 없는 변이를 번호로 골라 돌린다. 같은 파일을 대상으로 둔 대기열 350·455·517은 이 티켓에 넣지 않는다.
