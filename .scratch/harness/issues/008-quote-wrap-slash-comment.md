# 008: 인용 대조가 `//` 주석으로 감긴 원문을 펴고, 넘겨받은 파일을 모두 말뭉치에 넣은 뒤 대조한다

**What to build:** `tools/check_quotes.py`의 고침 둘이다. 감긴 줄을 펴는 이음매(`_WRAP`)가 다음 줄 머리의 `#`만 벗기고 `//`는 벗기지 않아, TS·JS의 `//` 주석이 감은 문장을 한 줄로 옮긴 인용을 저장소에 없다고 경고했다. 이음매가 `//`도 벗긴다. 그리고 `check`가 넘겨받은 미추적 파일을 대조하는 차례에 하나씩 말뭉치에 더해, 앞 파일의 인용이 뒤에 넘긴 미추적 파일의 원문을 보지 못했다. 넘겨받은 파일을 모두 말뭉치에 넣은 뒤 대조한다.

**대기열:** 436, 398

**Status:** done
