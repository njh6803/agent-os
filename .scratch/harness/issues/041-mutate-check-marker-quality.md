# 041: `mutate.py --check`가 표지가 없는 빨강과 단언 풀이 줄 표지를 알린다

**What to build:** `tools/mutate.py`의 `--check`(이름·번호·`--since`로 고른 변이)와 `--staged`(커밋에 든 표에서 새로 더했거나 바뀐 변이)가 변이의 표지 품질을 둘 더 본다. 지금은 표지가 시험 원문에 글자 그대로 있는 메아리(대기열 417)만 알린다.

1. 대기열 350. `expect = "red"`인데 `expect_output`이 없는 변이를 알린다. 엉뚱한 까닭의 빨강도 기대와 맞아, `wait_ci` 변이 열다섯이 표지 없이 셀프 리뷰와 PR 직전 리뷰를 지났다(PR #295 CodeRabbit 지적).
2. 대기열 517. 러너의 판정이 pytest인데 표지가 pytest의 단언 풀이 줄이면 알린다. 모양은 `where … = …(`와 `assert … == …`이고 `E` 접두와 들여쓰기는 받는다. 이 줄은 시험이 다른 까닭으로 빨개져도 실리는 호출 기록과 값 비교라 고른 단언이 빨개졌다는 표지가 못 된다(`model-rerun`의 변이 둘이 `where 1 = run()`을 표지로 골라, 러너가 다른 까닭으로 멈춰도 맞았다. PR #408 CodeRabbit 지적).

두 확인 모두 옛 변이를 소급하지 않는다. 저장소의 변이 표 3613 변이 가운데 빨강을 기대한 3571 중 1883이 표지가 없고, 단언 풀이 줄 표지를 든 빨강 변이도 176이다(`.scratch/**/*_mutations.toml`을 `tomllib`로 읽어 이 세션에서 손으로 셌다). 그래서 변이를 돌리는 실행(`_validate`)에는 걸지 않는다. 걸면 옛 표를 다시 돌릴 때마다 멈춘다. 알림은 원문 확인과 같이 문제로 세어 종료 코드 2다.

**대기열:** 350, 517
