# 001: 아침 보고의 "평소와 다른 것"이 동률을 7일 중 최고·최저로 뽑지 않는다

**What to build:** 종합 보고의 "평소와 다른 것" 표는 경보이거나 7일 가운데 최고·최저인 지표만 싣는다(`tools/morning_report.py`의 `verdict`·`unusual`). 지금은 창의 값이 모두 같은 때만 거르고, 다른 값이 하루라도 있으면 어제 값이 창의 최고나 최저와 같기만 해도 다른 날과 동률인 채 뽑힌다. 그래서 PR #332 병합 뒤 첫 확인 실행(2026-10-21, 10-20 보고)에서 어제의 전날 하루만 5이고 어제를 포함한 여섯 날이 0인 "읽지 못한 기록 줄"이 `| 읽지 못한 기록 줄 | 0 | 0 | +0 | 원인 모름 |`으로 올랐다. 어제가 창의 다른 여섯 날보다 높을 때만 최고, 낮을 때만 최저로 본다.

근거는 일지 2026-10-21-04와, 그 확인 실행이 남긴 수집 파일(`~/.claude/scheduled-tasks/daily-morning-report/reports/2026-10-20.data.json`의 `unreadable` 줄)이다. 기능은 `morning-report-split`(설계 `.scratch/morning-report-split/design.md`, PR #332)이고 그 폴더에는 설계만 있고 명세와 티켓이 없다. 이 고침은 명세 없이 티켓 하나로 끝나는 하네스 일이라 ADR 0037의 자리 결정대로 이 폴더에 둔다. 가리키는 대기열 행은 없다.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 어제가 창의 다른 여섯 날 모두보다 높거나 낮으면 지금처럼 `7일 중 최고`·`7일 중 최저`이고, 창 밖의 첫날은 견주는 날에 들지 않는다(평소의 중앙값에만 들어 셋째 줄의 판정에만 닿는다)
