# 021: 대기열 행을 낱말로 찾아 한 줄씩 찍는 옵션을 더한다

**What to build:** retro 5단계의 행 찾기(새 행을 쓰기 전에 같은 일을 다룬 행을 찾는다)에서 Grep 도구가 대기열의 긴 행을 `[Omitted long matching line]` 으로만 내어, 세션마다 맞은 행을 Read 로 다시 열거나 스크래치 스크립트와 `grep … | sed` 로 번호·머리·승인 칸을 찍었다(대기열 425, 4회차). Bash 로 행을 열면(`grep`·`sed`·`cut`) 반대로 한 행 전체가 결과에 실려, 306행(4,079자)이 한 번에 들어왔다(일지 2026-10-22-16). `tools/queue_open_rows.py` 에 `--search <정규식>` 을 더한다. 여러 번 줄 수 있고 하나라도 맞으면 맞은 행이다. 닫힌 행까지 맞은 행마다 번호, 파일의 줄 번호, 열림·닫힘, 회차, 무엇 칸의 머리, 승인 칸을 길이를 묶은 한 줄로 찍고, 같은 일로 보이는 행만 그 줄 번호로 Read 해 연다. retro 5단계의 행 찾기 문장이 그 옵션을 가리키게 고친다.

**대기열:** 425

**Status:** done
