# model-plugin: 모델을 플러그인으로 읽어, 에이전트가 고른 모델 설정을 서버를 다시 띄우지 않고 쓴다.
**슬라이스:** 5
**Blocked by:** 없음
**끝:** 2026-11-01

모델을 플러그인으로 읽는다. 에이전트 매니페스트의 선택 칸 `model`(플러그인 이름. 없으면 기본 모델)로 `plugins/models/<이름>/plugin.toml`을 실행을 준비할 때마다 읽어 그 설정(`provider`, `model_id`, 선택 `max_tokens`·`temperature`)으로 모델을 만든다. 그래서 모델 파일을 고치거나 켜고 끈 것이 서버를 다시 띄우지 않아도 다음 실행부터 듣는다. `--model`·`AGENT_OS_MODEL`은 모델 플러그인의 이름을 받고 코드의 기본값은 없어지며, 기본 모델이 없거나 비었거나 그 이름의 모델 매니페스트가 없거나 읽히지 않으면 구성 오류다(`serve`는 시작 때 한 목록으로, CLI `run`·`resume`은 지금 빈 이름을 거부하는 자리에서). 저장소가 `claude-opus-5`를 둔다. 트레이스는 바뀌지 않고 관리 화면은 모델 행의 안내 줄을 걷고 결정 칸이 에이전트가 고른 꺼진 모델을 미리 알린다. 첫 티켓은 계약: 매니페스트의 칸과 `openapi.json`(ADR 0040. 명세는 core 모델 포트의 모양도 계약에 두었으나 명세 검토가 런타임 티켓 04 로 옮겼다). 설계는 일지 2026-10-31-06. 명세는 `.scratch/model-plugin/spec.md`다(2026-10-31, 일지 2026-10-31-07). /to-spec이 첫 항목으로 받은 것은 기본 모델의 입구와 깨짐의 자리다(core.md의 준비 순서 불변식 부재 → 깨짐 → 꺼짐에 닿는다). 명세가 정한 것: 기본 모델의 이름은 `run()`·`resume()`의 키워드 인자 `default_model`로 들고, 모델 없음·읽히지 않음은 깨짐 안에서 mcp 뒤이며 모델 만들기는 import 뒤 마지막이라 깨짐과 꺼짐이 같은 순서(에이전트 → mcp → 모델)다. 포트 표의 모델 행은 `ModelSource`(매니페스트를 받아 모델을 돌려준다)이고 `ChatModel`은 만든 모델의 타입으로 남는다. 격리 루트의 기본 모델도 `claude-opus-5`이고 시험·스택은 `--model`로 명시한다. 만들기는 1ms 아래(중앙 0.1ms)이고 키·네트워크가 필요 없다(`.scratch/model-plugin/probes/`). 사용자가 고른 것은 시험 자리(core `run()`·`resume()`에 가짜 꽂기) 하나다. 자리는 계약·런타임·가장자리 세 묶음이고 계약 묶음이 먼저다. 2026-10-31 에 명세 검토를 거쳐 티켓 여섯으로 쪼갰다(`.scratch/model-plugin/issues/`, 일지 2026-10-31-08). 검토가 묶음 셋의 순서에서 막힘 둘을 찾아 다시 나눴다. 01 계약(모델 칸·에이전트 `model`·`openapi.json`·`sonnet` 픽스처, 포트와 `default_model` 은 빼서 04 로), 02 매니페스트를 읽지 못한 문구가 잘못 적은 값(`input_value`)을 되울리지 않는다, 03 저장소의 `claude-opus-5` 와 격리 루트·두 e2e 스택의 `--model` 명시(코드의 기본값이 남아 있어 동작은 그대로다. 런타임보다 먼저라 방향이 반대다), 04 런타임이 실행마다 모델을 만든다(포트 `ModelSource`, 준비 순서, 어댑터 한 곳의 제공사 좁힘), 05 코드의 기본값을 걷고 `serve`·CLI 가 시작할 때 기본 모델을 확인한다, 06 관리 화면의 모델 행 안내 줄을 걷고 결정 칸이 에이전트가 고른 꺼진 모델을 미리 알린다(ADR 0019 이력 초안)다. 결정 칸의 미리 알림을 모델까지 넓히는 것과 04 와 06 사이에 화면이 효과를 낮춰 말하는 틈을 받아들이는 것은 사용자가 골랐다. 01·02·03·04 는 병합됐다(04 는 `ModelSource` 포트와 준비 순서, 어댑터의 모델 소스, 두 면의 500·409, `-m llm` 의 바깥 증거까지 끝냈다. 일지 2026-11-01-04). 05 는 코드의 기본 모델 이름을 걷고 `serve`·CLI 가 시작할 때 이름·패턴·매니페스트를 확인하며 멈춘 `run` 의 재개 안내 줄이 `--model` 을 싣게 했다(일지 2026-11-01-05). 06 은 관리 화면의 모델 행에서 안내 줄을 걷고 결정 칸이 에이전트가 고른 꺼진 모델을 미리 알리게 해 기능을 닫았다(ADR 0019 이력, 일지 2026-11-01-06)
