# postgres-foundation 프로브

명세가 근거로 드는 측정 스크립트다. 규약은 `docs/agents/issue-tracker.md`의 "프로브와 근거", 짓는 규칙은 `.claude/rules/probes.md`다. 근거로 드는 자리는 명세(`.scratch/postgres-foundation/spec.md`)이고, 넷 모두 ADR 0066(`docs/adr/0066-agent-os-reaches-postgres-through-sqlalchemy-core-and-asyncpg-and-migrates-forward-only-before-serve.md`)이 명세에 넘긴 어림을 잰다. 설계 인터뷰가 잰 도구 조합은 이 폴더로 옮기지 않았고 `.scratch/admin-login/probes/pg_stack/`에 있다(ADR 0066 결정 "프로브 폴더"). 명세의 절 이름은 "명세" 뒤에 따옴표로 적는다. 결과와 갈래, 재지 못한 것은 폴더마다의 `README.md`에 있다. `requirements.in`은 넷이 함께 쓰는 도구 셋의 판 고정이고, 저장소의 잠금에는 아직 그 셋이 없으므로 폴더마다의 README가 저장소 밖의 사본 나무에 깔아 돌리는 명령을 적는다.
