# 04: 관리 화면 — 앞 실행과 요약이 덮는 끝이 그 실행으로 가는 링크다

**What to build:** 실행 상세에서 시작 이벤트의 앞 실행 필드와 요약 이벤트의 덮는 끝 필드가 그 실행의 상세로 가는 링크다. 운영자는 링크로 대화를 거슬러 보고, 요약을 원문 교환과 대조한다. 값이 없으면(이어 가지 않은 실행) 링크가 아니라 지금처럼 글자다. 요약 이벤트의 글과 토큰 수는 01이 세운 필드 이름 표대로 다른 이벤트처럼 글자로 보인다.

02·03과 나란히 돌 수 있다. 03과 04 가운데 마지막에 병합되는 쪽이 기능을 닫는다.

근거는 `.scratch/conversation/spec.md`의 "관리 화면" 절과 스토리 41~43이다. ADR 0022의 "관리 화면이 새 이벤트를 어떻게 그릴지는 명세가 정한다"가 앞선 결정이다.

- [x] **이벤트 하나를 그리는 자리(`EventItem`)에서 실행 식별자 필드 둘(시작 이벤트의 앞 실행, 요약의 덮는 끝)이 링크다.** 주소는 실행 목록의 링크와 같은 모양(`/runs/` 뒤에 `encodeURIComponent`로 감싼 식별자)이라 트레이스의 값이 경로 밖으로 나가지 않는다. 글자로만 그린다(web-admin 스토리 32). 값이 없으면 글자다
- [x] **이벤트를 그리는 자리의 주석을 고친다.** 지금은 값을 모두 React의 텍스트 자식으로만 넣는다고 적혀 있는데, 링크가 생기면 `href`에 트레이스의 값이 든다. 인코딩으로 경로 밖으로 나가지 않는다는 것과 글자로만 그린다는 규칙이 어떻게 양립하는지 거기 적는다(셀프 리뷰)

- [x] **이어 가기 단추와 대화 단위 화면은 두지 않는다.** 관리는 실행을 일으키지 않는다(용어집 "관리"). 결정은 운영자가 허락했을 때 채널을 쓰는 예외다(ADR 0019)
- [x] **e2e는 늘리지 않는다**
- [x] **기능을 닫는지는 병합 직전에 판정한다.** `git fetch` 뒤 `origin/main`의 03 티켓 파일 `Status:`가 `done`이면 이 PR이 `.scratch/plan.md`의 conversation 행을 `done`으로 바꾸고 프론티어 문단을 고친다. 아니면 03이 닫는다. main이 최신 기준(strict)이라 뒤에 병합되는 쪽은 앞의 병합을 들인 뒤에야 병합되므로 둘이 함께 열려 있어도 한쪽은 반드시 본다

### 이 티켓이 정한 것 (2026-10-05)

근거와 대안은 일지 `docs/journal/2026-10-05-02-admin-links-previous-and-covered.md`.

1. **링크는 `EventItem`의 `RUN_FIELDS`(`previous_run`, `last_covered_run`)와 `FieldValue`다.** 필드 이름이 그 집합에 들고 값이 문자열이면 `next/link`의 `Link`로 `/runs/` 뒤에 `encodeURIComponent`로 감싼 값이고, 아니면 `asText`다. 집합은 이름의 손 목록이다. 생성 타입에서 실행 식별자는 `string`이라 타입으로 가를 수 없다.
2. **`Object.entries<unknown>(event)`.** 필드 값을 컴포넌트의 prop으로 넘기자 ESLint가 `any` 대입을 잡았다(기존 코드는 `asText(unknown)`의 인자로만 넘겨 걸리지 않았다). 엔트리 값의 타입을 `unknown`으로 명시했다.
3. **적대적 트레이스 테스트가 앞 실행에 `javascript:`·`../`·`?`·`#`이 든 값을 둔다.** 링크의 `href`가 `/runs/` 뒤 인코딩한 조각 하나인 것을 단언한다. 이벤트를 그리는 자리의 주석이 글자로만 그리는 규칙과 `href`의 양립을 적는다.
4. **변이 둘.** 구현 전부터 초록이던 가드 둘(값 없는 앞 실행은 글자, 요약 필드의 용어집 말)에 변이를 겨눠 빨강을 봤다(`probes/continuation_mutations.toml`).
5. **기능을 닫았다.** `git fetch` 뒤 `origin/main`의 03 티켓이 `done`이라 이 PR이 `.scratch/plan.md`의 conversation 행을 `done`으로 바꾸고 프론티어 문단을 고쳤다.
6. **PR #133 3회차 리뷰의 Minor 하나를 닫았다.** `CONTEXT.md` 동사 표의 `read` 줄이 `_read_paused`와 어긋났던 것. 뜻을 "포트에서 입력 하나를 읽고 판정해 값으로 만든다. 그 값의 멤버를 채우느라 다른 이름의 읽기(`gather`, 명사구)를 안에서 부를 수 있다"로 넓혔다.
7. **`.`과 `..`은 링크가 아니라 글자다**(PR #134 claude-review 1회차 Minor). `encodeURIComponent`가 그대로 두는 둘은 `/runs/..`이 `/`로 풀린다. `EventItem`의 `runHref`가 둘에 null을 돌려준다. web에 계약의 식별자 패턴 술어를 손으로 옮기지 않고 둘만 가른다. `RunList`는 티켓 밖이라 두었고, 셋째 자리나 `RunList`를 다음에 건드리는 쪽이 `runHref`를 공용으로 올린다.
