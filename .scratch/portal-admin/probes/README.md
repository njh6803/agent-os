# portal-admin 프로브

portal-admin의 명세(`.scratch/portal-admin/spec.md`, 일지 `docs/journal/2026-11-16-1705-portal-admin-spec.md`)가 근거로 든 측정 스크립트와 실험의 색인이다. ADR 0064와 ADR 0065의 Consequences "재지 않은 것"이 이 명세에 넘긴 물음 셋을 본다. 규약은 `docs/agents/issue-tracker.md`의 "프로브와 근거", 짓는 규칙은 `.claude/rules/probes.md`다. 이 폴더의 코드는 프로브의 것이고 제품 코드가 아니다. 프로브마다 그 폴더의 `README.md`가 돌리는 법, 판, 결과, 재지 못한 것의 원천이고, 아래 표는 한 줄씩의 길잡이다.

| 파일 | 재는 것 | 근거로 드는 자리 | 다시 돌 때 | 잰 판 |
|---|---|---|---|---|
| `login_relay/` | 다른 포트의 서버(위젯 관리 서버 대역과 위젯 테스트 페이지 서버 대역)가 운영자의 로그인 쿠키를 Agent OS 대역의 "지금 누구인지"와 "갱신"에 전해 로그인을 이어 주는 흐름. 서버 사이 요청에 실리는 머리, `Set-Cookie` 여러 줄이 브라우저까지 닿는 모양, 갱신을 서버가 스스로 부를 때와 화면이 부를 때의 동시 갱신, 포트가 다른 탭 둘의 동시 갱신과 유예의 두 뜻, HTTP 클라이언트가 쿠키를 기억하는지를 본다. 서버가 Agent OS 대역을 부르는 클라이언트는 다섯이다(`httpx`, `httpx2`, Node의 `fetch`, `node:http`, `openapi-fetch`). 클라이언트마다 잰 범위가 달라, 어느 길에서 무엇을 쟀는지는 `login_relay/README.md`의 "재지 못한 것"이 적는다. 관리 화면 앱의 Next 중계와 Chromium은 실제 것이고 서버 셋은 대역이다 | 명세의 "로그인 확인"과 "위젯 테스트 페이지의 운영자 문", ADR 0064와 ADR 0065의 이력, admin-login의 기능 계획 | `web/`의 의존성(`pnpm -C web install --frozen-lockfile`), Playwright의 Chromium, `uv`와 저장소의 의존성. 네트워크를 타지 않는다. `web/apps/admin/.next/`를 다시 쓰므로 같은 체크아웃에서 두 실행을 함께 돌리지 않는다. 명령은 `login_relay/README.md`의 "다시 돌리기" | Next 16.3.6, Playwright 1.63.0, Chromium 153.0.8010.12, Node 24.19.0, Windows 10, Python 3.12.10, FastAPI 0.141.1, Starlette 1.6.0, uvicorn 0.53.0, httpx 0.28.1, httpx2 2.13.0, openapi-fetch 0.17.0. 원천은 `login_relay/README.md`의 "잰 판" |
| `settings_fetch/` | 위젯 테스트 페이지의 서버가 요청마다 위젯 관리 서버에 사이트 목록을 묻는 것이 페이지 응답에 더하는 시간, "지금 누구인지"까지 차례로 부를 때와 함께 부를 때, 2초 기억과의 차이, 위젯 관리 서버가 내려가 있거나 느리거나 답하지 않을 때의 동작. 서버 셋이 모두 대역이고 PC 한 대의 루프백에서 PostgreSQL만 컨테이너다 | 명세의 "위젯 테스트 페이지 설정을 데이터베이스로", ADR 0064의 이력 | 도는 Docker 데몬과 이미지 `postgres:18-alpine`, PATH의 `node`와 `docker`와 `uv`, psycopg를 처음 받을 때의 네트워크(PyPI). 기본값으로 9~15분이다. 측정이 아닌 회차가 하나라도 있으면 종료 코드가 1이다. 명령은 `settings_fetch/README.md`의 "다시 돌리기" | Windows 10 Home 10.0.19045, Docker 엔진 29.9.2, 호스트의 Node 24.19.0(undici 7.29.0)과 컨테이너의 Node 24.22.3(undici 7.30.2), Python 3.12.10, fastapi 0.141.1, starlette 1.6.0, uvicorn 0.53.0, psycopg 3.3.9, psycopg-pool 3.3.3, uv 0.10.8, PostgreSQL 18.7(`postgres:18-alpine`). 이미지 다이제스트와 잰 때의 부하는 `settings_fetch/README.md`의 "환경" |
| `shared_widget_parts/` | 위젯 앱의 화면 부품 20파일을 공유 패키지 `@agent-os/widget-ui`로 옮긴 패치와, 옮기기 전과 뒤의 검사 결과(타입 검사, 린트, 스토리 시험, 위젯의 사진 비교, 위젯 e2e), 관리 화면 앱에서 그 부품을 값만으로 그려 본 소비자 확인, 그 미리보기를 감싼 요소로 가렸을 때의 접근성 검사와 실제 Tab과 실제 마우스(누르기, 휠). 패치를 붙이는 데서 결과까지를 스스로 다시 내는 프로브가 아니다. 패치를 붙이고 명령을 한 번씩 쳐서 본 실험이라 근거의 종류는 "손으로 봤다"다. 가린 미리보기를 보는 `preview_shield.mjs`는 기대와 견줘 종료 코드를 내지만 패치를 붙이고 Storybook을 지은 체크아웃에서만 돈다 | 명세의 "미리보기를 그리는 부품"과 "미리보기", ADR 0065의 이력 | 기준 커밋 `02dcfe97d`의 체크아웃, Node 24와 pnpm 11, Playwright의 Chromium, Docker(사진 비교), `uv`(e2e의 `serve`). 패치는 기준 커밋에만 붙는다. 명령은 `shared_widget_parts/README.md`의 "다시 돌리는 법"과 "미리보기를 그림으로 가렸을 때" | Node 24.19.0, pnpm 11.24.0, TypeScript 5.9.3, React 19.3.0, Next 16.3.6, Tailwind 4.3.3, Vite 8.3.1, Storybook 10.6.1, Vitest 5.0.2, axe-core 4.14.0, ESLint 10.11.0, Playwright 1.63.0, Chromium 153.0.8010.12, Docker 29.9.2, Windows 10 Home 10.0.19045. 나머지 판과 사진 비교 이미지의 다이제스트는 `shared_widget_parts/README.md`의 "본 판" |

세 폴더 모두 Agent OS의 로그인 경로와 위젯 관리 서버가 지어지기 전의 것이다. `login_relay/`와 `settings_fetch/`의 대역이 고른 것(경로와 쿠키의 이름, 유예의 뜻, 데이터베이스 드라이버)이 admin-login과 widget-admin-server의 명세와 다르게 서면 그 자리를 다시 잰다(명세의 Further Notes).
