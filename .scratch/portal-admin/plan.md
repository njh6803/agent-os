# portal-admin: 질문 페이지 설정을 화면에서 고치는 관리 화면을 질문 페이지 쪽에 두어, 운영자가 파일을 열지 않고 사이트마다의 위젯 설정을 바꾼다.
**슬라이스:** 10
**Blocked by:** pilot-portal

질문 페이지 설정(`CONTEXT.md`)을 화면에서 고치는 관리 화면. 사용자가 pilot-portal 설계 인터뷰에서 다시 꺼낸 요구(사이트마다 위젯을 설정하는 관리 화면이 있어야 한다, 일지 2026-11-09-1410의 "사용자가 앞서 말한 요구를 다시 꺼냄")에서, pilot-portal이 "설정은 파일로, 미리보기까지 지금"으로 범위를 자르며 새 행으로 세운 것이다(ADR 0050 Consequences "다른 행"). ADR 0047대로 위젯 전용 기능은 Agent OS 관리 화면에 두지 않으므로 이 화면은 사이트 쪽인 질문 페이지의 것이고, `serve`와 Agent OS 관리 화면은 이것을 모른다. 질문 페이지 설정 파일(TOML, 사이트 여럿의 목록. ADR 0050. 칸은 pilot-portal 명세 "질문 페이지 설정")이 원천이고 이 화면은 그 파일을 읽고 쓴다. 슬라이스 10은 ADR 0050 승인 화면에서 사용자가 골랐다(제품 1.0 묶음. 0.1 판에는 들지 않는다). release-image의 설계 인터뷰에서 사용자가 요구 하나를 더했다. 이 화면에서 사이트 파일의 허용 출처와 요청 글자 수 상한도 바꾼다(일지 2026-11-11-1532 "위젯 질문에 사용자가 되물었다"). 두 값은 질문 페이지 설정이 아니라 사이트 파일의 것이고, 그 파일을 읽는 세 곳을 함께 고쳐야 바꾼 값이 다시 띄우지 않고 듣는다. `serve`는 사이트 파일을 시작할 때 한 번 읽고(변경 시각으로 다시 읽기는 ADR 0023의 2026-11-04 이력이 정했을 뿐 구현되지 않았다), 질문 페이지도 시작 때 한 번 읽으며(ADR 0050), 위젯은 빌드에 굳는다(ADR 0024). 그래서 release-image의 위젯 컨테이너는 뜰 때 사이트 파일로 빌드하고, 이 행이 나오기 전까지 운영자는 사이트 파일을 직접 고친 뒤 세 컨테이너를 다시 띄운다(ADR 0056 결정 "위젯 이미지"와 "사이트 파일을 고치면"). 사용자는 위젯이 그 값을 실행 중에 읽도록 고치는 일을 이 행을 만들 때 함께 하기로 골랐다. 위젯이 요청 때마다 사이트 파일을 읽는 실험 판의 측정은 `.scratch/release-image/probes/widget_runtime/README.md`에 있다(Windows에서만 돌았다. 그 판은 Next 서버 파일 금지와 `app/` 경계의 ESLint 규칙에 걸리고, ADR 0024가 거부한 예외를 다시 열어야 한다). 위젯이 값을 `serve`에 물어 받아 오는 길은 재지 않았다. 사이트 파일은 채널의 신뢰 설정이라(`CONTEXT.md`) 질문 페이지 쪽의 화면이 그것을 고쳐도 되는지, ADR 0047의 경계와 어떻게 맞추는지도 이 행의 설계 인터뷰가 본다. 설계 인터뷰가 먼저 볼 것: 화면을 질문 페이지 서버가 함께 내는지 따로 서는지, 고친 설정을 질문 페이지가 다시 띄우지 않고 읽게 할지(ADR 0050은 설정 파일과 사이트 파일을 시작 때 한 번 읽는다), 누가 이 화면에 들어오는지(질문 페이지는 익명 최종 사용자에게 열려 있으므로 운영자를 가르는 인증이 필요하다), 이 기능이 질문 페이지 설정에 칸을 더하면 `schema_version`을 올리는지(질문 페이지는 모르는 칸을 거부한다. pilot-portal 명세 "질문 페이지 설정"의 2026-11-10 주석이 이 기능의 명세에 넘겼다). portal-login의 설계가 넘긴 것(2026-11-12): 사용자가 로그인 방식을 화면에서 고르기를 물었고, 0.1 판은 설정 파일로 정하되 화면에서 고르는 일은 이 행이 맡기로 했다(일지 2026-11-12-1937 라운드 2). 그래서 이 화면이 고치는 것에 로그인 서버 항목(`CONTEXT.md`. 방식, 주소, 식별자로 쓸 주장, 유지 시간의 기준, 로그아웃 방식)과 사이트가 가리키는 항목이 든다(ADR 0059 결정 "로그인 서버 항목"). 클라이언트 비밀은 설정이 파일 경로로 가리키는 값이라 이 화면이 그 값을 받아 쓸지는 설계 인터뷰가 본다. 수락: 시험 환경에서 운영자가 화면에서 사이트 하나의 에이전트와 제목을 바꾸면, 질문 페이지의 그 사이트 위젯이 바뀐 값으로 그려지는 테스트가 통과한다
