# portal-admin: 질문 페이지 설정을 화면에서 고치는 관리 화면을 질문 페이지 쪽에 두어, 운영자가 파일을 열지 않고 사이트마다의 위젯 설정을 바꾼다.
**슬라이스:** 10
**Blocked by:** pilot-portal

질문 페이지 설정(`CONTEXT.md`)을 화면에서 고치는 관리 화면. 사용자가 pilot-portal 설계 인터뷰에서 다시 꺼낸 요구(사이트마다 위젯을 설정하는 관리 화면이 있어야 한다, 일지 2026-11-09-1410의 "사용자가 앞서 말한 요구를 다시 꺼냄")에서, pilot-portal이 "설정은 파일로, 미리보기까지 지금"으로 범위를 자르며 새 행으로 세운 것이다(ADR 0050 Consequences "다른 행"). ADR 0047대로 위젯 전용 기능은 Agent OS 관리 화면에 두지 않으므로 이 화면은 사이트 쪽인 질문 페이지의 것이고, `serve`와 Agent OS 관리 화면은 이것을 모른다. 질문 페이지 설정 파일(TOML, 사이트 여럿의 목록. ADR 0050. 칸은 pilot-portal 명세 "질문 페이지 설정")이 원천이고 이 화면은 그 파일을 읽고 쓴다. 슬라이스 10은 ADR 0050 승인 화면에서 사용자가 골랐다(제품 1.0 묶음. 0.1 판에는 들지 않는다). 설계 인터뷰가 먼저 볼 것: 화면을 질문 페이지 서버가 함께 내는지 따로 서는지, 고친 설정을 질문 페이지가 다시 띄우지 않고 읽게 할지(ADR 0050은 설정 파일과 사이트 파일을 시작 때 한 번 읽는다), 누가 이 화면에 들어오는지(질문 페이지는 익명 최종 사용자에게 열려 있으므로 운영자를 가르는 인증이 필요하다), 이 기능이 질문 페이지 설정에 칸을 더하면 `schema_version`을 올리는지(질문 페이지는 모르는 칸을 거부한다. pilot-portal 명세 "질문 페이지 설정"의 2026-11-10 주석이 이 기능의 명세에 넘겼다). 수락: 시험 환경에서 운영자가 화면에서 사이트 하나의 에이전트와 제목을 바꾸면, 질문 페이지의 그 사이트 위젯이 바뀐 값으로 그려지는 테스트가 통과한다
