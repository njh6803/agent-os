# 04: 세션 시작 훅 — 계정을 장부에 남기고 새 요약을 한 번 보인다

**What to build:** 이 저장소에서 세션이 시작되거나 이어지거나 갈라질 때마다, 새 훅 `hook_session_usage`가 그 세션의 계정(계정 ID와 이메일)을 사용량 장부의 계정 기록에 한 줄 남긴다. 그래서 보고서가 합계와 함께 계정별 내역을 낸다. 새 일간 보고서가 생긴 뒤 사람이 처음 세션을 열면 `summary.txt`의 요약 몇 줄이 사람에게만 보인다. 같은 보고서로는 다시 보이지 않고, 보고서가 36시간 넘게 갱신되지 않았으면 그 사실이 맨 앞에 붙어 하루 한 번 보인다. 카나리아 같은 헤드리스 세션은 요약의 몫을 가져가지 않는다.

근거는 `.scratch/token-usage/spec.md`의 "세션 시작 훅"(훅, 계정 기록, 요약, 헤드리스 세션, 자리, 못 보는 것), "사용량 장부와 보고서 도구"의 계정 기록의 줄, Testing Decisions의 훅 항목이다. 요약을 보이는 때는 ADR 0033 이력 2026-10-16 "요약은 새 보고서 뒤 처음 시작한 세션에 보이고 클라우드 세션은 인계하지 않는다"다.

**Blocked by:** 01(러너가 `notice`를 받는다), 02(장부의 자리와 `summary.txt`, 계정 기록을 읽는 쪽)

**Status:** done

### 훅

- [x] SessionStart에 매처 `startup|resume|clear|compact|fork`로 래퍼 모양 등록을 더한다(`tools/run_hooks.py`의 `REGISTRATION`)
- [x] 매번 계정 기록(`ledger/accounts.jsonl`)에 명세 "계정 기록의 줄"의 모양 그대로 한 줄을 덧붙인다. 계정은 `~/.claude.json`의 `oauthAccount.accountUuid`와 `oauthAccount.emailAddress`이다. Claude Code가 그 파일을 다시 쓰는 도중이라 읽지 못하면 짧게 기다려 한 번 다시 읽고, 그래도 못 읽으면 두 칸이 `null`이다. 그 파일의 다른 키는 출력하지도 장부에 남기지도 않는다(대기열 272)
- [x] 출력 폴더는 `CLAUDE_PROJECT_DIR`의 git 공용 디렉터리의 부모(주 체크아웃) 아래다. 워크트리에서 시작한 세션도 같은 곳에 쓴다
- [x] 요약은 `source`가 `startup`이고 요약의 보고서 날짜를 이름으로 한 표지 파일을 `O_EXCL`로 처음 만들었을 때만 `systemMessage`로 보인다. 보고서 날짜는 `summary.txt`의 첫 줄 `보고서 날짜: YYYY-MM-DD`에서 읽는다(명세 "요약 파일". 쓰는 쪽은 02다). 그 줄을 읽지 못하면 요약을 보이지 않는다. `summary.txt`의 수정 시각이 36시간보다 오래됐으면 앞줄을 붙이고 표지 이름에 지역 날짜를 더한다. `summary.txt`가 없으면 침묵이다. 판정은 지금 시각을 인자로 받는 순수 함수다
- [x] 헤드리스 세션을 가른다. 먼저 실제 대화형 세션과 `claude -p` 세션의 SessionStart 페이로드를 저장해 가를 칸이 있는지 본다(저장한 원본은 `.scratch/token-usage/probes/`에 커밋한다, `.claude/rules/probes.md`). 칸이 없으면 `tools/canary.py`가 띄우는 세션의 환경에 표지 변수를 주고, 훅은 그 변수가 있으면 요약의 표지를 만들지 않고 계정만 기록한다. 카나리아 밖의 `claude -p`는 못 보는 것이다. (페이로드에 칸이 없었다. 표지 변수(`AGENT_OS_HEADLESS`)를 주고, Claude Code 가 훅 환경에 주는 `CLAUDE_CODE_SESSION_ATTENDED` 로도 가른다. 둘 다 쓰는 것은 사용자가 골랐다. 아래 "정한 것" 1)
- [x] 독스트링에 무엇을 보고 무엇을 못 보는지 적고, 못 보는 것마다 시험으로 고정한다(`.claude/rules/tools.md`). 세션 도중의 계정 바꾸기, 이 저장소 밖에서 연 세션, 카나리아 밖의 헤드리스 세션이다. (셋째는 위 갈래로 보이게 되어, 그 Claude Code 값이 없는 판의 카나리아 밖 헤드리스 세션과 사람이 보지 않는데 대화형으로 셈하는 세션으로 바뀌었다)

### 정한 것

1. **둘로 가른다(사용자가 골랐다).** Claude Code 가 훅 환경에 주는 `CLAUDE_CODE_SESSION_ATTENDED` 가 `0` 이거나,
   `tools/canary.py` 가 띄우는 세션의 환경에 붙인 표지 변수 `AGENT_OS_HEADLESS` 가 있으면 헤드리스다. 저장한
   페이로드(`.scratch/token-usage/probes/session_start_payload/start.jsonl`)에는 대화형을 가를 칸이 없었다(`model` 은 헤드리스에만
   없었지만 데스크톱 세션의 페이로드는 재지 못해 쓰지 않는다). 같은 실행에서 데스크톱 세션 안에서 띄운 `claude -p` 의 훅은 앞의
   변수를 `0` 으로, 터미널의 대화형 `claude` 의 훅은 `1` 로 받았다. 부모의 값(`1`)을 물려받은 것이 아니라 Claude Code 가 세션마다
   정한 값이다. 실행 파일의 코드(`cli_attended.py`, 2.1.295·2.1.300)는 셸 도구와 훅의 환경을 같은 함수로 짓고, 그 값은 세션
   종류가 백그라운드·데몬이거나 축약된 함수 하나가 값을 내면 `0`, 아니면 "대화형이거나, 시작할 때 `CLAUDE_CODE_CHILD_SESSION` 이
   없었고 진입점이 데스크톱·VS Code 같은 목록에 있다"일 때 `1` 이다. 처음에는 이 값만으로 갈랐는데, 셀프 리뷰의 명세 축이 명세가
   정한 길(카나리아의 표지 변수)을 승인 없이 바꿨다고 짚었다. 그 값은 공식 문서에 없는 내부 값이라 판이 바뀌면 사라질 수 있어,
   사용자가 둘 다 쓰는 길을 골랐다(일지 2026-10-16-66). 표지 변수가 `claude -p` 세션의 훅까지 전해지는 것은
   `start_marker.jsonl` 로 봤다. 명세 221·223·298행을 이 결정으로 고쳤다. 못 보는 것은 그 Claude Code 값이 없는 판의 카나리아 밖
   헤드리스 세션, 사람이 보지 않는데 대화형으로 셈하는 세션(`open-session` 이 연 데스크톱 세션)이다(훅 독스트링). 데스크톱 세션의
   훅이 받는 값은 훅으로 재지 않고 셈했으므로, 실제 데스크톱 세션에서 요약이 보이는지는 09 가 본다(받는 쪽).
2. **출력 폴더 아래 `shown/` 에 `summary-<보고서 날짜>` 다.** 낡은 요약은 `summary-<보고서 날짜>-stale-<지역 날짜>` 다. 지우지
   않아 보고서 날짜마다(낡은 동안에는 지역 날짜마다 하나 더) 빈 파일 하나가 쌓인다. 장부와 같은 폴더라 `.gitignore` 의 `/.scratch/token-report/` 가 덮는다.
