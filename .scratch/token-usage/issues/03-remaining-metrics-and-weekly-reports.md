# 03: 장부의 나머지 지표와 주간·4주 보고서

**What to build:** 02의 `tools/token_report.py daily`가 일간 보고서에 명세 지표 7~12를 더한다. 40만을 넘은 세션과 압축, 쉰 뒤의 캐시 재작성, 시작 컨텍스트(출처별 스킬 목록), 브랜치별 비용과 인계 횟수와 PR 앞뒤의 몫, 캐시 효율, 큰 도구 결과와 반복 Read와 다시 읽기 후보다. 경보 둘도 더한다. 40만을 넘은 세션과 시작 컨텍스트 중앙값의 10% 넘는 증가다. 주가 끝나면 주간 보고서가, ISO 주 넷이 끝나면 4주 요약이 생긴다. 이 셈들은 대기열 273이 고치라고 한 프로브 코드를 옮겨 낸다. 이 티켓이 병합되면 대기열 273이 닫힌다.

근거는 `.scratch/token-usage/spec.md`의 "사용량 장부와 보고서 도구"(세션 행, 지표 7~12, 경보, 보고서 파일과 보관), "대기열 273과 보류 지적"(옮기는 코드, 보류 지적, 거절), Testing Decisions의 보고서 도구 항목이다.

### 세션 행과 지표

- [x] 세션 행에 나머지 칸을 더한다. 인계로 열렸는지(첫 사람 입력이 `이어받을 상태: 인계:` 줄을 든 지시문인지), 시작 컨텍스트와 그 구성, 큰 도구 결과, 읽은 파일과 다시 읽기 후보, 압축, 그 세션이 연 PR이다. 큰 도구 결과의 대상은 Read면 파일 경로, Bash·PowerShell이면 프로그램 이름만이다. 프로그램 이름은 명령 앞의 환경 대입(`이름=값`)과 PowerShell의 변수 대입을 벗긴 첫 낱말이고, 벗긴 뒤에도 `=`나 `$`가 든 낱말이면 남기지 않는다(명세 "장부의 행", 벗기는 선례 `tools/hook_user_settings_read.py`). `TOKEN=… curl`과 `$env:K='…'; …`의 시험으로 비밀이 장부에 없음을 단언한다. 문턱은 06의 훅과 같다(Read 2만 자, Bash·PowerShell 1만 자, 범위 없는 Read만). 06과 이 티켓 가운데 늦게 병합하는 쪽이 두 문턱이 같은지 보는 시험을 더한다(이 티켓이 먼저 병합되어 06이 더한다. 06 티켓에 메모를 남겼다)
- [x] 칸을 더하는 것이라 형식 판 `v`는 1 그대로다(명세 "장부의 행"). 읽는 쪽이 없는 칸을 "모름"으로 셈한다. 02로 손으로 만든 장부가 있으면 `ingest --full`로 다시 쌓는다. 파일을 손으로 지우고 `ingest`만 치면 `state.json`이 남아 그 사이 바뀌지 않은 세션이 빠진다. 계정 기록(`ledger/accounts.jsonl`)은 세션 기록으로 다시 만들 수 없어 `--full`도 건드리지 않는다. 04가 먼저 병합됐으면 그 파일에 실제 계정 줄이 쌓여 있다
- [x] 지표 7~12를 명세대로 낸다. 9절의 스킬 목록은 출처(플러그인, 프로젝트·내장)별이다. 10절은 PR 시각을 모르면 "PR 시각 모름"이다. 레벨 스윕의 갈래별 비교는 넣지 않는다
- [x] 경보 둘을 더한다. 40만을 넘은 세션이 있다. 시작 컨텍스트 중앙값이 지난 7일의 중앙값보다 10% 넘게 크다(호출이 있던 날만 세고 넷보다 적으면 비교하지 않고 그렇다고 적는다)

### 주간·4주 보고서

- [x] 주간은 월요일에서 일요일까지를 그 주가 끝난 뒤 `weekly/<ISO 주>.md`로, 4주 요약은 ISO 주 1~4, 5~8, …, 49~52를 그 묶음이 끝난 뒤 `four-weeks/`에 낸다. 53주가 있는 해는 마지막 묶음에 넣는다. 같은 절에 날짜별·주별 추이를 더한다
- [x] 주간은 최근 4개만 남고, 4주 요약과 장부는 지우지 않는다. 지우는 길은 02의 반박 시험에 주간을 더한다

### 대기열 273

- [x] `.scratch/harness/probes/token_usage/measure.py`의 나머지 셈을 옮기며 고친다. `idle`, `reads`, `rereads`, `plugins`의 스킬 목록, `compactions`다. 압축은 경계 한 건을 값으로 만드는 함수와 출력하는 함수로 나눈다. `reads`·`rereads`·`plugins`가 각자 쓰던 파일 고르기와 겹침 거르기를 공용 반복자 하나로 모은다
- [x] 보류 지적을 값으로 바꾼다. 인자로 받은 목록을 비우고 받은 사전을 바꾸는 `_flush` 대신 무게를 돌려주는 함수로 쓰고, `.scratch/token-usage/probes/measure.py`의 `scan_results` 안 `close`도 같은 모양이라 함께 값으로 바꾼다
- [x] 작은 입력의 시험 둘을 고정한다. 작업 트리를 바꾸는 git 명령의 정규식이 `merge-base`, `worktree list`, 커밋 메시지 속 낱말에 걸리지 않는다. 세션이 하나뿐일 때도 분위수 셈(시작 컨텍스트의 중앙값 등)이 끝난다
- [x] `_simulate`(압축 지점 시뮬레이션)는 옮기지 않는다. 프로브는 ADR 0033의 근거로 그대로 둔다(명세의 거절)
- [x] `.scratch/retro-queue.md`의 273 행에 취소선과 닫힌 자리(이 PR)를 적는다
