# admin-crud: 관리 화면에서 플러그인의 매니페스트와 본문 파일을 직접 만들고 고치고 지우며, 잘못된 내용은 거절한다.
**슬라이스:** 14
**Blocked by:** replay-evaluation

관리 화면 CRUD(후보 21). 매니페스트·본문 파일(`AGENT.md`·`SKILL.md`)·운영자 파일의 원문을 경로별 PUT(새 플러그인은 POST)으로 받아 sdk 판정과 운영자 파일 판정을 지나면 원자 교체로 쓰고 어긋나면 422다. DELETE는 꺼진 플러그인의 폴더를 지우고 켜진 것은 409다. 사이트 파일은 serve가 바뀌었을 때만 다시 읽고 깨진 판은 마지막 좋은 판을 쓴다(ADR 0042 묶음 ⑤)
