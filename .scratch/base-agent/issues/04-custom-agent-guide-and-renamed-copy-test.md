# 04: 커스텀 에이전트 안내 문서를 쓰고, 이름만 바꾼 사본이 원본과 같은 시험을 지난다

**What to build:** 고객사의 요구에 맞춘 커스텀 에이전트를 만들려는 개발자가 `plugins/README.md`를 읽으면, 기본 에이전트가 무엇으로 이루어졌는지, `assistant` 폴더를 복사해 이름을 바꾸는 순서, 무엇을 고치는지, 두 끝을 셈하는 법, 최종 사용자에게 여는 법, 사본이 원본을 따라가지 않는다는 것, 스킬의 지시가 보장이 아니라는 것과 보장이 필요할 때의 길, 확인하는 법, 문서 검색 서버에 붙이는 설정을 읽는다. 그 문서의 순서대로 만든 사본(폴더, `name`, 규칙 파일의 표 이름만 바꾼 것)이 03의 꾸러미 시험을 원본과 똑같이 지난다.

사본을 만드는 시험의 걸음이 안내 문서의 순서와 같아야 하므로 한 티켓이다(명세 "고칠 자리의 묶음"의 D 줄).

근거는 `.scratch/base-agent/spec.md`의 Implementation Decisions "안내 문서"(붙이는 설정의 세부인 `Bearer <토큰>` 전체와 `RAG_ALLOWED_HOSTS`는 같은 명세의 "연결 플러그인 doc-search")와 Testing Decisions "플러그인 꾸러미의 시험"의 "이름만 바꾼 사본" 항목, User Stories 17·18이다. 앞선 결정은 ADR 0051 결정 "커스텀 에이전트를 만드는 길"과 Consequences "사본은 원본을 따라가지 않는다", ADR 0052(두 끝), 기능 계획 `.scratch/base-agent/plan.md`의 "스킬의 지시에는 강제력이 없으므로 … 안내 문서에 한 줄 적는다"다.

**Blocked by:** 03 (기본 에이전트 assistant와 스킬 cite-sources, 연결 doc-search, 규칙 파일의 표를 기본 플러그인 루트에 둔다). 복사할 폴더와 매개변수화할 꾸러미 시험이 03에서 선다.

**Status:** ready-for-agent

### 안내 문서

- [ ] 자리는 `plugins/README.md`다. 로더는 종류 폴더 아래에서 `plugin.toml`이 있는 폴더만 플러그인으로 읽으므로 그 파일은 플러그인으로 읽히지 않는다(명세가 읽은 로더 동작)
- [ ] 내용은 명세의 여덟이다. (1) 기본 에이전트와 플러그인 셋, 규칙 파일의 표가 각각 무엇을 드는지 (2) 복사하는 순서: `agents/assistant`를 새 이름으로 복사, 매니페스트의 `name`을 폴더 이름과 같게, 규칙 파일에 `[agents.<새 이름>]` 표를 기본 에이전트의 세 줄로 시작 (3) 무엇을 고치는가: `mcp`·`skills`·`model`·두 끝과 스킬. 스킬을 고치려면 스킬 폴더도 새 이름으로 복사해 `skills`가 가리키게 한다 (4) 두 끝의 셈: 턴의 끝은 도구 호출의 끝에 2를 더한 값으로 잡고 10을 넘길 수 없다 (5) 열기: 사이트 파일의 열 에이전트 목록에 새 이름을 더하고 위젯의 `agent` 속성에 그 이름을 적는다 (6) 사본은 원본을 따라가지 않는다 (7) 스킬의 지시는 보장이 아니다. 보장이 필요하면 사본의 코드에 고정 단계를 넣는다(코드가 먼저 검색 도구를 부르거나 코드가 문장을 낸다). 도구 호출이 불안정한 모델의 대비책이기도 하다 (8) 확인하는 법: CLI의 `run <새 이름> "<질문>"`으로 돌리고 트레이스를 읽는다
- [ ] 문서 검색 서버에 붙이는 설정(`doc-search`의 주소와 그것을 고치는 자리, 환경 변수 `DOC_SEARCH_AUTHORIZATION`에 `Bearer <토큰>` 전체를 넣는다는 것, 문서 검색 서버의 `RAG_ALLOWED_HOSTS`에 서비스 이름이 들어야 한다는 것)을 적는다
- [ ] 사람이 읽는 안내라 쉬운 말로 쓴다. 명령과 설정은 그대로 붙여 넣을 수 있는 코드 블록이고, 이 티켓에서 실제로 돌려 본 뒤에 싣는다. 돌려 보지 못한 것(실제 문서 검색 서버에 붙는 것 같은)은 돌려 보지 못했다고 적는다(`CLAUDE.md` 원칙)

### 이름만 바꾼 사본의 시험

- [ ] 03의 꾸러미 시험 사례를 원본과 사본 둘로 매개변수화한다. 사본은 시험이 안내 문서의 순서대로 만든다(에이전트 폴더를 새 이름으로 복사, `name` 바꿈, 규칙 파일에 새 이름의 표 더함). 그 밖의 글자는 원본과 같다
- [ ] 사본의 실행에서도 검색은 `allow`, 전문 읽기는 `ask`로 멈추고, 지식베이스 목록은 막힌다
- [ ] 검증 명령이 모두 초록이다
