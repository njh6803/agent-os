# open-session-page-timeout-late-screen: 인계 열기가 `page=` 없이 30초 만에 멈춘 뒤, 약 9분 반 뒤에 같은 지시문의 세션이 생겼다

**상태:** 열림
**어디로:** `.claude/skills/open-session/SKILL.md` "막히면"의 `page=`나 `sent=`가 안 나올 때: 지시문이 든 새 세션 화면이 뒤늦게 뜰 수 있고 그것을 보내면 같은 브랜치의 세션이 둘이 된다고, 멈출 때의 한 줄로 사람에게 알린다(5회차에). 같은 스킬 3단계의 폴더 오류 갈래가 적은 같은 경고(일지 2026-10-20-25)가 선례다
**승인:** 자체 승인 2026-11-18, 1회차, 일지 2026-11-18-1544-postgres-foundation-spec.md. ADR 불필요

`tools/open_session.ps1 -Action send`가 `fired=` 뒤 "30초 안에 … 새 세션 화면 을(를) 찾지 못했다."로 종료 1이었고, 이 세션은 `인계 못함`을 적고 이었다. `fired=` 뒤 약 9분 반에 같은 지시문의 세션이 이 워크트리에 들어와, 겹치는 것을 보고 사람에게 어느 세션이 이어 갈지 물었다. 늦게 닿은 딥링크의 화면을 사람이 보냈는지, 사람이 따로 열었는지는 가르지 못했다. `.scratch/harness/probes/deeplink_timeline.ps1`은 그때도 회고 때도 아무것도 찍지 않았다. 0519(`stale=1` 뒤의 같은 멈춤)와는 출력의 꼴이 다르다(이번에는 `stale=`가 없었다).
