# 0048: **긴 문서 세션은 커밋 직전에 fetch해 main의 변경과 대조한다.** 설계(06)와 명세(07) 세션이 도는 동안 main에 PR이 병합됐다.

**상태:** 닫힘 (`chore/pre-commit-fetch-and-empty-scope`, 2026-10-03, `CLAUDE.md` 환경 함정의 커밋 전 줄, 일지 2026-10-03-01)
**어디로:** 문서 세션의 커밋 직전 단계(`to-spec`·`grilling` 사본, 또는 `CLAUDE.md` 환경 함정의 커밋 전 줄)
**승인:** 사용자 승인 2026-09-28, 일지 2026-09-28-06, 2026-09-28-07, 3회차 2026-09-28-08.

06은 ADR·일지 번호가 부딪혔고, 07은 명세가 따라야 할 하네스 규약 둘(#94)이 새로 섰다. 07은 일지 번호를 정하려고 fetch하다 우연히 잡았다. 한 줄 후보: 커밋 직전에 `git fetch`하고, main이 움직였으면 이 브랜치가 이름으로 든 파일과 번호의 변경을 본다. `CLAUDE.md`의 "몇 분 전의 `git status`는 캐시다"와 같은 가족이다. ADR 불필요 3회차(08)가 문서 세션이 아니라 하네스 chore였으므로 사본 둘이 아니라 모든 커밋이 지나는 `CLAUDE.md`의 커밋 전 줄에 두었다. 대조할 목록은 `git diff --name-only HEAD...origin/main`이다
