# 0028: **retro 훅은 단계를 닫는 쓰기에만 발동한다.** `tools/hook_journal_retro.py`가 일지를 고치는 모든 Write·Edit에 "retro를 지금 돌린다"를 넣는다.

**상태:** 닫힘 (`chore/harness-audit`, 2026-09-28, hook_journal_retro 조건 + 테스트)
**어디로:** `tools/hook_journal_retro.py` + 테스트
**승인:**

2회차다(일지 2026-09-22-07이 1회차로 적었다). 이번에는 retro를 시작한 직후 "검사" 절 한 줄을 고친 Edit가 다시 넣었다. 조건: Write이거나, Edit의 `new_string`이 `## 다음`을 담을 때. 훅을 만든 계기(2026-09-21, 일지를 쓰고도 돌리지 않음)는 Write가 덮는다. 기계적 조건이라 지침이 아니라 훅의 판정을 고친다. **3회차**: http-channel 명세 세션이 회고 결과를 일지에 덧붙인 Edit(`## 다음` 없음)에 다시 걸었다. **4회차**: 티켓 세션이 회고를 먼저 돌리고 일지를 Write한 뒤(여기는 조건대로 발동), 인용 다섯을 원문으로 고친 Edit(`## 다음` 없음) 다섯에 한 번씩 걸었다. **5회차**: 버전 드리프트 세션도 같은 순서였고, 인용 셋을 고친 Edit 셋에 걸었다
