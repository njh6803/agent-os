# probe-readme-run-claim-without-actor: **프로브를 고친 서브에이전트가 프로브 README에 자기가 돌린 것을 주체 없이 "다시 돌렸고", "손으로 봤다"로 적어, 본 세션이 돌린 것과 가려지지 않았다(셀프 리뷰 두 축이 모두 짚었다)**

**상태:** 열림
**어디로:** `.claude/rules/probes.md`: 프로브의 README나 명세가 "돌렸다"·"손으로 봤다"를 쓸 때는 누가 어떤 명령으로 돌렸는지를 함께 적는다는 줄 하나. 프로브를 서브에이전트에 맡기는 브리프(`docs/agents/issue-tracker.md`의 프로브와 근거 절)에도 같은 요구를 한 줄 더할지 반영할 때 함께 본다
