# 0059: **`tools/mutate.py`가 pytest 밖의 명령도 돈다.** 변이 파일에 명령과 빨강의 판정(Vitest는 실패한 테스트 수, tsc는 진단이 난 파일)을 적는다.

**상태:** 닫힘 (`chore/mutate-any-runner`, 2026-10-01, `tools/mutate.py`, `api_client_mutations.toml`, 일지 2026-10-01-01)
**어디로:** `tools/mutate.py` + `tests/tools/`. `.scratch/web-admin/probes/api_client_mutations.mjs`를 TOML로 옮긴다. ADR 불필요
**승인:**

티켓 03이 같은 규약의 JS 러너를 프로브로 새로 지었고, 첫 판정이 틀렸다(tsc의 종료 코드 2를 빨강으로, TS1360을 문법 오류로) 러너 표(`[runner.<이름>]`)와 판정 넷(pytest, vitest, playwright, tsc의 `diagnostic_in`), vitest의 처리하지 않은 에러(`unhandled`), 원문만 보는 `--check`, `tests`로 좁히기, 되돌릴 파일(`restore`). 제자리가 아닌 실행은 코드가 아니라 다른 워크트리에서 돌리는 절차(도구의 `ROOT`가 `__file__`에서 온다)다. `admin_app_mutations.mjs`의 새 파일 변이와 규칙 ID 판정은 받지 않았다
