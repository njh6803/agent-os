# 0572: **파일시스템 어댑터의 읽기 메서드가 `Path.is_file()`의 `OSError`를 `PluginError`로 바꾸지 않는다**(skill-plugin 02의 PR #461에서 CodeRabbit이 짚었고 포트 전체의 결정으로 미뤘다. 03에서 호출 자리를 보니 `read_manifest`가 매 실행에 이미 같은 노출을 갖고 있어 03이 새 종류의 문제를 더하지 않는다고 보고 core에서는 감싸지 않았다. 권한 오류나 끊긴 네트워크 드라이브가 실행 전에 `PluginError`가 아니라 처리되지 않은 `OSError`로 올라온다)

**상태:** 열림
**어디로:** `.claude/rules/adapters.md`와 `core/ports.py`: 읽기 메서드(`read_manifest`·`read_skill`·`read_disabled`)가 `OSError`를 `PluginError`로 바꾸는 규칙을 포트 전체에 하나로 정한다. 포트 계약을 건드리면 ADR 필요
