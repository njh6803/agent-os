# 0225: **Bash의 `cd <하위 폴더> && …`가 셸의 작업 폴더를 같은 체크아웃의 하위 폴더로 옮겨 다음 명령의 상대 경로가 그 자리에서 풀린다**(셋째에 알아채 절대 경로로 되돌렸다. 체크아웃 밖은 `hook_bash_cd_outside`가 막는다)

**상태:** 닫힘 (`chore/bash-hooks-commit-msg-and-cd`, 2026-10-13, `subfolder_notice`. 막을 자리가 없을 때 풀린 자리 하나라도 그 체크아웃의 루트가 아니면 알린다. 들렀다 돌아오는 `cd web && … && cd ..`도 알린다. 일지 2026-10-13-47)
**어디로:** `tools/hook_bash_cd_outside.py`를 넓혀 체크아웃 안의 하위 폴더로 옮기는 `cd`도 계기(additionalContext)로 알린다. 그 테스트와 `tools/hook_payloads.toml`의 발동·비발동 입력
**승인:** 자체 승인 2026-10-13, 3회차, 일지 2026-10-12-36·2026-10-13-10·2026-10-13-22. ADR 불필요
