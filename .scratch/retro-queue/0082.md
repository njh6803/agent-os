# 0082: **python 스텁 훅의 독스트링이 재지 않은 주장을 고친다.** `tools/hook_bash_python_stub.py`는 문자열 안의 python이 명령어 자리가 아니라고 적지만, 따옴표 안이라도 `;` 뒤의 python은 막는다(`echo "a; python x"`).

**어디로:** `tools/hook_bash_python_stub.py` 독스트링과 `tests/tools/`의 그 훅 테스트, `tools/hook_payloads.toml`. ADR 불필요
**승인:** 사용자 승인 2026-10-01, 1회차, 일지 2026-10-01-06.

`sh -c "…; python"`을 막는 것이 의도라면 그렇게 적고, 컨테이너 안의 python(`docker run … -c`)을 못 보는 것(거짓 양성)에 더한다 의도가 아니라 따옴표를 풀지 않은 결과라고 적었다. 셀프 리뷰가 키워드 뒤와 줄 머리도 같다는 것을 찾아(`git commit -m "fix: if python fails"`도 막는다) 함께 적었다. 동작은 바꾸지 않았다
