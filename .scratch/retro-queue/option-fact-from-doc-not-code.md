# option-fact-from-doc-not-code: 설계 인터뷰의 선택지 설명에 문서의 문장을 코드에 대 보지 않고 옮겨, "서버는 이미 재시작 없이 따라가고"가 지금 코드와 달랐다

**상태:** 열림
**어디로:** `tools/hook_choice_facts.py`의 막는 문구: 지금 코드의 동작을 적은 사실은 문서(ADR, `CONTEXT.md`)가 아니라 코드에 대 보고, 문서가 정한 것과 구현된 것을 가른다는 말을 더한다. 규칙이 정한 절차(무엇을 고쳐 쓰고 무엇을 포인터로 다는지)를 설명에 적을 때는 그 규칙 파일을 연다는 말도 더한다. 그 시험과 `tools/hook_payloads.toml`의 페이로드를 함께 본다
**승인:** 자체 승인 2026-11-11, 9회차(0394의 8·9회차), 일지 2026-11-11-1532-release-image-design-round3.md. ADR 불필요

닫힌 0394(막는 훅 `hook_choice_facts`를 낸 항목)를 잇는다. 훅은 화면을 한 번 막아 대 보라고 알렸고, 두 번 모두 대 본 대상이 모자랐다. 8회차는 `CONTEXT.md`의 직전 판 항목과 ADR 0050의 결정 문장만 보고 `serve`가 사이트 파일을 다시 읽는다고 적은 것이다(코드는 시작할 때 한 번 읽는다). 같은 세션이 합의 요약 화면에서 바로잡아 확인받았다. 9회차는 ADR 승인 화면이 "ADR 0046 14줄의 같은 문장을 고칩니다"라고 적은 것이다. `.claude/rules/adr.md`는 본문의 글자를 고치지 않고 포인터와 이력으로 바꾼다. 결과는 같아 답을 다시 받지 않았다.
