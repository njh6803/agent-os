# 회고 반영 대기열

retro 스킬이 낸 후보 가운데 **승인했으나 아직 반영하지 않은 것**만 이 폴더에 항목 파일로 둔다. 항목마다 파일 하나이므로, 나란히 도는 브랜치가 서로 다른 항목을 더해도 병합 충돌이 나지 않는다. 후보와 기각은 일지에 남기고 이 폴더에는 오지 않는다. 승인은 2026-10-12부터 retro가 스스로 판정한다(그 스킬 4단계, 일지 `2026-10-12-41`). 승인 줄은 `자체 승인 <날짜>`로 시작하고, 넘겨서 사용자가 승인했으면 `사용자 승인 <날짜>`로 시작한다.

이 폴더로 옮기기 전의 표(`.scratch/retro-queue.md`)는 지웠다. 그 표가 다시 생기면 저장소 상태 시험(`tests/test_retro_queue_names.py`)이 빨개진다. 결정은 ADR 0045 결정 1이다. 열린 항목과 회차, 만료 후보는 `uv run python tools/queue_open_rows.py`가 한 번에 낸다.

## 파일 모양

파일 이름은 `<ID>.md`이고, ID는 파일 이름에서 `.md`를 뗀 것이다. 내용은 이 모양이다.

```
# <ID>: <머리 한 문장>

**상태:** 열림
**어디로:** <반영할 자리>
**승인:** <승인 날짜, 회차, 최근 일지 파일 이름, ADR 필요 여부>

<본문: 머리에서 못 다 한 설명. 없으면 이 줄부터 쓰지 않는다>
```

- 첫 줄 아래에 빈 줄 하나를 두고, `**상태:**`, `**어디로:**`, `**승인:**` 줄이 이 차례로 이어진다. 세 줄 가운데 하나라도 빠지거나 차례가 바뀌면 도구가 읽지 못하고 저장소 상태 시험이 막는다. 빈 줄 뒤에 본문이 온다.
- 상태 값은 셋이다. `열림`, `닫힘 (…)`, `만료 <날짜> (ADR 0036)`이다. 닫을 때는 상태 줄 하나만 고친다. 취소선이나 표의 칸을 맞추지 않는다.
- 닫힘 꼴은 `닫힘 (<티켓 경로 또는 브랜치>, <날짜>, <한 것>. …)`이다. 티켓으로 닫았으면 브랜치 대신 그 티켓 경로를 적는다(ADR 0037). 부분만 반영해 열어 두는 항목은 상태를 `열림`으로 두고 승인 줄이나 본문에 반영한 몫을 적는다.
- 만료는 retro 5단계가 하는 일이다. 만료는 고쳐졌다는 판정이 아니라 목록에서 내리는 것이다.
- 머리는 한 문장이다. 길어진 설명은 본문에 둔다. 회차의 서술과 효과의 근거는 일지 회고 절이 원천이다(retro 스킬 5단계).
- 어디로 줄에는 반영할 자리를 코드 스팬 경로로 적는다. 괄호 밖의 경로는 대상이고 괄호 안의 경로는 근거로 든 인용이다(`tools/queue_open_rows.py` 독스트링). 계약이나 헌법에 닿는 것은 ADR과 사용자 승인이 따로 필요하므로 어디로 줄에 적는다. 사람이 할 일이면 `사람 몫:`으로 시작한다.
- 기본 반영 자리는 harness 티켓(`.scratch/harness/issues/<slug>.md`)의 `chore/<slug>` 브랜치다(옛 티켓은 `<NNN>-<slug>`). 티켓은 항목 식별자만 가리키고 항목의 내용은 옮기지 않는다(`docs/agents/issue-tracker.md`).

## 이름

- **식별자는 영구하다.** 닫은 항목 파일을 지우거나 이름을 바꾸지 않는다. 일지와 ADR이 `대기열 573` 같은 인용으로 가리킨다.
- **옛 항목**은 번호를 네 자리로 채운 이름이다(`0573.md`). 옛 번호의 가장 큰 값은 581이고, 새 번호는 더 받지 않는다.
- **새 항목**은 retro가 짓는 짧은 영어 제목이다(`coderabbit-inline-size.md`). 영어 소문자, 숫자, 하이픈으로 쓰고 영어 소문자로 시작한다. 숫자로 시작하지 않아 옛 번호와 섞이지 않는다. 한번 정한 제목은 바꾸지 않는다. 같은 제목을 두 브랜치가 더하면 git이 양쪽에서 더함(add/add) 충돌로 알린다.
- 이름이 이 둘이 아니거나, 옛 번호의 가장 큰 값보다 큰 네 자리 번호이면 저장소 상태 시험이 막는다.

## 인용을 푸는 규칙

글에 든 `대기열 <ID>`는 이렇게 파일로 푼다. 새 도구는 없고, 세션은 이 규칙대로 Glob이나 Read로 바로 연다.

- ID가 숫자이면 네 자리로 채운 `.scratch/retro-queue/<0으로 채운 번호>.md`이다. `대기열 573`과 `대기열 0573`은 같은 `0573.md`로 풀린다.
- 숫자가 아니면 `.scratch/retro-queue/<ID>.md`이다.
- `<ID>의 k회차`로 같은 일의 회차를 잇는 말도 같은 규칙으로 푼다. 만료된 번호 항목을 새 항목(슬러그)이 이을 때는 새 항목의 승인 줄에 이어 센 회차(`5회차`)를 적는다.
- 지난 일지와 ADR의 인용은 고치지 않는다.

찾기는 `uv run python tools/queue_open_rows.py --search <정규식>`이다. 맞은 항목마다 파일 경로를 찍으므로, 같은 일로 보이는 항목은 그 파일을 열어 본다.
