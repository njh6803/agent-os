# 0376: **일지 번호를 옮긴 뒤 열린 PR 본문에 옛 일지 경로가 남아 claude-review가 짚었다**(일지 2026-10-13-01·2026-10-13-64는 `--move`가 들기 전에 손으로, 이 일지는 `tools/sibling_overlap.py --move`로 옮긴 뒤다. `--move`를 들인 닫힌 249의 처방은 PR 본문을 다루지 않았고, 그 독스트링이 PR 본문을 옮기지 못하는 것으로 적는다)

**상태:** 닫힘 (`chore/third-round-batch`, 2026-10-20, `--move`가 옮긴 뒤 이 브랜치의 열린 PR 본문을 REST(`gh api repos/<owner>/<repo>/pulls?state=open&head=<owner>:<브랜치>`)로 읽어, 옮길 번호대로 바뀌는 본문만 임시 파일에 쓰고 PR 번호와 올리는 명령(`gh api … --method PATCH -F "body=@<파일>"`)을 한 줄로 낸다. 바뀔 것이 없으면 그렇다고, 읽지 못하면 손으로 보라고 한 줄을 낸다. 본문을 올리지는 않는다. 못 보는 것에 GitHub 아님·분리 HEAD, 포크 PR, gh 실패, 클라우드(REST라 막히지 않을 것으로 보나 재지 않았다), PR 제목을 적었다. 새 시험 일곱(통합 하나. 본문에 날것으로 든 U+0085·U+2028에서 줄을 가르지 않는 하나는 PR 직전 `bug-perf-review`를 받아 더했다), 변이 여덟(`sibling_overlap_mutations.toml`). 그 표에서 원문이 썩어 있던 변이 여섯도 지금 코드에 맞췄다. 일지 2026-10-20-34-third-round-batch.md)
**어디로:** `tools/sibling_overlap.py`의 `--move`: 이 브랜치의 열린 PR 본문(`gh api`)에 옛 번호가 있으면 그 PR 번호와 고칠 명령 한 줄을 출력에 더한다. 그 시험과 독스트링의 못 보는 것(클라우드에서 gh가 막히는 길)
