# 0300: **`git push -h`(도움말)를 `hook_push_behind_main`이 푸시로 보고 막았다**(셀프 리뷰 명세 축 리뷰어가 확인하려고 쳤다. `hook_push_delete_open_pr`도 짧은 옵션 `-h`를 값 없는 옵션으로 넘겨 `git push -h origin --delete <열린 PR 브랜치>`를 막는다, 코드를 읽었다)

**상태:** 닫힘 (`chore/hooks-push-help-and-commit-lock`, 2026-10-16, 일지 2026-10-16-52): 뒤처짐 훅의 `asks_help`와 지우기 훅의 `_push_words`가 `-h`(묶음 포함, `o` 뒤의 글자는 값)·`--help`·`--help-all`이면 지나간다. 값으로 먹힌 `-h`, `--` 뒤, 꼬리 주석 뒤는 도움말이 아니다. 꼴마다 실제 git을 임시 저장소에서 쳐 종료 코드와 원격 ref로 대 보는 시험을 두 훅에 두었고, 뒤처짐 훅의 값을 먹는 긴 옵션 표는 이 기계의 `git push -h`와 맞추는 시험이 본다
**어디로:** `tools/hook_push_behind_main.py`와 `tools/hook_push_delete_open_pr.py`: `-h`(와 그것이 든 짧은 옵션 묶음)·`--help`가 든 `git push`는 푸시하지 않으니 지나간다. 그 시험과 `tools/hook_payloads.toml`의 침묵 사례
**승인:** 자체 승인 2026-10-16, 1회차, 일지 2026-10-16-27. ADR 불필요
