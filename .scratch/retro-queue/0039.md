# 0039: **워크트리에서의 병합 절차.** 사용자 수준 `git-pr-merge`의 `gh pr merge --delete-branch`와 `git checkout main && git pull`은 단일 체크아웃을 전제한다.

**상태:** 닫힘 (`chore/harness-audit`, 2026-09-28, next-session 1단계)
**어디로:** `.claude/skills/next-session/SKILL.md` 1단계
**승인:**

워크트리에서는 main이 주 체크아웃에 있어 로컬 checkout이 실패하고(PR #85, `fatal: 'main' is already checked out at '<주 체크아웃>'`) 원격 브랜치 삭제까지 건너뛰어 원격 브랜치가 남았다. 한 줄: 병합 뒤 `git push origin --delete <브랜치>`로 원격을 지우고, main 최신화는 주 체크아웃이 main이고 깨끗할 때만 `git -C <루트> pull --ff-only`, 워크트리 자신은 `git fetch origin`으로. 워크트리 작업은 이제 흔하다(일지 2026-09-27-02도 워크트리에서 반영했다)
