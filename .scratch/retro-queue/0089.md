# 0089: **`verify`가 같은 실행의 잡 목록을 API로 읽어 `needs` 밖의 잡을 빨강으로 본다.** 잡을 더하며 `needs`에 넣지 않으면 그 잡은 필수 검사 밖에서 돈다.

**상태:** 닫힘 (`chore/verify-needs-check`, 2026-10-01, ADR 0021의 둘째 2026-10-01 이력, 일지 2026-10-01-10)
**어디로:** `.github/workflows/ci.yml`의 `verify`(`actions: read` 권한), 실험 커밋으로 빨강을 본다. ADR 0021의 2026-10-01 이력 중 "자동 검사는 두지 않았다" 문장을 이력으로 고친다
**승인:** 사용자 승인 2026-10-01, 1회차, 일지 2026-10-01-09.

지금은 문서(ci.yml 머리, `operations.md`, ADR, 대기열 34)로만 막는다. YAML 파서 없이 `gh api …/actions/runs/$GITHUB_RUN_ID/jobs`로 판정할 수 있다. 대기열 34보다 먼저 들면 좋다 `verify`가 같은 실행의 모든 시도(`filter=all`)의 잡 목록을 읽어 `needs` 밖의 잡과 빈 목록을 빨강으로 본다
