# 0402: **부동소수 값의 같음을 `==`와 엄격한 `>`·`<`로 가려, 한 ulp 갈린 같은 값이 평소와 다르다거나 7일 중 최고·최저로 뽑혔다**(`tools/morning_report.py`의 `verdict`. 평소와의 `==`는 셀프 리뷰 명세 축이, 다른 날과의 엄격한 견줌은 PR 직전 `bug-perf-review`가 Nit으로 잡았다. 구현 세션은 다른 날과의 동률에는 오차가 끼지 않는다고 적었다가 번복했다. 피연산자가 변수인 실수 견줌은 린터가 타입 없이 가르지 못한다)

**상태:** 만료 2026-11-05
**어디로:** `CODING_STANDARDS.md`(세 번째 반복에서 retro가 더할 때): 더하거나 평균한 실수끼리의 같음은 `math.isclose`로 보고, 같음이 갈래를 가르는 견줌(최고·최저, 평소와 같음)에도 같은 허용 오차를 둔다
