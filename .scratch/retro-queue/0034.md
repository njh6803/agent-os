# 0034: **선언된 의존성 하한을 재는 게이트가 없다.** CI는 `uv sync --frozen`으로 잠긴 버전만 돌아 `pyproject.toml`의 하한이 거짓이어도 초록이다.

**상태:** 만료 2026-10-20 (ADR 0036)
**어디로:** `pyproject.toml`·`uv.lock` + `.github/workflows/ci.yml` + `tech.md`
**승인:** 사용자 승인 2026-09-26, 일지 2026-09-26-03.

티켓 03이 요구해서 잰 lowest-direct에서 fastapi 하한이 거짓이었고(#76이 바로잡음), `langchain-core>=0.3`(0.3.36에서 core 테스트 36개 실패)과 `langchain-mcp-adapters>=0.1`(mcp 상한이 없어 mcp 2.2.0에서 import 실패)은 지금도 거짓이다. 기계가 판정할 수 있어 검사다 — CI에 런타임 의존성만 lowest-direct로 푼 잡 하나(개발 도구는 락). 그 잡은 필수 검사 `verify`의 `needs`에 넣는다. 빠뜨리면 `verify`가 빨갛다(ADR 0021의 2026-10-01 이력 둘). 두 하한을 먼저 올려야 초록이고, 워크플로 변경은 별도 PR로 먼저 병합한다(`operations.md` 리뷰 파이프라인. 2026-09-28 정정: 그 규칙은 `claude-code-review.yml`에만 걸리고 `ci.yml`은 별도 PR이 필요 없다, ADR 0021의 2026-09-28 이력)
