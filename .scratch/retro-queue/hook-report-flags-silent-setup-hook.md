# hook-report-flags-silent-setup-hook: `tools/hook_report.py`가 성공하면 아무것도 내지 않는 설치 훅 `hook_session_web_deps.py`를 "창 안에서 알리지도 막지도 않았다"며 뺄 후보로 낸다

**상태:** 열림
**어디로:** `tools/hook_report.py`: 알리거나 막는 것이 본분이 아닌 훅(성공하면 침묵하는 SessionStart 설치 훅)을 뺄 후보에서 빼고 "판단하지 않는 훅"으로 가르거나, 그 훅이 실제로 깐 횟수를 세는 길을 둔다. 도구의 판정을 고치는 일이라 사건 하나로 반영한다
**승인:** 자체 승인 2026-11-11, 1회차(고침), 일지 2026-11-11-1532-release-image-design-round3.md. ADR 불필요

그 훅은 클라우드 세션에서만 git 훅과 web 의존성을 깔고 로컬 세션에서는 판정만 하고 끝난다(그 독스트링). 보고서는 알림과 막음만 세므로 이 훅은 창 안에서 늘 0건이다. 같은 날의 다른 회고(일지 2026-11-11-1050)도 같은 뺄 후보를 봤다. 보고서가 훅의 일을 세지 못해 뺄 후보로 낸 앞 사건은 닫힌 0404와 0424이고(UserPromptSubmit 훅의 알림), 까닭이 달라 잇지 않는다.
