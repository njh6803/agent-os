# 0083: **사용자에게 영어로 답하면 멈추지 않고 한국어로 다시 쓴다.** `CLAUDE.md`의 "답변과 문서는 한국어로 쓴다"가 있는데도 세션 중간의 보고를 영어로 썼고 사용자가 두 번 고쳤다.

**상태:** 닫힘 (`chore/korean-stop-hook-and-review-brief`, 2026-10-01, 훅 `tools/hook_stop_korean.py`, 일지 2026-10-01-08)
**어디로:** `tools/hook_stop_korean.py`(새 훅), `.claude/settings.json`의 Stop, `tests/tools/`, `tools/hook_payloads.toml`. 거짓 양성(코드만 든 짧은 답)의 문턱은 실제 트랜스크립트로 잰다. ADR 불필요
**승인:** 사용자 승인 2026-10-01, 2회차(일지 2026-09-24-01 보고 언어), 일지 2026-10-01-07.

지침이 어겨진 것이라 막는 훅으로 간다. Stop 훅이 마지막 assistant 메시지에서 코드 펜스·코드 스팬을 뺀 산문의 한글 비율을 보고, 낮으면 멈춤을 막아 다시 쓰게 한다 `tools/hook_stop_korean.py`. 펜스·인용 줄·코드 스팬·링크 대상·URL·식별자를 뺀 산문이 8글자 이상이고 한글이 20% 미만이면 막는다. 문턱은 Stop이 받는 답 754개로 쟀다(막는 답은 모두 0.041 이하, 막지 않은 답의 최저 0.340). 이 행은 2회차(일지 둘)로 적었는데, 트랜스크립트에서 사용자가 "한국어로"라고 고친 것은 세션 넷에서 다섯 번이었다(2026-09-23, 09-30, 10-01에 세션 둘 — 59aeea28의 하나는 작업 중에 보낸 대기 메시지).
