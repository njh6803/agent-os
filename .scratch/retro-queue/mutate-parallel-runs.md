# mutate-parallel-runs: **`tools/mutate.py`의 측정 실행 둘을 같은 체크아웃에서 나란히 띄워, 두 실행의 위젯 빌드가 겹쳐 기준선이 빨개졌다**(answer-markdown 03의 변이 표 수리에서 e2e 표와 실제 모델 표를 한 메시지에 나란히 보냈다. e2e 쪽 기준선이 위젯 빌드가 아직 돌고 있다는 Next의 오류로, 실제 모델 쪽 기준선이 217초를 쓰고 빨강으로 끝났고, 둘 다 변이를 넣지 않아 소스에는 변이가 남지 않았다. 따로 차례로 돌리자 기준선이 초록이었다)

**상태:** 열림
**어디로:** `tools/mutate.py`의 `_running_marker`: 표지를 쓰기 전에 같은 git 디렉터리에 pid가 살아 있는 다른 표지가 있으면 측정을 시작하지 않고 멈춘다. 표지의 pid가 다른 프로세스에 넘어간 경우는 시작 시각으로 가른다(대기열 449). 확인과 생성 사이에 틈이 없도록 표지를 배타적으로 만들어 한 번에 얻고(`O_EXCL`), 동시 시작 시험을 `tests/tools/test_mutate.py`에 둔다. 독스트링의 못 보는 것에 이 도구가 막지 못하는 길을 적는다
**승인:** 자체 승인 2026-11-14, 381의 4회차(381이 3회차로 만료돼 이어 센 회차이고, 그 항목이 처방한 둘째 시작 거부는 구현되지 않았다. 편집 훅은 알릴 뿐 둘째 실행을 막지 못한다), 일지 2026-11-14-0126-widget-renders-answers-as-markdown.md. ADR 불필요
