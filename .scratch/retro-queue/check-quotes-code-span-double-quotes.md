# check-quotes-code-span-double-quotes: `tools/check_quotes.py`가 코드 스팬 안에 큰따옴표가 든 인용을 저장소에 없다고 경고했다

**상태:** 열림
**어디로:** `tools/check_quotes.py`: `_blank_code`가 짝을 맞추려고 코드 스팬 안의 따옴표를 지운 글을 그대로 인용으로 뽑아, 따옴표가 남은 원문과 맞지 않는다. 짝은 지운 글로 맞추되 대조는 그 자리의 원래 글로 하거나, 말뭉치 쪽에도 같은 지우기를 한 사본을 둔다. 그 꼴의 시험을 `tests/tools/`에 더한다
**승인:** 자체 승인 2026-11-18, 1회차(고침), 일지 2026-11-18-1544-postgres-foundation-spec.md. ADR 불필요

그 일지의 "PR 직전 리뷰에 밀 주장" 목록 6(명세의 문장 가운데 코드 스팬에 `"agent_os"`가 든 것)이 명세에 글자 그대로 있는데 경고였다. 회고 때 `quotes_in`을 불러 보니 뽑은 인용에서 `"agent_os"`의 따옴표가 빠졌고, `normalize`는 원문의 따옴표를 남겼다(손으로 봤다). 같은 커밋의 다른 경고 하나(목록 12)도 원문에 글자 그대로 있었지만 이 꼴인지는 가르지 않았다. 경고만 내는 검사라 손상은 없고, 세션이 grep으로 한 번 가렸다.
