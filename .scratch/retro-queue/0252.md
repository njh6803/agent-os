# 0252: **`hook_bash_cd_outside`의 하위 폴더 `cd` 경고(대기열 225)를 받은 뒤에도 같은 세션이 하위 폴더로 두 번 더 옮겼다**(`cd web/packages/ui`, `cd …/src/components`. 셋째 뒤 변환기가 하위 폴더에서 돌아 모듈을 찾지 못했다)

**상태:** 닫힘 (`chore/existing-hook-fixes`, 2026-10-16, 하위 폴더의 이유로 막고(대안 `-C`·서브셸을 안내한다) 알림 갈래를 걷었다. 밖으로 옮기는 자리가 있으면 그 이유를 먼저 낸다. 셸이 이미 하위 폴더에 있으면 이유가 지금 작업 폴더와 루트로 돌아오는 길을 적는다. 한 호출 안에 머무는 `cd web && …`도 막는다(대안이 있다). `;`로 늘 돌아오는 꼴과 서브에이전트의 `cd`는 거짓 양성으로 못 보는 것에 적었다. 일지 2026-10-16-27)
**어디로:** `tools/hook_bash_cd_outside.py`: 체크아웃 안 하위 폴더로 옮기는 맨 `cd`(서브셸로 가두지 않은 것)를 경고에서 막기로 올린다(지침으로 적은 뒤에도 어겨졌다, `.claude/rules/tools.md`의 계기·막는 훅 가름). 그 시험과 변이
