# 0500: **시험이 외부 도구의 판마다 바뀔 수 있는 세부(`git push -h`의 종료 코드 129)를 단언해, GitHub 러너 이미지가 git 2.55.0에서 2.56.0으로 오르자 코드 변경 없이 새 이미지에 걸린 PR(#403)의 필수 검사 verify가 빨개져 병합이 막혔다**(harness 018. 두 푸시 훅 시험의 `test_도움말_판정이_실제_git_과_같다` 열 갈래. 훅의 판정 코드는 종료 코드를 보지 않았고, 시험만 그 값에 기댔다)

**상태:** 열림
**어디로:** 대상 미정, 회차 감시. 기계로 가를 수 없는 판단이라 5회차에 `CODING_STANDARDS.md`에 "외부 도구를 실제로 부르는 시험은 그 도구가 판마다 바꿀 수 있는 값(종료 코드, 메시지 문구)이 아니라 관찰할 결과(상태의 변화, 이 저장소가 읽는 표지)로 가른다" 한 줄을 고른다. 새 줄 대신 이웃한 22줄(실패를 기대하는 테스트는 실패의 까닭까지 단언한다, 대기열 144)을 넓히는 길도 함께 본다
