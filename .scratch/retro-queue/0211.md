# 0211: **루트에서 경로 패턴을 준 Glob이 시간 초과로 끝났고, `.claude/**` 패턴의 Grep이 `.claude/worktrees/` 아래 다른 워크트리(이 PC에 40개, `ls -d`로 셌다, 2026-10-12)의 파일을 함께 냈다**

**상태:** 닫힘 (`chore/path-pattern-gitignore`, 2026-10-19, 넘었다. Glob은 패턴과 상관없이 `.gitignore`를 보지 않고, Grep은 glob(중괄호면 갈래 하나)에 바로 맞는 무시된 파일과 폴더만 넘었다(표지 파일과 `.venv`·`.claude/settings.local.json`으로 손으로 봤다). Glob이 ripgrep에 `--no-ignore --hidden`을 기본으로 넘기는 것은 claude 2.1.299 실행 파일을 읽었다. 2026-10-12에 다른 워크트리의 파일을 낸 Grep은 맨 `.claude/**`가 아니라 갈래에 `.claude/**`를 둔 중괄호 glob이었고, 같은 세션에서 갈래를 `.claude/**/*.md`로 끝낸 앞 호출은 워크트리 줄을 내지 않았다(그 세션의 트랜스크립트를 읽었다). `CLAUDE.md` 환경 함정에 Glob 줄과 Grep 줄을 더했다. `tidy-checkouts`의 정리 범위는 바꾸지 않았다. 살아 있는 워크트리와 체크아웃마다의 `.venv`·`node_modules`는 그 스킬이 지울 것이 아니다, 일지 2026-10-19-21-path-pattern-gitignore.md)
**어디로:** 경로 패턴이 `.gitignore`를 넘는지 재고(어림: ripgrep의 `--glob`이 무시 규칙보다 앞선다), 넘으면 `CLAUDE.md` 환경 함정이나 `tidy-checkouts`의 정리 범위에 둔다
**승인:** 사용자 승인 2026-10-12, 1회차, 일지 2026-10-12-37. ADR 불필요
