# 0245: **`tools/run_hooks.py` 독스트링의 "자리표시자 열일곱"이 실제 열여덟인 채 충돌 없이 합쳐졌다**(이 브랜치와 PR #225가 자리표시자를 하나씩 더하며 둘 다 "열여섯 → 열일곱"으로 고쳐 git이 같은 변경으로 하나로 합쳤다)

**상태:** 닫힘 (`chore/hook-list-check-and-timing-guards`, 2026-10-17, 독스트링의 `${…}` 집합과 `fixtures()`의 키, 표 머리의 `# 기대:` 값과 `Expectation`을 견주는 저장소 상태 시험 둘과 변이 넷(`.scratch/harness/probes/hook_list_and_timing_guards_mutations.toml`). 수 낱말과 표 머리의 자리표시자 줄을 지웠다, 일지 2026-10-17-12-hook-list-check-and-timing-guards.md)
