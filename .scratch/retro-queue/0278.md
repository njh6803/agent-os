# 0278: **지우는 도구의 반박 시험이 꺼낸 자리 안의 링크를 넣지 않아, `git worktree remove --force`가 junction을 따라가 바깥 파일을 지우는 길이 셀프 리뷰를 지나 PR 직전 `bug-perf-review`에서야 Major로 나왔다**

**상태:** 닫힘 (`chore/rules-tools-tests-batch`, 2026-10-16, `.claude/rules/tools.md`의 지우거나 덮어쓰는 도구 항목. `tools/tidy_checkouts.py`에는 `_cut_links`가 없어 그 파일의 선례는 링크 자체만 지우는 `delete_path`로 적었다. 같은 입력 예를 옮겨 적은 `tidy-checkouts` 스킬의 "하지 않는 것" 표도 고쳤다. 카나리아 `tools_rule_thread_job_and_links.toml`·`tidy_skill_link_input.toml`, 일지 2026-10-16-16)
**어디로:** `.claude/rules/tools.md`의 지우거나 덮어쓰는 도구 항목: 판정을 깨려는 입력의 예에 지우는 자리 안의 링크(심볼릭 링크, junction)를 더한다(선례는 `tools/tidy_checkouts.py`와 `tools/canary.py`의 `_cut_links`)
**승인:** 자체 승인 2026-10-15, 1회차, 일지 2026-10-15-19. ADR 불필요.
