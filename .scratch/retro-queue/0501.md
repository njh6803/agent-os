# 0501: **445의 13회차(421부터 셈). 일지를 Bash heredoc(`cat >>`)으로 덧붙여 `tools/hook_journal_evidence.py`의 계기가 닿지 않은 채, 잡 로그를 보지 않은 git 판("러너의 git 2.56")을 본 것처럼 적었다**

**상태:** 닫힘 (.scratch/harness/issues/019-journal-evidence-bash-writes.md, 2026-10-28, 같은 훅이 PostToolUse 의 새 `Bash` 묶음으로 명령 글을 읽어 일지 경로에 쓰는 꼴(`>`·`>>`, `tee`, `sed -i`, 쓰기를 하는 `python`)이면 Write·Edit 와 같은 표지로 한 번 알린다. 읽기만 하는 명령과 PowerShell 은 알리지 않고 독스트링의 "못 보는 것" 에 적었다. 시험과 변이 서른셋)
**어디로:** `tools/hook_journal_evidence.py`와 `.claude/settings.json`: Bash 명령이 `docs/journal/` 아래 `.md` 를 쓰는 꼴(리다이렉트 `>`·`>>`, `tee`, `sed -i`, 그 경로를 든 `python -`)일 때도 같은 계기를 넣는다. 판정이 명령 글을 읽는 것이라 거짓 양성(일지를 읽기만 하는 `cat`)을 가르는 꼴을 반영할 때 정한다. `.claude/rules/tools.md`의 계기 훅·막는 훅 가름을 따른다
**승인:** 자체 승인 2026-10-27, 13회차(421의), 일지 2026-10-28-01-git-help-exit-code.md. ADR 불필요.
