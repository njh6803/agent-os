# 0176: **`tools/gh_run_summary.py`가 거부 수와 훅 오류를 보여 주지 못하고 도구 결과의 원문을 신호로 쏟는다.** Claude Code 2.1.292의 결과 블록은 `permission_denials_count`가 아니라 `permission_denials` 배열을 내 0건과 키 없음이 갈리지 않았고, `::error` 패턴이 Read로 읽은 워크플로 원문 줄(약 6KB)에 두 번 걸렸으며, `hook_response`의 `outcome: error`(종료 127)는 찍지 않았다

**상태:** 닫힘 (`chore/run-summary-and-lock-holder`, 2026-10-12, 로그의 JSON 객체를 통째로 읽어 결과 블록의 거부 배열, 오류인 훅 응답, 알림을 따로 찍고, 신호는 JSON 밖 줄의 `##[warning]`·`##[error]`에서만 잡는다. 실패한 PR #172 실행의 `##[error]` 세 줄은 옛 패턴이 놓쳤던 것이다. 변이 표 `gh_run_summary_mutations.toml`. 일지 2026-10-12-08)
**어디로:** `tools/gh_run_summary.py`와 그 테스트
**승인:** 사용자 승인 2026-10-12, 1회차, 일지 2026-10-12-04. ADR 불필요
