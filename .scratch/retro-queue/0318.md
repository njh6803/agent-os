# 0318: **새 실제 프로세스 시험이 쓴 git 훅 스크립트에 실행 권한을 주지 않아, 이 PC에서는 초록이고 리눅스 CI의 git은 그 훅을 건너뛰어 시험이 빨개질 뻔했다**(PR 직전 `bug-perf-review`가 잡았다. 이 PC에서만 초록인 시험의 둘째 꼴이고 첫째는 281이다)

**상태:** 닫힘 (`chore/tests-rule-batch`, 2026-10-19, `.claude/rules/tests.md`의 pwsh 항목을 `tests/tools/`의 시험은 CI의 리눅스에서도 돈다는 일반 조항으로 올리고, 실행 권한(선례 `tools/run_hooks.py`의 `committing_repository`)과 pwsh 윈도 전용 형식을 그 예 둘로 두었다. 카나리아 `tests_rule_linux_exec_bit.toml` 통과 4, 옮긴 pwsh 예는 `tests_rule_pwsh_linux.toml` 사전 확인으로 갈음, 일지 2026-10-19-11-tests-rule-batch.md)
**어디로:** `.claude/rules/tests.md`: pwsh 시험 항목을 `tests/tools/`의 시험은 CI의 리눅스에서도 돈다는 일반 조항으로 올리고, 윈도에서는 없어도 되는 것(윈도 전용 형식, 시험이 쓰는 스크립트의 실행 권한)을 그 예로 둔다. rules를 바꾸므로 카나리아를 돈다
