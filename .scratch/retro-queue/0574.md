# 0574: **명세가 연결 직후 실패 문구에 운영자 파일의 규칙 줄을 "적힌 그대로" 싣게 정해, 명세 검토와 셀프 리뷰 두 축과 PR 직전 리뷰 둘이 지나간 뒤 PR 봇이 Major(원칙 V, 맨 도구 이름 자리에 비밀이 든 줄이 트레이스에 남는다)로 짚었다**(approval-rules PR 472 첫 회차. 같은 기능의 깨짐 문구가 모르는 키의 값을 되울리는 것은 명세 검토가 잡아 값을 벗기게 고쳤는데, 둘째 문구는 같은 부류인데도 놓쳤다. 일지 "PR 직전 리뷰"의 보안 축은 이 길을 문턱 아래 참고로만 적었다)
