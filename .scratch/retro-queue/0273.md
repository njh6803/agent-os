# 0273: **세션 기록으로 토큰·비용을 잴 때 저장소 단가표(`session_cost/costs.py`)를 모르고 근사 가중치로 셌고, 폴더 둘에 겹친 기록을 두 번 셌다**

**상태:** 닫힘 (`feature/03-remaining-metrics-and-weekly-reports`, 2026-10-16, 티켓 02가 `tools/token_report.py`와 `CLAUDE.md` 지도 행, 단가표, 겹침 거르기, 호출 모으기·`split`·유형 잇기, `REPO_PREFIX` 제거를 들였고, 티켓 03이 `idle`·`reads`·`rereads`·`plugins`의 스킬 목록·`compactions`를 옮기며 고쳤다. 파일 고르기와 겹침 거르기는 한 번 고른 사본을 `read_stream`이 한 번 읽는 길 하나로, 압축은 `compaction_of`와 글 함수로, `_flush`는 실려 간 호출 수를 돌려주는 `carried_of`로 나눴다. `GIT_MUTATION`의 `merge-base`·`worktree list`·커밋 메시지 낱말과 세션 하나뿐인 분위수 셈을 작은 입력의 시험으로 고정했고 `_simulate`는 옮기지 않았다(명세의 거절). 일지 2026-10-16-69)
**어디로:** ADR 0033의 보고서 도구 티켓: 측정의 기본 길(보고서 도구, `token_usage/measure.py`, 단가표, 겹침 거르기)을 그 도구의 독스트링과, 토큰·비용을 묻는 요청이 닿는 자리(`CLAUDE.md` 지도 한 줄이나 스킬 설명)에 둔다. 프로브의 코드를 옮길 때는 이 PC 경로에 묶인 상수(`REPO_PREFIX`)를 인자나 설정으로 빼고 `dict` 매개변수에 타입을 채운다. 한 함수에 섞인 단계를 나누고(`cmd_compactions`는 경계 한 건을 데이터 클래스로 만드는 함수와 출력 함수로), `reads`·`rereads`·`plugins`가 각자 쓰는 파일 고르기·겹침 거르기 루프를 공용 반복자 하나로 모은다. PR 직전 버그 리뷰가 잡은 자리(`_simulate`가 압축 뒤 호출마다 압축하지 않는지, `GIT_MUTATION`에 `merge-base`가 걸리지 않는지)와 셀프 리뷰가 보류한 자리(남은 세션이 하나일 때의 `statistics.quantiles`)를 작은 입력의 시험으로 고정한다(PR #249 claude-review·셀프 리뷰)
**승인:** 자체 승인 2026-10-15, 1회차, 일지 2026-10-16-01. ADR 불필요(ADR 0033의 범위)
