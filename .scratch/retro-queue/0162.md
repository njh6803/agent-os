# 0162: **`hook_env_read`의 읽기 명령 목록에 Claude Code가 묻지 않고 돌리는 `column`·`rev`가 없다.** 대기열 146의 탐침에서 둘이 glob 경로로 `.git/config`를 읽거나 권한 단계를 지났다
