# rag-engine-port-by-hand: **agent-os의 하네스 변경(스킬, 훅, 일하는 규약)을 문서 검색 서버 저장소(rag-engine)에 손으로 옮긴 일을 회차로 센다**(사용자가 공통 저장소나 플러그인으로 뽑는 때를 세 번째 프로젝트가 생기거나 같은 변경을 손으로 옮기는 일이 여러 번 쌓였을 때로 정했다. 이 항목을 쓴 2026-11-11에는 옮긴 일이 아직 없다)

**상태:** 열림
**어디로:** 공통 저장소나 플러그인(저장소와 무관한 조각부터 뽑는다. 새 저장소를 세우는 일이라 뽑기 전에 사용자에게 묻고 ADR을 쓴다)
**승인:** 사용자 승인 2026-11-11, 0회차, 일지 2026-11-11-1532-release-image-design-round3.md. 뽑을 때 ADR 필요

회차는 agent-os의 세션이 rag-engine의 세션에 줄 지시문을 사용자에게 낼 때 더한다. 지시문 하나가 손으로 옮기는 일 하나다. 예정된 첫 둘은 dev 브랜치 전환과 판 내기 워크플로이고, 그 지시문을 내는 자리는 `.scratch/plan-head.md`의 dev 전환 문단과 `.scratch/release-image/plan.md`의 본문이 적는다. 세 번째 프로젝트가 생기면 회차와 무관하게 뽑을지를 사용자에게 묻는다. 그때까지는 공통 ADR 저장소도 공통 하네스 저장소도 두지 않고, 일하는 방식의 원천은 agent-os다(같은 일지 "인계한 세션에서 사용자가 정했다"). 두 저장소가 벌어진 곳을 알리는 점검 도구는 `rag-engine-harness-drift`의 일이다.
