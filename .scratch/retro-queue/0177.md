# 0177: **`tools/tidy_checkouts.py`가 워크트리 폴더를 쥔 프로세스의 이름을 대지 못해, 남긴 이유가 "다른 프로세스가 쥐고 있다"에서 멈춘다**

**상태:** 닫힘 (`chore/run-summary-and-lock-holder`, 2026-10-12, 방법을 Restart Manager에서 작업 디렉터리 훑기(윈도 PEB, 리눅스 `/proc`)로 바꿨다. DELETE 권한으로 열리지 않던 워크트리 셋을 쥔 것은 모두 데스크톱 앱이 띄운 `claude.exe`(그 세션들은 `isRunning`이 아니었다)의 작업 디렉터리였고, Restart Manager는 폴더를 받지 않고 작업 디렉터리를 보지 못하며 그 워크트리의 파일을 덩이로 등록하면 209초였다. 프로브 `lock_holder.py`. 일지 2026-10-12-08)
**어디로:** `tools/tidy_checkouts.py`(Windows Restart Manager로 쥔 프로세스의 이름과 pid를 남긴 이유에 붙인다)와 그 테스트
**승인:** 사용자 승인 2026-10-12, 3회차, 일지 2026-10-07-19·2026-10-07-21·2026-10-12-04. ADR 불필요
