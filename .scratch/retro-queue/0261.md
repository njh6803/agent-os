# 0261: **`/design-sync`의 `write_files`에 829개를 올리느라 묶음마다 파일 이름을 출력해 읽은 뒤 `{path, localPath}` 객체를 손으로 다시 지어 넘겼다.** 글꼴 771개가 여섯 묶음이라 같은 이름이 두 번씩 컨텍스트에 실렸고, 드라이버가 `styling: false`를 내는 재동기화에서도 글꼴을 다시 올릴지 정할 근거가 NOTES에 없었다

**상태:** 만료 2026-10-30
**어디로:** `.design-sync/`에 묶음 스크립트를 커밋하고(무시된 `.cache/`의 스크래치 판을 옮긴다) `write_files`에 출력을 그대로 넘기는 길과, 판정의 `bundle`·`styling`·`aux`가 `false`이면 그 몫을 다시 올리지 않아도 된다는 것을 NOTES "돌리는 법"에 적는다
**승인:** 자체 승인 2026-10-15, 1회차, 일지 2026-10-15-01. ADR 불필요.
