**어디로:** `docs/constitution/operations.md` 브랜치와 병합: PR은 제목과 본문을 JSON 파일로 써서 `gh api repos/njh6803/agent-os/pulls --method POST --input <파일>`로 연다(제목의 공백을 셸 인자로 넘기지 않아 워크트리 가드에 걸리지 않고, MCP의 확인 양식에 기대지 않는다). 이 길을 들이기 전에 PR 연 뒤의 계기 훅 둘이 이 길을 알아보게 한다(대기열 408)
