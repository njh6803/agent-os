# 0196: **프로브 README `canary/` 행이 명세마다의 결과를 한 칸에 이어 적어, 카나리아 명세를 더하는 PR 둘이 나란히 돌면 그 줄에서 병합 충돌이 난다**

**상태:** 닫힘 (`chore/canary-results-in-specs`, 2026-10-12, 명세 스물하나의 최신 결과를 각 머리 주석의 `# 최신 결과:` 줄로 옮겼다. README 행에서는 명세 수, 병합 뒤 그대로 돌지 않는 명세의 수와 이름, 명세마다의 결과를 걷고 일반 규칙만 남겼다. `operations.md`에는 결과를 적는 자리와 사전 확인 갈음을 적는 자리를 그 줄로 적고, 문서 위치 절의 기록 목록에 그 줄을 더했다. 헌법 3.0.27, 일지 2026-10-12-32)
**어디로:** `.scratch/harness/probes/canary/*.toml` 머리 주석에 명세마다 최신 결과 줄을 두고, 프로브 README `canary/` 행은 그 폴더와 기대만 가리킨다(185의 후속). `docs/constitution/operations.md` 카나리아 항목의 "일지와 프로브 README에는" 문장도 함께
