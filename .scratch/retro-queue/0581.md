# 0581: **CI `web` 잡의 `vitest run`이 시작 로그 한 줄(`RUN v5.0.2`) 뒤로 15분 동안 출력 없이 멈춰 잡 시간 제한으로 취소되고 `verify`가 빨갰다**(PR #479 실행 42196941501, 2026-11-06. 같은 웹 코드는 앞선 두 실행이 3분 50초에 지났고, 실패한 잡만 다시 돌려 지났다. 이 PR은 문서와 e2e 설정 파일 하나만 바꿨다. 멈춘 시험 파일은 로그에 없다)

**상태:** 열림
**어디로:** 대상 미정, 회차 감시. 다섯 번째에 `web` 잡의 시험 실행이 진행 출력으로 멈춘 시험을 이름으로 드러내게 하거나, 그 단계에 따로 짧은 `timeout-minutes`를 둔다. 477(`e2e-widget`의 apt 단계가 잡 제한까지 멈춘 것)과 같은 종류(CI 단계 하나가 멈춰 잡 제한에 걸린 뒤 재실행으로 통과)라 둘의 처방을 함께 본다
