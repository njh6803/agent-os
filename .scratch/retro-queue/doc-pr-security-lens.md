# doc-pr-security-lens: **바뀐 파일이 모두 문서인 PR에서 PR 직전 보안 축의 대체(`/security-review`)가 문서 파일의 지적을 규칙으로 빼, 공개 인터넷에 서는 기능 계획의 보안·개인정보 Major 둘이 셀프 리뷰 두 축과 PR 직전 대체 둘을 지나 PR 봇에서야 나왔다**

**상태:** 열림
**어디로:** `.claude/agents/bug-perf-review.md`: 바뀐 파일이 모두 문서이면 `/security-review`가 그 파일의 지적을 내지 않으므로, 이 서브에이전트가 보안·개인정보(문서가 정하는 공개 면, 토큰과 신원, 고지와 보존, 밖으로 나가는 데이터)도 본다. 새 지침 문장이라 문턱은 다섯 번째 반복이고 그 전에는 회차를 센다. 같은 부류를 명세 검토의 길로 고치는 열린 항목은 대기열 0574다
**승인:** 자체 승인 2026-11-07, 1회차, 일지 2026-11-07-2053-public-demo-plan.md. ADR 불필요

PR 488. CodeRabbit 첫 회차의 Major는 portal-login이었다(익명 모드에서 로그인 모드로 바꾼 뒤 같은 서명 키로 남는 익명 토큰). 둘째 회차의 Major는 public-demo였다(질문이 모델 API에도 보내지는데 배포의 정리 작업은 로컬 트레이스만 지운다). 이 세션의 `/security-review`는 발견 0건이었고 바뀐 파일 16개가 모두 `.md`였다. 그 명령의 프롬프트는 거짓 양성 거르기에 문서 파일(markdown)의 지적을 내지 말라는 하드 제외를 둔다(이 세션에 실린 프롬프트를 읽었다). 봇 회차가 둘 더 돌아 푸시와 CI가 두 바퀴 더 들었다.
