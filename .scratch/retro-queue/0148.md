# 0148: **등록 없는 워크트리 폴더가 '사람에게 넘긴다'인 채 쌓인다.** 지우다 실패한 `git worktree remove`가 남긴 폴더와 출처 모를 폴더가 여섯이었고(2026-10-07, `tools/tidy_checkouts.py judge`), 오래된 것은 며칠 전 것이다

**상태:** 닫힘 (`chore/tidy-checkouts-locks-and-leftovers`, 2026-10-12, 커밋하지 않은 내용은 파일마다 git 블롭 이름을 셈해 참조에서 닿는 객체(`git rev-list --all --objects`)와 견주어 가른다. `.git`이 있으면 넘기고, 링크나 커밋에 없는 파일, 쥔 프로세스가 있으면 남기며, 나머지는 `remove-stray`가 탐침과 재판정을 거쳐 지운다. 스킬 3의 판정 요약과 2의 명령 목록. 일지 2026-10-12-38)
**어디로:** `tools/tidy_checkouts.py`에 마저 지우는 하위 명령(경로가 `.claude/worktrees/` 바로 아래이고 등록과 `.git`이 없음을 확인하고, 막히면 멈춘다)과 `tidy-checkouts` 3의 넘긴다 갈래. 출처 모를 폴더의 커밋하지 않은 내용을 어떻게 가릴지가 먼저다
**승인:** 사용자 승인 2026-10-07, 1회차, 일지 2026-10-07-15. ADR 불필요
