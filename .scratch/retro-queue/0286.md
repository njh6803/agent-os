# 0286: **`tools/tidy_checkouts.py judge`가 체크아웃되지 않은 로컬 브랜치를 지울 후보로 낼 때 판정 3(그 브랜치가 제목인 실행 중 세션)을 보지 않아, 실행 중인 세션 `chore/mutate-followups`의 브랜치를 `remove-branch` 후보로 냈다**(세션이 손으로 판정 3을 적용해 치지 않았다)

**상태:** 닫힘 (`chore/tidy-running-branch`, 2026-10-19, `judge_branch`가 판정 1이 지울 것으로 낸 브랜치를 `--running` 제목과 견주어 같으면 `남긴다`(그 브랜치가 제목인 세션이 돈다)로 바꾼다. 윈도에서 `for-each-ref`가 낱개 참조 폴더의 대소문자로 이름을 찍는 것을 반박 시험이 찾아 대소문자를 가리지 않고, 같은 입력이 체크아웃 견줌(`judge`, `remove-branch`)도 깨 체크아웃된 브랜치를 지우는 것을 셀프 리뷰 명세 축이 재현해 세 자리를 `same_branch`로 모았다. `remove-branch`의 재판정은 `remove`처럼 세션을 보지 않고, `judge` 뒤에 열린 세션의 브랜치를 못 보는 것에 적었다. 시험 여섯을 더하고, 변이 다섯을 더하고 셋을 고쳤다(48의 원문과 표지, 체크아웃된 브랜치 줄의 원문, 초록 기대이던 `remove-branch`의 체크아웃 가드를 빨강 기대로). 독스트링의 판정과 못 보는 것, 프로브 README 행, 스킬 3의 문장과 그 카나리아 `tidy_skill_running_branch.toml`을 맞췄다)
**어디로:** `tools/tidy_checkouts.py`의 브랜치 지우기 판정과 그 테스트·변이 표: `--running`으로 받은 제목과 같은 이름의 브랜치는 `남긴다`(그 세션을 이유로 든다). `.claude/skills/tidy-checkouts/SKILL.md` 3의 체크아웃되지 않은 브랜치 문장도 판정 3을 든다. 지우는 길이라 `.claude/rules/tools.md`의 반박 시험을 거친다
