# 0319: **origin/main 을 합친 병합 커밋 뒤 저장소 전체 린트를 돌리지 않고 푸시해, main 에 새로 든 ruff 규칙이 이 브랜치의 파일을 CI 에서야 잡았다**(병합 커밋의 pre-commit ruff 는 스테이지된 `.py` 만 본다)

**상태:** 만료 2026-11-07 (ADR 0036)
**어디로:** `.pre-commit-config.yaml`: 푸시 단계(pre-push)에서 `uv run ruff check .` 를 전체로 한 번 돌리거나, `tools/hook_push_behind_main.py` 가 병합 뒤 첫 푸시에 그 명령을 계기로 넣는다. 걸리는 시간과 고르는 쪽을 재고 정한다. 2회차의 사건이 `ruff format --check .` 가 `.md` 안의 파이썬 코드 블록을 짚은 것이라 명령은 `uv run ruff check . && uv run ruff format --check .` 둘이고, 훅의 `types` 만 `types_or: [python, markdown]` 으로 넓히면 `.md` 만 바꾼 커밋은 덮어도 병합 커밋 뒤의 전체 린트는 덮지 못하니 푸시 단계 쪽을 먼저 잰다. 넓히기 전에 ruff 가 실제로 보는 확장자부터 잰다
**승인:** 자체 승인 2026-10-16, 2회차, 일지 2026-10-23-40-web-widget-spec.md(최근). ADR 불필요
