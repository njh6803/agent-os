# 0248: **`claude -p`의 stream-json을 읽는 탐침의 첫 판이 결과 이벤트를 줄 머리(`{"type":"result"`)로 찾고 막히는 `readline`으로 읽어, 첫 키가 `duration_api_ms`인 결과를 놓친 채 15분 넘게 멈췄다**(고친 판도 읽기 스레드의 EOF 표지를 먹어 끝의 배출이 막히는 결함이 있었고 PR 직전 버그 축이 재현했다)

**상태:** 닫힘 (`chore/probes-rule-batch`, 2026-10-16, `probes.md` 끝에 하위 프로세스 출력을 이어 읽는 탐침의 항목을 더했다. 읽기가 끝없이 기다리지 않고 원본을 잃지 않게 짓는다는 조항 아래, 줄을 풀어 `type`으로 알아보되 풀지 못한 줄은 넘기고, 읽는 스레드(daemon)와 큐로 읽고, 읽지 않는 stderr는 버리고, 기다리던 쪽이 꺼낸 EOF 표시는 큐에 되돌리고, 끝의 배출에도 제한 시간을 두며, 새 `claude -p` 탐침은 갈래 하나를 줄마다 받은 시각을 찍어 먼저 띄운다. 대안인 `tools/canary.py` 함수 빼기는 고르지 않았다. 사건의 탐침은 턴마다 입력을 보내며 출력을 이어 읽고 `canary.py`는 `subprocess.run`이 끝난 뒤 한꺼번에 풀어(코드를 읽었다), `canary.py`에는 뺄 이어 읽기 코드가 없다. 그래서 같은 파일을 든 287과 묶지 않았다. 카나리아 `probes_rule_stream_delete_marker.toml` 통과 4. 일지 2026-10-16-22)
**어디로:** `.claude/rules/probes.md`(223이 만든 탐침 규칙)에 한 문장: 이벤트는 줄을 풀어 `type`으로 알아보고, 하위 프로세스 출력은 제한 시간이 걸리는 읽기(스레드와 큐)로 읽고, 새 `claude -p` 탐침은 갈래 하나를 줄마다 시간을 찍어 먼저 띄운다. 또는 `tools/canary.py`의 실행·읽기를 탐침이 나눠 쓰는 함수로 뺀다
**승인:** 자체 승인 2026-10-13, 1회차, 일지 2026-10-13-59. ADR 불필요
