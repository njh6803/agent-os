# option-description-implied-omission: 설계 인터뷰의 선택지 설명이 "끝자리만 오른 판은 운영자가 이미지 태그만 바꾸면 된다"고 적자, 사용자가 버그 수정 판에는 릴리스 노트를 쓰지 않는다는 뜻으로 읽었다

**상태:** 열림
**어디로:** `.claude/skills/grilling/SKILL.md`의 "올리기 전" 항목: 선택지 설명이 무엇을 줄이거나 생략한다고 적으면, 그대로 남는 것(노트, 검사, 확인)도 같은 문장에 적는다. 새 지침 문장이라 문턱은 다섯 번째 반복이고 그 전에는 회차를 센다
**승인:** 자체 승인 2026-11-11, 1회차, 일지 2026-11-11-1110-release-image-design.md. ADR 불필요

설명의 사실은 맞았고(올릴 때 운영자가 할 일이 없다는 뜻이었다), 사용자가 그 문장에서 빠진 것(노트)까지 빠진다고 읽었다. 사용자가 고르지 않고 되물어 같은 턴에 바로잡았고, 다음 화면의 질문 문장에 "모든 판에 노트가 붙고, 고친 것도 빠짐없이 실립니다"를 넣었다. 자동 검사로 잡을 수 없는 판단이라 지침 층이다.
