# 0050: **claude-review의 코멘트 0개 가드를 자기 워크플로 파일로 좁힌다.** 가드 스텝은 `.github/workflows/` 아래 어느 파일이 바뀌어도 건너뛴다.

**상태:** 닫힘 (`chore/review-checkout-credentials`, 2026-10-07, 가드가 바뀐 파일 목록에서 그 파일 이름만 글자 그대로 찾는다. PR 템플릿의 `.github/` 줄도 고쳤다. 31행의 정정도 고쳤다. 탐침 `.scratch/harness/probes/review_workflow.py`, 일지 2026-10-07-14)
**어디로:** `.github/workflows/claude-code-review.yml`의 가드 스텝
**승인:** 사용자 승인 2026-09-29, 8회차, 일지 2026-09-28-07, 2026-10-07-11.

그런데 액션이 건너뛰는 것은 자기 파일을 바꾼 PR뿐이다(`operations.md` 리뷰 파이프라인). 가드의 주석도 같은 넓은 읽기다. 첫 web 티켓(`ci.yml`)과 대기열 31이 이 틈에 선다. 그 파일을 바꾸는 PR은 별도 PR로 먼저 병합하므로 첫 web 티켓 전에 도는 것이 좋다. ADR 불필요
