# pr-body-claims-behavior-code-lacks: **PR 본문이 코드에 없는 동작("알림 본문에서 일지의 인용을 지운다")을 적어, claude-review가 첫 회차에 Minor로 잡았다**

**상태:** 열림
**어디로:** PR 본문의 "왜 이렇게 했나"와 "리뷰어 참고"가 동작을 말하는 문장(지운다, 막는다, 거른다)은 그 동작을 하는 줄을 diff에서 찾은 뒤에 적는다. 5회차에 `CODING_STANDARDS.md`나 `git-pr` 사용자 스킬의 본문 작성 단계로 올릴지 판정한다(자동 검사로 옮길 수 없다. 본문과 diff의 일치는 문장 뜻을 읽어야 가려진다)
**승인:** 자체 승인 2026-11-08, 1회차, 일지 2026-11-08-1148-measure-word-journal-scope.md. ADR 불필요

사건: PR #498의 본문이 "알림 본문에서 일지의 `> 사용자:` 인용 문구가 낱말 검사에 걸리지 않게 지운다"고 쓰고 리뷰어에게 "인용을 지우는 부분"을 보라고 했지만, `tools/hook_measure_word.py`에는 인용을 지우는 코드가 없고 알림 문구에 무시하라고 적은 것이 전부였다. claude-review가 첫 회차에 이를 Minor로 잡았고 `gh pr edit`으로 본문을 고쳤다(코드는 그대로 두었다). 본문은 셀프 리뷰 이전에 쓴 초안을 이어 쓰다 어긋났을 것으로 어림한다(재지 않았다).
