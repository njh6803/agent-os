# 0136: **CLI 좌석이 없고 PR 리뷰가 rate limit이면 보안·버그·성능 축 리뷰가 없다.** 두 PR 연속이었다.

**상태:** 닫힘 (`chore/review-axis-and-failure-reason`, 2026-10-07, CLI가 돌지 못하면 PR 직전에 `/security-review`(보안)와 새 서브에이전트 `.claude/agents/bug-perf-review.md`(버그·성능)를 나란히 돌린다. 버그·성능의 대체는 사용자가 골랐다. operations.md 리뷰 파이프라인 2단계와 초록 착시 항목, PR 템플릿, `CODING_STANDARDS.md` 리뷰 관점, ADR 0006의 2026-10-07 이력, 일지 2026-10-07-16)
**어디로:** `docs/constitution/operations.md` 리뷰 파이프라인 2단계, PR 템플릿의 `coderabbit-review` 줄
**승인:** 사용자 승인 2026-10-07, 5회차, 일지 2026-10-07-01, 2026-10-07-03, 2026-10-07-12, 2026-10-07-13, 2026-10-07-15. 리뷰 파이프라인을 바꾸므로 ADR 이력이 필요할 수 있다

좌석이 없을 때 보안 축은 내장 `/security-review`를 PR 직전에 대신 돌린다. 그 명령은 보안만 보므로 버그·성능 축의 대안은 이 행을 닫는 세션이 따로 정한다(PR #158의 CodeRabbit)
