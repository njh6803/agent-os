# 0392: **`.scratch/mcp-shutdown/probes/full_stack.py`가 돌 때마다 저장소 사본(`.venv` 포함, 143~472MB)을 임시 폴더에 남겨, 두 세션의 열 번이 약 2.8GB를 남겼다**(사본 경로를 결과 JSON에 찍어 살펴보게 했지만 지우는 길이 없다. 같은 폴더의 `close_paths.py`·`serve_shutdown.py`도 사례마다 작은 폴더를 남긴다)

**어디로:** 그 세 프로브의 `main`: 어긋남이 없으면 만든 임시 폴더를 지우고, 있으면 지금처럼 경로를 남긴다. 고침이라 이 프로브를 다시 돌릴 때 함께 한다. `full_stack.py`는 2026-10-21 PR 직전 리뷰의 회차에 반영했다(같이 더한 `stale_parent.py`도 지운다). 남은 것은 다시 돌지 않은 `close_paths.py`·`serve_shutdown.py`다
