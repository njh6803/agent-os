# 0056: **pytest가 한국어 매개변수 id를 이스케이프하지 않게 한다.** 실패 출력이 `\uXXXX` 꼴로 찍혀 어느 사례인지 못 읽고, `-k`로 사례를 고르면 선택이 비어 변이 도구가 기준선 오류로 멈췄다

**상태:** 닫힘 (`chore/spec-pipeline-and-pytest-ids`, 2026-10-11, `pyproject.toml`의 그 옵션과 테스트 `tests/test_pytest_ids.py`. 그 옵션이 줄바꿈 같은 인쇄되지 않는 문자도 그대로 두어 id 여섯이 출력 줄을 갈라, 그 문자만 되돌리는 `pytest_make_parametrize_id`를 `tests/conftest.py`에 더했다. 옵션이 켜지면 바이트 값의 id가 수집을 죽여 같은 훅이 문자열로 바꾼다. PowerShell과 Git Bash에서 id가 한국어로 찍히고 `-k`가 id로 고르는 것을 손으로 봤다. CI(Ubuntu 24.04)의 `pytest -q`는 통과한 id를 찍지 않아 로그로는 보지 못했고, id 시험 셋을 포함한 1875 passed로 리눅스에서도 이스케이프되지 않는 것을 봤다, 일지 2026-10-11-01)
**어디로:** `pyproject.toml`의 `[tool.pytest.ini_options]`에 `disable_test_id_escaping_and_forfeit_all_rights_to_community_support = true`. `conftest.py`가 이미 stdout을 UTF-8로 고정한다. 반영할 때 Windows 콘솔과 CI 로그에서 실제 출력을 본다
