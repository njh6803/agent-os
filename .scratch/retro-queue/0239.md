# 0239: **막는 훅이 하류 판정(git, commit-msg 훅)을 앞당길 뿐이라고 적으면서 하류가 입력을 바꾸거나 판정을 건너뛰는 길을 나열하지 않아, 셀프 리뷰와 PR 직전 리뷰가 거짓 양성 반례 열하나를 찾았다**(여러 `-F`, `--squash`, `-e`, 같은 명령에서 쓰는 파일, 판정이 없는 저장소, `SKIP`, `--dry-run`, heredoc 본문 등)

**상태:** 닫힘 (`chore/rules-tools-batch`, 2026-10-14, `.claude/rules/tools.md`의 막는 훅 항목 바로 뒤에 뗀 하류 판정 항목(PR 봇 리뷰가 한 항목에 주제가 넘친다고 짚어 뗐다). 병합 때 합친 2회차(래퍼가 입력을 다르게 읽는 길의 거짓 음성)도 같은 문장이 덮게 넓혔다, 카나리아 `tools_rule_writer_receiver_cloud_gh_downstream.toml`, 일지 2026-10-14-07)
**어디로:** `.claude/rules/tools.md`의 막는 훅 항목에 한 문장: 하류 판정과 같은 입력에서만 막는다고 주장하는 훅은 하류가 입력을 바꾸거나(옵션, 정리, 접두) 판정을 건너뛰는(우회 옵션, 환경, 설정) 길을 먼저 나열하고 그 길마다 지나간다는 시험을 둔다
**승인:** 자체 승인 2026-10-13, 2회차, 일지 2026-10-13-47·2026-10-13-67. ADR 불필요
