# 0496: **`.design-sync/`의 노드 스크립트(`upload-output.mjs`, `check-conventions.mjs`)에 커밋된 시험이 없어, 리뷰마다 스크래치 탐침으로 종료 코드의 갈래를 다시 쟀다**(design-reverse-sync 08. 셀프 리뷰 표준 축과 PR 직전 `bug-perf-review`가 각자 가짜 `ds-bundle/`을 지어 쟀고, 뒤의 것이 잡히지 않은 예외와 모르는 항목이 같은 종료 1인 것을 잡았다. PR #404의 claude-review 첫 회차도 같은 지적을 Minor로 냈다)

**상태:** 닫힘 (.scratch/design-card-build/issues/04-upload-always-assembles.md, 2026-10-30, 두 스크립트를 지웠다. 산출은 짓기 명령(`assemble.ts`)이, 사용 규약 검사는 `pnpm -C web verify`의 파일 검사(티켓 02)가 맡고 둘 다 커밋된 시험이 있다. 일지 2026-10-30-10-upload-always-assembles.md)
