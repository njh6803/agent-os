# open-session-send-denied-despite-allow-rule: **0498이 넣은 허용 규칙과 글자까지 맞는 인계 열기(`tools/open_session.ps1 -Action send`)를 자동 모드 분류기가 다시 거부해 인계를 못 했다**(PowerShell 도구, `-Folder C:\project\agent`, `-PromptFile`은 세션 스크래치패드 아래였다. 도구 결과는 서버의 자동 모드 분류기가 설명 없이 위험하다고 판정했다는 문구였다. 0498은 허용 규칙에 맞는 호출이 판정기를 거치지 않는다는 것을 공식 문서의 요약으로만 보고 닫혔다)

**상태:** 열림
**어디로:** 하네스 chore: 허용 규칙에 맞는 호출도 자동 모드의 서버 분류기가 거부할 수 있는지 공식 문서 원문으로 확인한다. 거부할 수 있으면 허용 규칙으로는 이 길이 열리지 않으므로, 인계 열기가 분류기에 막혔을 때의 길을 `.claude/skills/next-session/handoff.md`(`인계 못함`을 적는 단계)에 정하고, 사용자가 고를 몫(권한 모드, 사람이 대신 치기)이 들면 넘긴다. 거부하지 않는다면 이 세션의 호출이 규칙에 맞지 않은 까닭(설정을 읽은 체크아웃, 규칙의 글자)을 가른다
