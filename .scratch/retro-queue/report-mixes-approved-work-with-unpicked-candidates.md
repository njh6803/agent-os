# report-mixes-approved-work-with-unpicked-candidates: 마무리 보고의 "정하실 것" 한 항목에 사용자가 이미 승인한 일과 아직 고르지 않은 후보를 섞어 적었다(여덟 이름은 사용자가 새 이름을 골라 승인한 일이고 마흔아홉 후보는 고른 적이 없는데 "남은 이름 후보를 더 바꿀지" 한 항목으로 물었다. 사용자가 "1. 진행"이라 답했고, 무엇을 진행할지 가르려고 선택 화면을 다시 올렸다)

**상태:** 열림
**어디로:** 대상 미정, 회차 감시. 마무리 보고에서 사용자에게 정해 달라고 하는 항목은 이미 승인된 일(할지 말지가 아니라 언제 할지)과 아직 고르지 않은 후보를 따로 적는다. 자동 검사로 옮길 수 없다(대화의 보고다). 5회차가 되면 `CLAUDE.md` 원칙에 더할지 판정한다
