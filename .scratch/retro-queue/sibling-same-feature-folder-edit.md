# sibling-same-feature-folder-edit: **붙여 넣은 다른 저장소의 판정으로 시작한 세션이 같은 `.scratch/base-agent/`를 고치는 형제 세션을 모른 채 명세와 프로브를 고치고 실제 모델로 77회차를 돌린 뒤에야, 커밋 직전의 `tools/sibling_overlap.py`로 같은 파일 넷의 겹침을 알았다**(사용자는 그 브랜치를 병합하지 않기로 했다. 그 기능의 직전 일지 "다음"은 그 일을 티켓 세션의 몫으로 적고 있었다)

**상태:** 열림
**어디로:** 대상 미정, 회차 감시. 후보는 한 세션이 `.scratch/<slug>/` 아래 파일을 처음 고칠 때 형제 워크트리가 같은 폴더를 고쳤는지 알리는 계기 훅이다(`tools/sibling_overlap.py`의 "함께 고친 파일" 판정을 쓴다). 0393의 처방(다음 작업을 고르는 자리가 형제 워크트리의 커밋하지 않은 `.scratch/<slug>/`를 찍는다)과 같은 판정을 나눠 쓸 수 있다
**승인:** 자체 승인 2026-11-11, 0393의 2회차, 일지 2026-11-11-1555-base-agent-tickets.md(사건은 일지 2026-11-11-1537-base-agent-full-text-window.md). ADR 불필요
