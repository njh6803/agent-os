# 0152: **`tools/mutate.py` 변이 파일의 원문에는 닫는 `'''` 앞의 줄바꿈까지 든다.** 줄의 일부만 적은 원문 넷이 `--check`에서 걸렸다(검사가 잡았다).

**상태:** 닫힘 (`chore/mutate-timeout-and-select`, 2026-10-12, 변이 파일 문단에 닫는 `'''` 앞의 줄바꿈이 원문에 든다는 것과, 그렇게 닫는 원문은 마지막 줄을 줄 끝까지 적고 줄의 일부는 닫는 `'''`를 같은 줄에 둔다는 것을 적었다. 세 경우를 시험으로 쟀다. 일지 2026-10-12-29)
**어디로:** `tools/mutate.py` 독스트링의 변이 파일 문단
**승인:** 사용자 승인 2026-10-07, 1회차, 일지 2026-10-07-12. ADR 불필요
