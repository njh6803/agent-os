# 07: 에이전트가 MCP 도구를 쓴다

**무엇을 만드나:** 에이전트가 매니페스트에 적은 MCP 서버의 도구를 써서 답한다. 모델이 도구를 부르면 런타임이 실행해 결과를 되돌리고 모델이 멈출 때까지 반복한다. 도구 호출이 이벤트로 남고 트레이스에 보인다. 적지 않은 서버의 도구는 붙지 않는다.

이 티켓이 제품 의도 문서의 둘째 성공 조건을 끝낸다. CLI로 에이전트 하나가 MCP 도구를 써서 답하고 트레이스가 남는다. 첫 슬라이스가 여기서 닫힌다.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] core가 도구 원천 포트를 선언한다. 시작과 종료의 수명을 가진다
- [ ] 실행 함수의 시그니처가 그 포트를 받도록 넓어진다. 04가 만든 넷에 다섯째가 붙고, 06이 이미 쓰고 있던 호출부도 같이 고친다
- [ ] 어댑터가 stdio MCP 서버에 붙어 도구 목록을 주고 도구를 호출한다
- [ ] 에이전트 매니페스트가 지정한 서버의 도구만 붙는다. 다른 서버가 저장소에 있어도 붙지 않는다
- [ ] 지정이 비면 도구 없이 돈다
- [ ] 지정한 이름이 실재하지 않으면 실행 전에 끝난다. 종료 코드 1이고 트레이스가 없다
- [ ] 컨텍스트의 모델 호출이 도구를 붙인 채 루프를 돈다. 모델이 도구를 부르면 실행하고 결과를 되돌린다
- [ ] 도구 호출마다 이벤트가 하나 나고 성공 여부가 담긴다
- [ ] 컨텍스트가 모델을 거치지 않고 도구를 직접 부르는 길을 준다
- [ ] 컨텍스트 메서드의 인자와 반환이 JSON으로 직렬화 가능하다. 파이썬 객체를 넘기지 않는다
- [ ] MCP 서버 기동 실패가 실패 이벤트로 끝난다. 도구 없이 절반만 답하지 않는다
- [ ] 도구가 에러를 내면 실패로 기록하고 에러 내용을 모델에 되돌려 루프를 계속한다
- [ ] 수명이 있는 도구 원천을 테스트에서 async 픽스처로 연다
- [ ] 06이 만든 `calc`의 매니페스트에 `everything`을 더하고 그 mcp 플러그인을 저장소에 둔다. 새 에이전트를 만들지 않는다
- [ ] 마커를 단 end-to-end 테스트가 실제 호출로 답을 받고, 트레이스에 모델 호출과 도구 호출이 모두 남는다
- [ ] 프로바이더와 MCP 라이브러리의 타입이 sdk와 채널로 새지 않는다. 경계는 포트다
- [ ] 검증 명령 넷이 초록이다
