# 05: 플러그인을 디스크에서 읽고 트레이스를 디스크에 쓴다

**무엇을 만드나:** 플러그인의 진실의 원천이 파일시스템이 된다. 에이전트 개발자는 디렉터리에 매니페스트와 파이썬 파일을 놓는 것만으로 등록을 마치고, 운영자는 실행마다 트레이스 파일을 하나씩 얻는다. 아직 실행 함수와 연결되지 않는다. 부르는 쪽은 테스트다.

04가 선언한 포트 셋을 구현한다. 처음에 04와 나란히 갈 수 있다고 적었다가 셀프 리뷰에서 철회했다. 포트의 선언 주인이 04라서 나란히 가면 둘이 같은 자리에 포트를 만든다.

04와 따로 두는 이유는 남는다. 실행 함수를 쓰지 않으므로 04가 후퇴로 루프를 다시 만들어도 이 티켓은 영향을 받지 않는다.

**Blocked by:** 03, 04

**Status:** done

- [ ] 플러그인 원천 어댑터가 디렉터리에서 매니페스트를 읽는다. 디렉터리와 종류가 어긋나면 에러를 낸다
- [ ] 에이전트 진입점을 고유 모듈명으로 로드한다. 검색 경로를 건드리지 않는다
- [ ] 같은 파일명을 가진 플러그인 둘을 놓아도 서로 덮어쓰지 않는다
- [ ] 에이전트가 지정한 MCP 서버 이름을 그 이름의 mcp 매니페스트로 풀어 준다. 없는 이름은 에러다
- [ ] 트레이스 어댑터가 한 줄에 JSON 하나를 쓴다. 첫 줄은 형식 버전과 실행 식별자를 담은 헤더다
- [ ] 파일 이름이 실행 식별자이고 쌓이는 디렉터리를 정할 수 있다
- [ ] 쓴 것을 다시 읽으면 넣은 이벤트와 같다
- [ ] 모르는 종류의 이벤트가 섞인 트레이스를 읽어도 원문이 보존된다
- [ ] 시계 어댑터가 UTC 시각과 실행 식별자를 준다. 식별자는 실행마다 다르다
- [ ] 어댑터가 포트를 상속하지 않고 시그니처로 만족한다. 픽스처가 포트 타입으로 annotate된다
- [ ] 어댑터가 채널과 관리를 import하지 않는다. 경계 검사가 판정한다
- [ ] 검증 명령 넷이 초록이다
