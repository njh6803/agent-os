# 03: sdk 계약을 첫 슬라이스에 맞춘다

**무엇을 만드나:** 플러그인 작성자가 첫 슬라이스에 필요한 것을 매니페스트와 이벤트에 적을 수 있게 된다. 매니페스트에 형식 버전을 적고, 에이전트가 쓸 MCP 서버를 지정하고, mcp 플러그인이 서버 실행 방법을 적는다. 모든 실행 시작 이벤트에 주체가 붙고, 에이전트는 컨텍스트에서 실행 식별자와 현재 시각을 받는다.

디스크에 남는 형식을 바꾸는 티켓이라 04와 05를 막는다. 02와는 겹치지 않아서 나란히 갈 수 있다.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 디스크 형식을 바꾸는 변경이라 ADR 초안을 쓰고 승인을 받는다. 기존 매니페스트에 형식 버전을, 기존 시작 이벤트에 주체를 필수로 더하는 것이다. 규칙의 원천은 `.claude/rules/sdk.md`
- [ ] 매니페스트가 형식 버전을 요구하고, 아는 값 하나만 받으며, 모르는 값은 거부한다
- [ ] 플러그인 종류가 넷이고 고정 값 집합으로 선언된다. 판별자와 형식 버전만 리터럴로 남는다
- [ ] 에이전트 매니페스트가 쓸 MCP 서버 목록을 가진다. 비어 있으면 도구가 없다는 뜻이고, 에이전트 종류가 아니면 이 항목을 갖지 못한다
- [ ] mcp 매니페스트가 서버 실행 명령과 인자를 가진다. mcp 종류가 아니면 이 항목을 갖지 못한다
- [ ] 실행 시작 이벤트가 주체를 필수로 가진다. 주체 없는 시작 이벤트는 거부된다
- [ ] 컨텍스트가 실행 식별자와 현재 시각을 준다. 에이전트가 시각과 난수를 직접 얻지 않아도 된다
- [ ] 실행 식별자, 에이전트 이름, 플러그인 이름, 주체가 각각 고유 타입이고 JSON 형식은 문자열 그대로다
- [ ] 이벤트가 JSON을 왕복해도 같고, 모르는 종류는 거부된다
- [ ] 기존 `sdk` 테스트가 계약 변경에 맞게 고쳐져 초록이다
- [ ] sdk가 엔진과 프로바이더를 모른다. 경계 검사가 판정한다
- [ ] 검증 명령 넷이 초록이다
