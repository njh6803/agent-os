# 01: 의존성과 테스트 설정을 헌법 스택 표에 맞춘다

**무엇을 만드나:** 저장소가 첫 슬라이스를 만들 수 있는 상태가 된다. 그래프 엔진과 모델 추상, 프로바이더 어댑터와 MCP 브리지가 설치되고, 비동기 테스트를 쓸 수 있게 되며, 기다리지 않은 코루틴이 초록으로 지나가지 않는다.

계약 변경과 나누어 놓았다. 이 티켓의 락 파일 diff가 수백 줄이라 스키마 변경과 같이 담으면 리뷰어가 그 더미에서 계약을 찾아야 한다. 패키지 교체가 실패했을 때 원인이 모호해지지 않게 하는 목적도 있다.

**Blocked by:** 없음. 바로 시작할 수 있다.

**Status:** done

- [ ] MCP 라이브러리가 브리지의 요구대로 내려가는 것을 확인하고 받아들인다. ADR 0001이 예상한 대가다
- [ ] 비동기 테스트를 `async def`로 쓴다. 데코레이터도 마커도 없고 이벤트 루프를 직접 돌리지 않는다. ADR 0007
- [ ] 기다리지 않은 코루틴이 스위트를 실패시킨다. 경고 전부가 아니라 해당 경고만 에러다
