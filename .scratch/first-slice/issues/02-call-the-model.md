# 02: 모델을 실제로 부른다

**무엇을 만드나:** 런타임이 모델 포트를 통해 Anthropic 모델을 실제로 부르고, 그 호출이 테스트로 증명된다. 운영자는 어떤 모델로 부를지 정할 수 있고, 지정한 모델이 안 되면 다른 모델로 몰래 넘어가지 않는다.

**이 티켓이 원칙 I의 판정이다.** 성공의 정의는 `docs/PRD.md`가 원천이고 거기서 조건이 둘로 나뉘어 있다. 이 티켓이 그중 2026-09-22 기한이 붙은 첫째를 끝낸다. 그래서 sdk 계약보다도 앞에 온다. 모델 어댑터는 매니페스트도 이벤트 스키마도 쓰지 않기 때문에 계약 티켓을 기다릴 이유가 없다.

프로바이더 라이브러리의 strict 타입 마찰이 여기서 처음 드러난다. 그래프 엔진 쪽 마찰은 04에서 드러나고 ADR 0001의 후퇴 판단은 그때 내린다.

**Blocked by:** 01

**Status:** done

- [ ] core가 모델 포트를 선언한다. 포트는 닫힌 목록 다섯 중 하나이고 새 포트를 더하지 않는다
- [ ] 어댑터가 Anthropic 모델을 부른다. core는 프로바이더 라이브러리를 import하지 않고 경계 검사가 그것을 판정한다
- [ ] 조합 층이 모델 인스턴스를 만들어 넘긴다. 어댑터가 자기를 스스로 조립하지 않는다
- [ ] 모델 이름이 환경변수와 기본값으로 정해지고 폴백이 없다. 기본값은 명세에 적혔다. 플래그는 CLI가 생기는 06에서 이 순서 앞에 붙는다
- [ ] 실제 호출 테스트 하나가 마커를 달고 통과한다. 요청을 보내고 답을 받는다
- [ ] 키가 없으면 그 테스트가 skip이 아니라 실패한다
- [ ] 기본 스위트는 네트워크 없이 돈다. 실제 호출 테스트는 기본 실행에서 제외된다
- [ ] 타입 우회 없이 통과한다. 프로바이더 타입은 경계에서 우리 타입으로 감싼다
- [ ] 이벤트와 로그에 키나 토큰이 실리지 않는다
- [ ] 검증 명령 넷이 초록이다
