# 06: 일시정지가 프로세스보다 오래 사는 것을 실물로 잰다

**What to build:** 이 기능의 존재 이유를 실물로 증명하고 슬라이스를 닫는다. 실제 CLI 프로세스가 승인 대상 도구에서 멈추고 **끝난 뒤**, 다른 프로세스가 같은 실행을 재개해 끝까지 간다.

가짜 포트로 증명할 수 없는 주장이 딱 하나 있고 그것이 이 기능의 전부다. 프로세스 안에서 기다리는 설계를 버린 이유가 여기 있으므로, 그것만은 프로세스를 실제로 죽였다 살려서 잰다.
