# 03: 멈춘다

**What to build:** 승인이 필요한 도구를 부르려 하면 실행이 멈추고 끝난다. 여기서 처음으로 기능이 데모 가능해진다. `requires_approval`을 단 에이전트를 돌리면 CLI가 실행 식별자와 "무엇을 승인해 달라는지"를 찍고 전용 종료 코드로 끝나며, 그 도구는 실행되지 않은 채 트레이스에 일시정지가 남는다. 아직 재개는 못 한다.

가드레일은 런타임이 건다. 에이전트 코드는 플러그인이고 신뢰 경계 밖이므로, 경로를 바꿔 빠져나갈 수 있으면 가드레일이 아니다.

**Blocked by:** 02. (진짜 관문은 01뿐이다 — 멈추는 데 트레이스 읽기가 필요하지 않다. 02를 앞에 둔 것은 둘 다 실행 조립부와 CLI를 건드려 사슬로 가기로 한 순서 선택이다.)
