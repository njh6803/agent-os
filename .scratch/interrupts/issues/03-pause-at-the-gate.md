# 03: 멈춘다

**What to build:** 승인이 필요한 도구를 부르려 하면 실행이 멈추고 끝난다. 여기서 처음으로 기능이 데모 가능해진다. `requires_approval`을 단 에이전트를 돌리면 CLI가 실행 식별자와 "무엇을 승인해 달라는지"를 찍고 전용 종료 코드로 끝나며, 그 도구는 실행되지 않은 채 트레이스에 일시정지가 남는다. 아직 재개는 못 한다.

가드레일은 런타임이 건다. 에이전트 코드는 플러그인이고 신뢰 경계 밖이므로, 경로를 바꿔 빠져나갈 수 있으면 가드레일이 아니다.

**Blocked by:** 02. (진짜 관문은 01뿐이다 — 멈추는 데 트레이스 읽기가 필요하지 않다. 02를 앞에 둔 것은 둘 다 실행 조립부와 CLI를 건드려 사슬로 가기로 한 순서 선택이다.)

**Status:** ready-for-agent

- [ ] `requires_approval`에 적힌 도구를 모델이 부르려 하면 일시정지 이벤트가 나고 실행이 끝난다. 그 도구는 실행되지 않는다
- [ ] 컨텍스트로 직접 부른 도구에도 같은 정책이 걸린다. 게이트는 도구에 붙는 것이지 경로에 붙는 것이 아니다
- [ ] 한 모델 턴에 승인 대상이 둘이면 첫 것에서 멈춘다. 일시정지 이벤트는 도구 하나만 담는다. (재개 뒤 둘째에서 다시 멈추는 나머지 절반은 04가 판정한다)
- [ ] `secret_args`로 선언된 인자가 마스킹된 채 이벤트에 담긴다. 마스킹은 이벤트를 만드는 `core`가 하고 트레이스 어댑터는 받은 것을 쓴다
- [ ] `requires_approval`이 실재하지 않는 도구를 가리키면 도구 연결 직후 실행이 실패한다. 실행 안의 실패이므로 트레이스가 남는다
- [ ] `requires_approval`이 없거나 비어 있으면 지금과 똑같이 동작한다
- [ ] CLI가 멈출 때 실행 식별자와 도구 이름·인자를 표준 출력에 찍는다. 마스킹된 인자는 마스킹된 채로 보인다
- [ ] 일시정지가 실패와 **다른** 전용 종료 코드로 끝난다. 스크립트가 성공으로 오해하지 않는다
- [ ] 검사 넷이 초록이다
